## 六、作者上手指引（新能力怎么用）

- **看用量/成本**：工作台（ribbon「工作台」）→「AI 用量」卡；要金额 → 设置·服务提供方 → 展开供应商 → 自定义设置 → 价格表（每百万 token 四档单价）。
- **章/卷摘要**：默认自动——定稿即生成章摘要、写作时自动补近章与上一卷；手写摘要放 `定稿/摘要/章摘要/<N>.md` 即优先。关闭：book.yaml `summary.auto: false`。
- **预算双口径**：book.yaml `budget.tokens_per_chapter` / `cost_per_chapter`（或 global.json `tokensPerChapter`/`costPerChapter`）——超限自动写章拦截，文案含出路。
- **误报治理**：机检面板红/黄项点「误报」；存量书跑 `npm run corpus:harvest` → 在 `工作区/语料候选/*.md` 勾选 `[x]` → `npm run corpus:commit` 入回归门；账本 fm 写 `leak_keywords: [...]` 免手填 book.yaml。
- **日志排查**：`<userData>/logs/app-YYYYMMDD.jsonl`（保留 7 天）；启动迁移故障应用内横幅直达。
- **token 校准**：攒一段真实用量后 `npx tsx scripts/calibrate-tokens.ts`，把建议值填进 `src/process/prepare.ts` 的 `TOKEN_COEFFICIENTS`。
