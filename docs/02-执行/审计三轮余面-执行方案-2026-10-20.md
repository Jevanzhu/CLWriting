- **靶点与现状**：`src/events/store-retention.ts` **已有完整实现**——库 header 读档位，新库按 `auto_vacuum = INCREMENTAL` 建（`src/events/store-open.ts:72-103`），存量库走「同一连接上设 PRAGMA 再立即 VACUUM」的转换路径（`store-retention.ts:318-361`），并用存活页上限 `CONVERT_VACUUM_LIVE_PAGE_MAX = 2048` 封顶代价（`:86,342`），正是为了避免大库 VACUUM 卡住。**rag / cache / check / learn 四库零 vacuum**（实测各档 `vacuum` 命中数均为 0）；`src/rag/store.ts:335-364` 的开库只设 `busy_timeout` + WAL。
