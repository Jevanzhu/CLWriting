## 一、观察面余项

- **dev-api 端口占用提示跨平台**：C5b-a 的「端口提示跨平台」扫的是 `src/` 八档，`scripts/dev-api.ts` 不在其射程内——其 EADDRINUSE 提示仍为 POSIX 单口径（`lsof`），win 上给不出可执行动作。本次按 `process.platform` 分支给命令（win：`netstat -ano | findstr :PORT` + `taskkill /PID <pid> /F`；其余：`lsof -i :PORT`），与 `src/` 侧口径对齐。
- **bookRoot 拼写分裂余面**：mac 专属缺陷（书架摘要缓存 realpath 与词法书根拼写失配）此前只修了单点；本次逐面核——`src/studio/server/cache-registry.ts` 增 `bookRootAliases`（词法 + resolve + realpath 三形态）与 `forgetBookKeyedCachesForRoots`，删书（`api/books-lifecycle.ts`）与改名（`api/books-rename.ts`）在 FS 操作**前**捕获别名族并广播失效（目录已搬走后再 realpath 取不到旧拼写）。`test/studio/server/ttl-cache.test.ts` 补 `bookRootAliases` 组（realpath + POSIX symlink 两例）。
- **低精度卷 mtime 依赖面**：`src/cache/rebuild.ts` 的章读缓存按 mtime 指纹判失效，而 FAT（2s）/exFAT（10ms）/SMB（1s）卷的 mtime 精度会把同秒内改动静默判为未变——新增 `isCoarseMtimeNs` 判据，粗精度卷直接绕过缓存读写（`misses++` + 直读），`test/cache/rebuild-chapter-read-cache.test.ts` 用 `utimesSync` 置整秒 mtime 断言零缓存条目/零命中。
- **覆盖率贴线桶实测**：见 §二 四桶行。
