- 靶点：链规约、索引、活账三份正本对齐 skill 模型；旧规范按失效档归档。
- 动作：新增本档与设计档；重写 `05-规范/文档操作链-现行规范-2026-10-14.md`（八槽位与「不属于这里」、命名四段与类型词闭合、定位行、活账文法与加摘行纪律、评审三出口、归档三关、篇幅、门与诚实边界、链档与决策记录分界、升级）；重写 `Dev/Docs/README.md`（槽位表 + 阅读顺序 + 维护，去文件名枚举）；`00-总览与实施路线-2026-08-15.md` 改名 `00-活账.md` 并收身（摘掉文档地图 / 阅读顺序 / 决策镜像，留开放任务与现行口径）；旧规范加归档记后移入 `Archive/`；`scripts/check-docs.mjs` 的索引面清单路径随改名更新。
- 验收：`npm run check:docs` 绿；`npm run check:counts` 绿（Archive 篇数 8→9 同步）；索引篇数 = 磁盘实况；diff 只含上述文件。
- 门命令：`npm run check:docs`、`npm run check:counts`、`npx vitest run test/scripts/check-docs.test.ts`。

## 批 B：链实体迁移

- 门命令：`npm run check:docs`、`npm run check:links`（批 C 落地后并入 `check:harness`）。

## 批 C：门禁落地与治理正本指针

- 靶点：让批 A/B 的规约可机器核；`AGENTS.md` 与 skill 的分工落成指针。
- 动作：`.agents/skills/` 装 skill 副本（同时收口此前暂存的删除）；`scripts/harness/markdown-patterns.json` 划定 Markdown 扫描面（根常驻档 + `Dev/Docs/**`）；`scripts/harness/doc-index.manifest.json` 声明 `Dev/Docs` 槽位（六条 `count:true`）；`package.json` 加 `check:harness`；`ci.yml` 加一步；`AGENTS.md` 「五 check」→「六 check」并给同文条目加 skill 指针（删重复展开、条目结构不动）；`check-counts` 的 Archive 篇数族摘掉（改由 doc-index 承担）。
- 验收：`check:harness` 绿；造一条死链 → 红且报 `path:line`，还原 → 绿；Archive 篇数单点声明（改索引数字即红、改磁盘即红）。
- 门命令：`npm run check:harness`、`npm run check:counts`、`npm test`。

## 批 D：决策记录层

- 靶点：链档管过程与交付、决策记录管可检索的决定——这一层本仓目前为空。
- 动作：`.agents/notes/harness.json` 配 `{"primaryLanguage":"zh","pairedDocuments":false}`；回填 3–5 条样板记录（从既有设计档里提炼：形态选择、负面保证、被否决的替代，日期取该主题首次被提出那天）；规范第九节与 `AGENTS.md` 的指针落地核对；CI 加 note 门与归档基线环境变量。
- 验收：骨架错的记录（缺 `## 备选方案`）→ 红；`Status:` 与所在目录不符 → 红；归档一条并 `--write` 封存后，改字节 → 红。
- 门命令：`npm run check:harness`、`npm test`。
