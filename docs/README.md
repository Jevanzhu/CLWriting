## 二、阅读顺序

活账（领任务/看状态）→ 上表对应槽位的档 → 规范（动手前须知）。设计档只做展示、不纳入计划；归档文档与调研底稿不作实施依据。

## 三、维护

- 新档落地/换类/归档：同批更新本表篇数；活账的加行与摘行同批做完。
- 分类目录常驻，空目录以 `.gitkeep` 保形。
- 本文件只写槽位与篇数（不写正文、不设变更记录节）；根 `README.md` 只对外介绍，篇幅纪律见规范。
