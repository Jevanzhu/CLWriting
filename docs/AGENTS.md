# docs/ 子树规则

- 定位：`docs/` 链的**局部强制规则薄档**——只写「进这片子树须知」；规则正文不在此。操作规则 = `05-规范/文档操作链-现行规范-2026-10-14.md`，治理与纪律 = 项目根 `AGENTS.md`，判据全文 = `.agents/skills/` 两 skill 副本。本档不复制它们。
- 槽位与篇数 = `README.md`（唯一声明点）；未了结事项 = `00-活账.md`。在这片子树里找入口，先读这两份。

## 三条进门纪律

- **一个事实一个家**：写下一段话前先问「这个事实已经住在哪了」；答案在别处就改那处原文并链回，不在此另写一份。
- **历史正文不改写**：存量文档的正文与 `Archive/` 保持原样，只随现况更新索引行、状态行与路径行；归档只增不改，要改就移回来改完再冻。
- **格式门在此生效**：散文一段一行、单行长度上限与禁用短语（`check:docs`）、相对链接与锚点（`check:harness` 的 `markdown-links`）都是进门门槛，写档前过一遍规范第七、八节。

## 不属于这里

产品语料（`知识层/`、`resources/`）、决策理由（`.agents/notes/`）、常驻指令（根 `AGENTS.md`）——各回各家。
