# 章节钩子速查

用于连载中写章首与章尾：按本章情绪与跨章期待选钩法、定强度、定落点。与本书大纲、账本、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 章尾读起来像总结，读者没有下一步预期 | 章尾选型 + 落点判据 |
| 章首平铺直叙，进正文慢 | 章首承接 + 尽早出现异常 |
| 上章钩子吊了几章不兑现 | 期待—兑现回路 |
| 连续两章同一种钩法，读者猜得到走向 | 钩法轮换 |
| 日常章硬塞强钩，读着别扭 | 强度与阶段匹配 |
| 打脸爽不起来，甚至读成虐主 | 前置备好 + 铺垫重于打脸 |
| 危机章的章尾不紧张 | 按本章情绪选型 |
| 反转揭得太早，读者提前猜到 | 信息差与揭示范畴 |
| 两难抉择读者不纠结 | 两难成立判据 |
| 章尾靠解释、回顾凑长度 | 落点服从信息复杂度 |
| 金手指出场没期待感 | 系统激活 / 选择型钩法 |
| 换卷、换章处读者流失 | 跨章期待移交 |

## 法则清单

### 章尾选型（按本章情绪）
- 本章主调是悬念 → 揭一部分留一部分，或只给含义未知的物件与反应。
- 本章主调是紧迫 → 用下章必须回应的威胁、倒计时、被打断的动作。
- 本章主调是反转 → 用身份偏离预期、表面正常里藏信息、与章首呼应的回声。
- 本章主调是情感 → 用被迫二选一、有人宣布意图、态度骤然转变。
- 本章主调是日常 → 用意象变化、不可能的消失、角色知道而读者不知道的信息差，暗流即可。
- 系统机制文另有两个专用落点：金手指初次激活，与二选一抉择，用于把能力带进读者的期待里。
- 选型先服从本章在主线上的功能，再服从情绪；两者冲突时以功能为准。

### 钩子与推进
- 钩子只负责把读者送进下一章，不负责本章收束：本章的账在本章内结清，钩子是下一笔账的开头。
- 看点吊起期待、爽点兑现期待，一一对应：前面铺多少，后面就爽多少。
- 章末钩子写到「期待成立」为止，不写兑现；兑现留给下一章开头。
- 钩子必须挂在主线上，不指向主线进程的钩子是偏移期待。
- 换章、换卷处把未闭合的期待明确移交，别让读者以为这条线断了。
- 连续多章不兑现同一钩子，等于宣布它作废；钩子挂账与还账要成对。

### 章首与跨章承接
- 章首尽早出现可识别的行动、异常或未闭合期待，按情节复杂度定位置，不按固定位置机械卡点。
- 上章的钩子要在本章开头被回应或推进，哪怕只是让代价先落地。
- 章首策略与钩法配套：要即时冲击就用进行中的动作或倒计时开局；要好奇就用信息差；要反差就把两个不相干的场景并置。
- 章首不重复上章已交代的信息，默认读者记得住。

### 强度取舍
- 强度与故事阶段匹配：开篇期与高潮前必须强，日常期中等即可，收束段转弱、转收。
- 强钩子用多了会钝：日常章硬上强钩，读者会开始以为每章都要出事。
- 钩子强度服从本章信息复杂度，不用解释与回顾充篇幅。
- 同类强钩连用会掉价，相邻两章换一种钩法。
- 弱钩不等于没有钩：日常章的钩子是暗流与关系变化，不是无事发生。

### 写法判据（分钩法）
- 揭示型：抛出的信息要改变读者对全局的判断，只给答案碎片不给结论。
- 危机型：威胁必须在下章真的落地，喊出来又不发生的威胁掉价。
- 截断型：断在动作与反应之间；动作要具体，反应要过火，答案本章不给。
- 抉择型：两个选项都要付代价，无代价的选择不构成两难；章尾不公布结果，但要让读者替角色算得下去账。
- 留白型：只写反应与动作，不写发生了什么，信息靠读者补全。
- 回声型：章尾复现章首的句子或细节，但关键处已经变了。
- 系统激活型：落在主角最低谷处，先给一处感官异常再亮出系统提示，让能力登场本身成为期待。
- 选择型：把奖励与代价一并摆出，停在未选之处，让读者替角色权衡。
- 预知型：主角冷静面对眼前的嚣张，只预告反转将至，不透露怎么反转。
- 时间跳跃型：给一个时间标记直接落到结果，过程留白，用结果的反差制造追问。
- 预告型（收获／反派／行动）：只暗示即将到来的东西，不写结果，且预告之物须在数章内兑现。
- 收在反应上时，反应力度要与身份相称：有分量的人一皱眉就够了，喊出来的愤怒反而把筹码喊没了。

### 铺垫与期待蓄势
- 打脸前先备好道具、人物、实力；前置不足，读者只会替主角担惊受怕，嘲讽变成虐主。
- 铺垫重于打脸：铺垫到位，主角不开口也成立；打脸只是最后一击。
- 打脸对象的层级决定爽感层级：路人震惊不算爽，有分量的人震惊才成立。
- 旁观者的议论用来抬高对手分量，为打脸蓄势；对手嚣张到读者恨，打脸才解气。
- 铺垫期每章仍要有新信息与进展，不让读者觉得在原地等。

## 自检清单

- [ ] 章尾给的是期待不是总结，且本章的账已在本章内结清
- [ ] 钩子指向主线进程，不是可随手摘掉的枝节
- [ ] 钩子强度与本章所处阶段匹配，日常章没有硬塞强钩
- [ ] 相邻两章没有用同一种钩法
- [ ] 上章的钩子在本章开头已被回应或推进
- [ ] 章首尽早出现行动、异常或未闭合期待，未按固定位置卡点
- [ ] 章尾没有靠重复解释或回顾凑篇幅，落点由信息复杂度决定
- [ ] 此前发出的钩子已在数章内兑现，没有挂空账
- [ ] 危机型的威胁在下一章真的落地，不是喊完就没
- [ ] 抉择型的两条路都付代价，读者无法一眼选出
- [ ] 揭示与留白型只给碎片和反应，没有提前交代结论
- [ ] 打脸前的道具、人物、实力已备好，不靠读者替主角担心
- [ ] 换章、换卷处的未闭合期待已明确移交
- [ ] 章尾句有具体画面或动作，不是抽象概括
