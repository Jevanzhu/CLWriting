# 情绪引擎速查

用于设计连载的情绪配比与循环：把期待、焦灼、释然、爽感、虐感写成「押注—偿还」工序，维持感情线、成长线、复仇线等长线的张力。与本书大纲、账本、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 读者说平淡、追不动 | 先补情绪发动机因果链，不是加事件或加描写 |
| 虐了几章没有回报，评论区喊弃文 | 情绪债清账：押注有没有可见偿还与偿还时点 |
| 情绪很激烈，读者却不心疼 | 回查羁绊是否具体，缺口是否押在读者在意的对象上 |
| 转折用尽全力，读者反应寥寥 | 转向缺触发事件，或铺垫厚度撑不起这次撕裂 |
| 收益来得太容易，读者说不真实 | 契约护栏四问：收益是否由主角自己的选择挣得 |
| 越写越空、后面没得用 | 检查终局底牌与升级线是否已被提前透支 |
| 单元尾没劲、读者从这里走 | 意义变化与可见兑现是否落在本单元内 |
| 前后像两篇故事 | 长线情绪命题复现，加伏笔、物件、主题贯穿 |
| 反转之后还在反复交代 | 收束速度是否与题材、篇幅适配 |
| 读者抱怨吊胃口、说注水 | 旧期待只付利息未还本 |
| 角色关键时刻出戏 | 人设即行为缘由，不为意外崩人设 |
| 结尾看完就忘 | 余韵钝痛：日常动作、旧物细节、「不」留白 |

## 法则清单

### 情绪债务（押注与偿还）
- 每个单元先立核心情绪命题，再答三问：押了什么、何时还、拿什么还；三问答不全，单元不开。
- 押注＝读者的情绪缺口与承载对象；先选定承载对象（人物 / 关系 / 目标 / 规则 / 场景），读者才知道该为谁揪心。
- 因果链闭合：情绪命题 → 承载对象与缺口 → 缺口为何维持 → 本轮触发 → 主角不可替代的转化动作 → 意义变化或可见兑现 → 题材契约兑现。
- 不要求每个题材都有长期受阻、最终画面或克制反应；不适用的环节写「无 / 即时」，但链不能断开。
- 偿还＝可见兑现：收益必须经主角自己的选择挣得；无交换地拿走收益，或长期只给情绪不给结果，都算赖账。
- 旧期待要还本：反复吊着只给小甜头、不给结果，久了读者判定注水。
- 终局底牌与升级线是情绪额度的上限，提前动用即透支后续单元。

### 受阻与张力维持
- 先答「为何此前没有被直接解决」，再写这一轮为何能推进；受阻越具体，焦灼越实。
- 合理性五问截漏：为何是它、为何是现在、为何此前悬置、主角凭什么介入、设定边界如何约束；用来堵巧合式工具人与突然变蠢的机构。
- 情绪转向必须有触发事件，不允许无理由变调；最后一次转向决定结尾余韵的基调。
- 爽感靠反弹速度与密度，虐感靠铺垫厚度；爽文可快速反弹，虐文须更长铺垫，两者不共用一种配比。
- 悬疑的焦灼来自信息差：读者知道而角色不知道，或角色知道而读者不知道，不是含糊其辞。
- 动机揭示顺序：先揭示做了什么，再揭示为什么做。

### 长线情绪线
- 长线靠同一情绪命题反复复现：每轮可换承载对象与场景，命题本身不换。
- 单元之间用伏笔、物件、主题贯穿，保证越写越像同一个故事。
- 主角的介入动作须不可替代；换个人来做同样成立，这轮情绪就与主角无关。
- 复仇线：人物关系保持清晰，不铺复杂世界观；最大底牌留到后段集中揭示，打脸直接不拖泥带水。
- 感情线张力来自反复试探：不确认心意的拉扯里，每次都要读得出「甜」与「涩」两种。
- 亲情线不站队，展示双方的苦；和解不急，先让双方充分受伤。

### 三板斧（情感题材可选技法）
- 羁绊铺设用具体数字给时间感、具体物件承载感情、重复动作成习惯；「他们很相爱」这类抽象描述等于没铺。
- 撕裂三法：反差（先暖后碎）、错位（以为在保护实为伤害）、延迟真相（在读者最不期待处揭示）。
- 撕裂的力度取决于羁绊的厚度；铺垫不够的撕裂是无根之木。
- 余韵钝痛：用日常动作承载巨大情绪，用旧物细节回收，用「不」（不解释、不回头、不流泪）留白。
- 强情绪来自具体投入、受阻延迟、意义变化、可信反应等机制的组合，不来自堆叠死亡、疾病与哭喊。
- 克制反应与锚点复现（同一物件 / 动作 / 台词）是可选放大器，复现频率随篇幅与读者记忆需求调整，不强制固定次数。
- 三板斧只对部分情感题材成立，是可选技法不是硬模板；冲突时以因果链引擎为准。

### 失败模式与修正
- 太平：长时间没有情绪转折 → 插入意外事件或新信息，而不是加大描写力度。
- 太赶：重大转折缺可辨认的铺垫 → 按转折重量给足够且可辨认的铺垫。
- 假虐：读者不心疼只是难受 → 回查羁绊是否具体、缺口是否押对对象。
- 割裂：前后像两篇故事 → 用伏笔、物件、主题贯穿。
- 烂尾：反转后长时间重复交代 → 按题材与篇幅适配的速度收束或冷却。
- 人设崩：角色关键时刻行为不符前文 → 行为逻辑一致优先于意外性。
- 护栏≠发动机：没踩红线只说明「安全」，不代表好看；诊断完护栏要回头补发动机。

## 自检清单

- [ ] 每个单元能一句话答出「押了什么、何时还、拿什么还」
- [ ] 因果链闭合，缺省环节已显式标注「无 / 即时」
- [ ] 本轮兑现由主角自己的选择挣得，没有无交换拿走收益
- [ ] 旧期待有还本动作，不是只靠付利息吊着
- [ ] 未提前动用终局底牌，升级线未顶到天花板
- [ ] 羁绊用具体数字 / 物件 / 习惯落地，没有抽象抒情式关系描述
- [ ] 每次情绪转向都能指出触发事件
- [ ] 长线情绪命题在多个单元复现，且承载对象有更换
- [ ] 单元之间有伏笔 / 物件 / 主题贯穿
- [ ] 结尾基调与题材匹配，最后一次转向与之同向
- [ ] 撕裂之前有可辨认的羁绊厚度，没有凭空撕裂
- [ ] 结尾用安静细节收，不是大段抒情
- [ ] 六种失败模式（太平 / 太赶 / 假虐 / 割裂 / 烂尾 / 人设崩）均已排查
- [ ] 护栏诊断没有代替发动机设计
