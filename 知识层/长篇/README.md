# 长篇

长篇（连载）专属语料：章节钩子、反转机制、悬念编排、节奏与升级感、情绪引擎、
核心梗与卖点、开篇设计、大纲方法、题材框架与长篇质量清单。

通用的方法（人物 / 对话 / 情绪 / 结构）在 `通用/`，本类目只收连载独有判据，
不写短篇默认值（单章闭口、一篇一反转那类口径在 `短篇/`）。
篇目与注入面由 `src/knowledge/catalog.ts` 声明。

素材以「精选速查版」改写自外部 MIT 项目（oh-story-claudecode），每篇 front matter
带 source/source_ref/license，许可全文见 `许可/`。

## 现有素材（10 篇）

| 素材 | 用途 |
|---|---|
| 章节钩子速查 | 章首章尾选钩法、定强度、定落点与跨章承接 |
| 反转机制速查 | 反转选型、埋线与误导、揭示时机与兑现、打脸节奏 |
| 悬念编排速查 | 悬念层级与嵌套、信息差、兑现与延期、多线交织 |
| 节奏与升级感速查 | 阶段节奏、升级感表达工序、期待值管理 |
| 情绪引擎速查 | 长线情绪配比、情绪债务与偿还、张力维持 |
| 核心梗与卖点速查 | 核心卖点定义、高频复用与保鲜、稀释与跑偏修正 |
| 开篇设计速查 | 开篇要立起的三件事、切口选择、失效形态与修改工序 |
| 大纲方法速查 | 从一句话主线到大纲的推演工序、层级边界、失效回修 |
| 题材框架速查 | 题材构成要素、骨架配置、金手指匹配、迁移与错配修正 |
| 质量清单速查 | 连载稿审读逐项核对（主线卷结构 / 连续性 / 人物 / 卖点守恒） |
