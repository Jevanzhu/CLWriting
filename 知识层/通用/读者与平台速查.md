# 读者与平台速查

用于选题与定位：读者深层需求、题材生命力、平台适配、题材边界、代入感、书名与简介。与本书选题案、目标平台样本冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 判断题材还有没有红利 | 生命力三阶段：先用目标平台近期样本定阶段，再定策略 |
| 不清楚读者到底要什么 | 读者画像 → 深层需求：先定位读者，再设计情绪 |
| 同一题材要换平台 | 平台重校准：驱动元素、节奏、雷点全部按目标读者重定 |
| 拿不准素材撑不撑得住 | 边界感判定：有边界感按成熟受众写，创新则降篇幅与创新数 |
| 要定书名 | 先选命名公式，再按目标平台命名口径筛选 |
| 要写简介 / 文案 | 先定类型，再叠组合，最后查安全感与钩子 |
| 读者说不爽、不入戏 | 查代入感与塑料感：主角能否被投射、世界是否自洽 |

## 法则清单

### 读者与深层需求
- 先定位读者再设计情绪：能一句话说出目标读者是谁、现实中最缺什么。
- 从爆款反推：提炼核心剧情元素 → 框定读者画像 → 推测心理需求 → 对照读者真实生活验证。
- 主情绪必须一以贯之；多头并行、情绪散乱是扑街信号。
- 小情绪（升级 / 复仇 / 寻宝）统一到主情绪之下，不各说各话。
- 情绪根源是「不公平」与「为什么」；写出区别对待，愤怒自然产生。
- 深层需求落在被认可、被理解、被尊重；「打脸」只是外壳，不是目的。
- 情绪需求越深，作品天花板越高；只做表层爽点则上限低。
- 特别留意「外人觉得剧毒、核心读者痴迷」的元素——那是该题材的真实需求。

### 题材生命力与边界
- 生命力按样本判断，不把历史经验当当前事实。
- 先定阶段：新鲜期 / 成熟期 / 审美疲劳期。
- 新鲜期优先提炼创意方向；成熟期稳交付边界期待；疲劳期必须给新切入点。
- 阶段确认不了时按成熟期处理：保守满足边界期待，微创新不超过 3 处。
- 跟风只复用结构功能位，不复刻剧情内容。
- 有边界感 = 受众成熟、写法有迹可循，适合稳定交付。
- 无边界感 = 受众不确定、写法待探索，风险高，须降篇幅与创新数量。
- 历史题材以读者为第一要素，不以真实为第一要素；立场须一贯，摇摆即割裂。
- 历史人物评判跟随当下主流共识，不逾越。
- 爽感阈值要管理：前期升级过快，后期难以为继。

### 平台适配
- 同一题材换平台须重写，不能拿 A 平台样本套 B 平台。
- 用目标平台样本校准读者期待、节奏与雷点，确认该题材在目标平台仍有反馈。
- 按读者筛选成本定节奏：筛选成本高可慢热，筛选成本低须开头直给强情绪。
- 平台口径随规则与榜单变化，一律以当前规则和用户要求为准，不引用旧结论。

### 代入感与塑料感
- 代入感与爽感高度重叠：代入感低，主角做什么读者都不觉得爽。
- 去塑料感 = 让世界像真实存在的世界；设定自洽、画风统一，不做「仙侠搞科研」式撕裂。
- 设定越贴近主角生活与职业，越容易代入。
- 例外：搞笑 / 梗文核心是「有趣」，爽感居次，可用旁观者视角，不强求代入。

### 金手指
- 金手指必须与主角生活、职业相关：医生配医术合理，医生配隐身牵强。
- 一个技能能升级、能衍生多种效果，不要频繁开新金手指。
- 金手指挂在主线上；与主线无关的设定会写丢。

### 书名与简介
- 身份法：高位身份 + 反差行为；戏剧身份对照：低位替高位做超出预期的事。
- 其他公式：掉马甲型、逼格起名法、反义词法、主线 + 爽点法。
- 书名须与内容贴合，货不对板会劝退；同质样本过多时慎用同一公式。
- 简介五型：四段式成功型（最通用）/ 三段式行动型（留悬念）/ 二段式悬疑型（制造好奇）/ 四段式失败型（虐感）/ 三段式成功型（轻快）。
- 组合：成功型 + 悬疑型 = 安全感 + 好奇；行动型 + 成功型 = 先期待再满足；失败型 + 悬疑型 = 虐后留悬念。
- 简介至少暗示主角会成功；悬疑不宜叠太多，太「谜语人」会看不懂且安全感不足。
- 文案须体现主角主体性，主体性差会拉高流失风险。

### 自嗨与商业化
- 私人表达占比极低，且不得打断叙事节奏。
- 商业化不是故意恶心读者；私人表达必须服务核心卖点，不独立于主线。

## 自检清单

- [ ] 能用一句话说出目标读者是谁、现实中最缺什么
- [ ] 题材提供的核心情绪对位读者深层需求，不是自嗨
- [ ] 已用当前样本确认题材阶段，未把历史热度当当前事实
- [ ] 写法已按目标平台调整，不是拿别处经验硬套
- [ ] 当前素材、知识储备与篇幅能支撑所选题材
- [ ] 书名在目标平台命名口径内，能快速传递核心卖点或钩子
- [ ] 简介类型选择正确，既有安全感又留了钩子
- [ ] 世界观自洽、画风统一，无「仙侠搞科研」式撕裂
- [ ] 书名、简介、正文三位一体
- [ ] 金手指与主角职业、生活相关，且挂在主线上
