# 情绪弧线速查

用于选情绪弧线与管期待：弧线选型、中段加压、期待维持、情绪落纸。与本书大纲、账本、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 虐完翻盘 | V 形：谷底压深靠后，治愈急速回升，结尾高于起点 |
| 甜完刀死（BE） | 倒 V 形：高点前置，坠落快于上升，结尾不加糖 |
| 多反转猜不到 | W 形：每峰高于前峰，峰谷之间留喘息 |
| 层层打脸升级 | 递进形：无回落，中间只给小胜，最高点留到末尾 |
| 隐忍后大爆发 | 延迟满足：前段压住，末段集中爆，爆发之后快收 |
| 结尾颠覆 | 急转形：转向本身要短，前文线索回看必须说得通 |
| 中段平、读者不疼 | 中段加压四手段：公开升级 / 双重背叛 / 代价加速 / 战略性沉默 |
| 爽点到了读者无感 | 调动不够：调动程度决定释放爽度，仇恨拉多满打脸才多爽 |
| 有目标但读者不关心 | 目标没转成期待；给目标接上「达成后会怎样」的预期 |
| 读者中途失焦 | 闭环一个期待时，下一个开环必须已经在跑 |
| 感情线平淡 | 无阻碍即无期待；用身份差距 / 家族反对 / 误会 / 使命冲突设鸿沟 |
| 怕人物写崩 | 读者未代入主角前，不把对手写得可怜 |

## 法则清单

### 弧线选型
- 弧线由「想要哪种情绪效果」定，不由题材定。
- 可叠加两种弧线，不超过两种。
- V 形：谷底要够深、转折要突然、治愈不拖，结尾情绪必须高于起点。
- 倒 V 形：坠落速度必须快于上升；BE 结尾不加糖。
- W 形：每峰比前峰高，峰谷之间必须有喘息空间，起伏数量设上限。
- 递进形：不许回落，像台阶一阶一阶上行；中间只给小胜利，不提前释放。
- 延迟满足：铺垫段每段都要有信息量与张力，不能无聊；压法要多样，爆发要密集。
- 急转形：前段先把假象立稳再急转，急转只占极少段落，埋的线索回看必须说得通。

### 中段加压
- 公开升级：把私下伤害搬到公开场合。
- 双重背叛：已知一层背叛后再加一层。
- 代价加速：不行动的代价不断升高。
- 战略性沉默：主角暂不反击，沉默本身持续加压。

### 期待维持
- 期待最大化：将满足而未满足的那一刻，是全篇张力最高的位置。
- 信息顺序即预期：先植入什么信息，读者就先往哪个方向想。
- 期待递增：在基底期待上不断添加具体化细节，细节必须与核心梗一致。
- 断期待禁止：旧期待兑现前，新期待的种子必须已经种下。
- 下行安全：写情绪下行时锅是别人的、功是主角的，并给出可能的解法或潜在收获。
- 爽点递增：连续爽点逐级加码，维度取影响范围、揭示深度、身份落差。
- 目标不等于期待：目标是角色要做什么，期待是读者对达成后会怎样的预期；有目标无期待等于读者不在乎结果。
- 确定型期待写「怎么赢」，不确定型期待写「结果悬念」；爽文不怕剧透，期待在过程不在结果。
- 开环提出问题，闭环揭晓答案；嵌套开环 = 闭环一个的同时开启下一个。
- 感情线没有阻碍就是白给，必须设鸿沟。
- 感情线两条进度线（情感、社会关系）不能齐头并进，落差就是看点。

### 情绪落纸
- 三层情绪分离：角色感受到的、文本要传达的、读者实际体验的，三者可以完全不同。
- 主公式：平静 → 调动 → 释放 → 爽；每个场景先标出读者情绪在哪一段、下一步是调动还是释放。
- 只有调动没有释放 = 读者憋屈弃书；只有释放没有调动 = 爽感平淡无力。
- 虐 / 悲壮场景走三步：前反应（先让读者预知坏结果，再写美好）→ 复现（坏结果发生）→ 后反应（主角真情流露并改变）。
- 热血 / 逆袭场景走四步：铺垫弱者的苦 → 强者到来 → 弱势方被拯救 → 整体气势转变。
- 「不该如此」是最根本的情绪驱动：想要爽必先不爽，想要公平必先不公平。
- 短期冲突比繁杂情节更共鸣；开篇必须用塑造人物性格的事件，先认同人，再关心事。
- 长期投入三步：抛共鸣锚点 → 让读者当见证者 → 让读者当参与者。
- 理念之争比利益之争更能引发深层共鸣；少量关键场景即可，用于抬高全书情绪上限。
- 优先用角色行为暗示情绪，必要的内心可直写；以乐写悲，张力比直接哭更强。
- 句长跟情绪走：紧张决断处用短句提速，铺垫沉淀处用长句蓄势；短句是提速工具，不是默认底色。
- 情绪词制造紧迫，动作词外化情绪，形容词精准克制、不堆砌。

### 长线维护
- 阶段结局不能太圆满——完美解决会杀死后续追读动力。
- 解决一个麻烦的同时，必须埋下下一个麻烦。
- 越到后期，情绪张力必须越大。
- 死亡赌注选一种贯穿全书（肉体 / 事业 / 心理）；主角过强时必须把赌注转为事业死亡。
- 对立双方必须有黏结剂，无法轻易脱身（杀人理由 / 职责 / 道德责任 / 场所）。

## 自检清单

- [ ] 弧线类型与想写的情绪效果对得上，叠加不超过两种
- [ ] 关键转折落在该弧线应有的位置，不在收尾处泄力
- [ ] 每个场景都标得出读者当前在调动还是释放
- [ ] 没有只有调动没有释放的段落（会憋屈弃书）
- [ ] 没有只有释放没有调动的段落（爽感平淡）
- [ ] 连续爽点逐级递增，影响范围 / 揭示深度 / 身份落差至少一项在加码
- [ ] 每个目标都已转成读者期待，不是干目标
- [ ] 闭环一个期待时，下一个开环已经在运行
- [ ] 感情线有阻碍，无阻碍的段落已改或已删
- [ ] 开篇用了塑造人物性格的事件
- [ ] 读者未代入主角前，没有把对手写得可怜
- [ ] 下行情节给了安全感：锅是别人的、功是主角的
- [ ] 转折与反转的伏笔回看说得通
- [ ] 解决一个麻烦时已埋下下一个麻烦
- [ ] 越到后期情绪张力越大
- [ ] 死亡赌注选了一种贯穿全书
- [ ] 对立双方有黏结剂，脱不了身
