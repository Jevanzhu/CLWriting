# 质量清单速查

写稿、审稿逐项打勾用：先按信号定位维度，再逐条核对。判断一律附证据与失败影响，不凭整体印象。

## 决策路由

| 信号 | 查哪个维度 |
|---|---|
| 这段能不能删、像不像水 | 叙事单元推进 + 节奏与水 |
| 读着平，像什么都没发生 | 场景与信息 |
| 满页设定解释、名词堆叠 | 场景与信息 |
| 开头几行抓不住人 | 开头与结尾 |
| 结尾像总结、翻不动页 | 开头与结尾 |
| 情绪靠形容词硬喊 | 情绪与兑现 + 语言与对话 |
| 人物说话都一个调 | 人物 + 语言与对话 |
| 读者说追不动了 | 情绪与兑现 + 节奏与水 |
| 前后对不上、因果跳步 | 连续性与逻辑 |
| 改稿不知先动哪 | 审读口径与修复取舍 |

## 法则清单

### 叙事单元推进

- 本单元至少改变目标、风险、信息、关系、资源、身份、情绪立场中的一项。
- 删掉它说不出因果、人物或期待损失的段落，判为填充。
- 结尾落在决定、发现、后果、关系变化或未完成动作上，不用总结代替变化。
- 推进强弱服从本书已建立的题材与兑现节奏，不套固定字数。

### 场景与信息

- 场景缺目标、缺阻碍、缺状态变化中任何一项，即为扁平场景。
- 设定跟着行动、冲突或证据出现；成片集中解释即是说明文。
- 人物在选择、行动、承受后果；连写数段同一种感觉就是空转。
- 新概念数量与该场理解负荷匹配，必要概念给可验证的使用边界。

### 人物

- 动机、行动与已立人设冲突时，补可见触发或将行动改回人设，不放过无因转向。
- 关键行动偏离性格时，要么补足原因，要么调整行动。
- 配角要有自己的目标与行动线，不能只作主角的布景。
- 对手的分量与本阶段主角的筹码匹配，过弱无压力，过强失真。

### 情绪与兑现

- 情绪落到选择、台词、物件或实际后果上；直写更准就直写。
- 情绪对等释放：压了多少给多少回报，只压不给则期待流失。
- 读者等待的问题要按期兑现，或给出新的等待；长时间悬空即毒点。
- 契约四问：结果靠主角自己的选择挣来吗；核心收益与高光有没被配角、机构或巧合无交换拿走；有没提前动用本阶段不该解锁的底牌；旧期待付了利息又留了新期待吗。
- 兑现后允许短暂低压与可见小收益，不必机械立刻加新危机。

### 语言与对话

- 对白要改变信息、策略、权力、关系或下一步行动；删掉后场景无变化即无效。
- 说话方式区分身份、关系与现场权力位置，遮住名字仍能认出是谁。
- 同一句式成片、套路修辞与堆叠的身体反应，都是 AI 腔信号，删无功能的，留角色化的。
- 标题行以外不混入写作工程元信息；叙事内真实语境除外。
- 抽象情绪要有支撑；为显得精致而加的词句是负担，不是文采。

### 节奏与水

- 通篇对话无新信息、同一情绪写多段、回忆不给新视角、流程细节删掉无损，皆为水的信号。
- 长期没有冲突、压力或进展，读者就会走；慢热不等于不动。
- 低压与过场要克制，各自至少留一个「想知道后续」的点。
- 卡点要卡出变化；卡完无状态改变，就压掉流程、留下结果。

### 开头与结尾

- 开篇不从天气、风景或日常垫场起手，用钩子、异常或当前目标切入。
- 开篇尽早让主角出场，并让卖点或危机可见。
- 有钩子不等于不同质：整段能原样搬进同题材任意一本书，就是同质化。
- 结尾是具体动作、对话或画面，不是总结与反思。
- 结尾要拉住翻页：给危机、决定、发现、反转中至少一项，或留下余韵。

### 连续性与逻辑

- 设定、时间线、角色已知信息与证据链必须闭合；「原因→行动→结果→后果」断在哪补在哪。
- 角色不得知道自己无从得知的事；证据不足时标注疑点，不替作者补设定。
- 已立承诺与伏笔必须有推进；不推就回收、延期留痕或明确弱化。
- 新设定、新地图、新谜团不得用来逃避旧承诺，也不得一次性倒出。
- 故事引擎须持续运转：读者追的那条线不能停摆。

### 审读口径与修复取舍

- 每条判断附证据与失败影响；说不出影响就别下结论。
- 按严重度排序修：契约、因果、事实不成立先修；明显损伤追读与人物可信度的本轮修；局部拖慢按收益修。
- 可增强项只作提示，不得包装成硬性门槛。
- 先核对情节点是否都写到；都写到了，就不为凑字数加戏。
- 结构性崩坏（核心冲突、动机、因果链）重写相关段落；小问题打磨语言。

## 自检清单

- [ ] 每段至少改变七类状态之一，且通不过删除测试的段落已砍
- [ ] 场景都有目标、阻碍与结束后的状态变化
- [ ] 无成片设定说明文，新概念负荷不过载
- [ ] 人物在做事而不只是感觉，情绪有落点
- [ ] 不同角色说话能区分，对白删掉后场景会变
- [ ] 正文无写作工程元信息，无堆叠的修辞与身体反应
- [ ] 低压与过场克制，没有长期无冲突、无进展
- [ ] 开篇不从天气日常起手，主角与卖点或危机都露出
- [ ] 结尾落在具体动作 / 对话 / 画面上，不是总结
- [ ] 伏笔有推进，因果链闭合，角色知识不越界
- [ ] 期待按期兑现或给出新期待，收益未被无交换拿走
- [ ] 判断都附了证据；修复按严重度排序，提示项未当门槛
