# 人物设计速查

用于设计角色：反差点、人设功能分层、配角与群像、关系与感情、代入感与安全感。与本书人设档、大纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 角色扁平、读者记不住 | 三层标签反差：身份 / 表现 / 内核，内核层必须反转 |
| 要写出「亮牌时刻」 | 反差越大越震撼；用行为对比呈现，不靠旁白描述 |
| 关系升温后角色变味 | 行为反差进阶：亲密期做不出陌生期做得出的举动 |
| 角色只有身高爱好 | 人设 ≠ 人物设定表，重做成以人格驱动行为的功能性设计 |
| 人设撑不起剧情 | 补强关联设定——直接推动剧情走向与核心爽点的那几项 |
| 辨识度低、画面发飘 | 六维反差里选一到两个维度贴标签 |
| 角色像工具人 | 先定功能再定性格；配角功能化 + 脸谱化标签 |
| 配角抢戏 | 压光环不超过主角；功能性配角不强行立体化 |
| 要写高情商 / 聪明人桥段 | 靠临场表现写，每个桥段至少一次「以为会尴尬却化解」的反转 |
| 要写感情线 | 人设关系四阶段：相遇 / 相识 / 相知 / 相恋 |
| 人设飘、前后不一 | 开头就交代清楚，转变前后一致，不「又当又立」 |
| 读者改用现实逻辑评判 | 情感链条已断，查破坏代入感的四种行为 |
| 紧张感被冲淡 | 靠山过度：撤掉能随时解决危机的强力靠山 |
| 该深化故事还是深化人设 | 主线太复杂 → 向人设深化；人物够鲜明但事件不足 → 向故事深化 |

## 法则清单

### 三层标签与反差
- 三层：身份标签（外界看到的身份）→ 表现标签（展现给外界的行为）→ 内核标签（真正的内心）。
- 身份与表现可以相似以强化刻板印象，内核必须反转；反差即立体感。
- 每个重要角色至少有一层反差，且必须落到行为对比上，不写成描述。
- 关系进阶后行为退化 = 感情深化：进入亲密期反而做不出早期举动；若仍维持早期行为，反差失效。

### 人设的功能性
- 人设是为戏剧张力服务的功能性设计：以人格驱动行为，不被剧情硬推。
- 关联分三层：强关联直接影响剧情走向与核心爽点（每个角色至少三个），中关联给配角功能与辨识度且不抢主角风头，弱关联只添厚度、不得喧宾夺主。
- 六维反差任选一到两个：表面性格 / 内在性格、外表 / 表面、外表 / 内在、身份 / 生活方式、身份 / 爱好、身份 / 内在。
- 读者记住的是标签不是外貌——美貌是最廉价的资源，别在容貌上花大笔墨；性格可极端化，但设定后言行始终一致。
- 记忆点：每人至少一个特质特别突出，突出到人物纯聊天读者也愿看。
- 模糊标签（如「热血」「杀伐果断」）撑不起角色，换成可复现的具体梗才有强记忆点。
- 反差不等于越大越好，尺度失控会筛掉读者。

### 配角与群像
- 配角的能力与特质必须与剧情紧密相关；配角之力为主角所用，配角脱困靠主角。
- 白手套型配角接下主角不便做的事：替说话、替发狠、坚决维护、粗中有细、适时搞笑。
- 配角光环弱主角一点，惊艳出场，对主角的质疑第一时间反驳。
- 先判功能性再决定要不要立体化：功能性配角保持扁平与神秘反而更强大，不必人人立体。
- 每个角色出场都要有功能，功能不明确的角色不要出场；关系要有层次（引路人 / 对手 / 伙伴 / 障碍）。
- 不同角色要有不同的说话风格与行为特征；脸谱化抓一到两个突出特点立标，不占笔墨。
- 高人气角色出场留间隔，每次出场必须带新信息或新功能；读者不感兴趣的角色自然下线。
- 以角色带角色：用已讨喜的角色牵出其亲友，各贴一个标签，角色池可续。

### 关系与感情
- 四阶段：相遇（只知外表，警惕设防）→ 相识（初步了解、不知底线）→ 相知（知秉性与底线，可交心）→ 相恋（知内心伤疤）。
- 关系结构按「职场」理解：在一个层级场域里爽透，再换到更大的场域。
- 任何场域都同时存在层级（上下）、互助（同级合作）、互害（同级倾轧）三种关系。
- 感情桥段用察言观色、临场应变、控场接话的具体场景写，不用旁白夸赞。
- 用一个配角做期待枢纽：多条期待压在一人身上，每次收束都回到他身上起新一轮。
- 人物下线时给出更大好处，把读者的损失厌恶转成收益预期。

### 代入感与安全感
- 红线：节奏与情感链条不断裂；读者一旦改用现实逻辑评判情节，就是链条断了。
- 共情三层次：经历类似（表层）→ 情感类似（深层）→ 价值观一致（认同）。
- 情绪链按序推进：认同 → 同情 → 共鸣 → 共情，先满足再打击，落差才有劲。
- 让角色暴露弱点与困境，比展示强项更容易换来保护欲。
- 破坏代入感的行为一律避开：角色选择读者无法理解、大段设定说明打断叙事、节奏拖沓、主角三观偏离目标读者。
- 安全感需求随题材而定，先定题材再定靠山强度；紧张向题材的靠山不得削弱紧迫感，削弱即标记「靠山过度」。
- 精力有限时情节优先，世界观只是加分项。

### 主角与反派
- 金手指不只是给能力，更是让主角性格与行为合理化；用规则绑架行为，由配角反应侧写品格。
- 明确人设 = 筛选读者 = 预期管理：开头就交代清楚，转变前后一致，不「又当又立」。
- 主角可犯错，但只限不可抗力或信息差导致的；因蠢、因无底线善良、因实力身份不匹配而犯错，不可原谅。
- 反派 = 立场不同、利益相悖的人；给他自己的想法与追求，不写纯粹的恶。
- 表面与内心可设反差，增加深度与冲突可能性。
- 正戏反写：正面行为背后可藏反向动机；冷漠外壳下可藏深层情感驱动。
- 行为选择必须符合已建立的人设逻辑，否则即崩人设；成熟题材里经受住检验的标签人物可直接取用。

## 自检清单

- [ ] 重要角色有三层标签，且至少一层反差
- [ ] 反差靠行为对比呈现，没有旁白直述
- [ ] 人设是功能性设计，不是外貌爱好堆砌
- [ ] 强关联设定够用，弱关联未喧宾夺主
- [ ] 每个出场角色都有明确功能，没有水分
- [ ] 配角光环不超过主角，功能性配角未被强行立体化
- [ ] 不同角色的说话风格与行为特征可区分
- [ ] 每个角色至少一个记忆点
- [ ] 关系阶段与行为匹配，亲密期没有残留早期行为
- [ ] 主角的错误在可原谅范围内
- [ ] 反派有自己的逻辑与追求，不是纯粹的恶
- [ ] 言行前后一致，没有崩人设
- [ ] 感情桥段由具体场景展现，非旁白夸赞
- [ ] 代入感链条连续，未被设定说明打断
- [ ] 安全感与题材匹配，无靠山过度
