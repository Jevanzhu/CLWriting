# 通用

跨体裁通用的写作方法：情节推演、冲突结构、人物、关系、对话、情绪、技法、读者与质量口径。

长篇与短篇共用这些篇；体裁专属的判据（篇幅配比、钩子类型、升级节奏等）归 `长篇/` 与 `短篇/`，
本类目不写档位默认值。篇目与注入面由 `src/knowledge/catalog.ts` 声明。

素材以「精选速查版」改写自外部 MIT 项目（oh-story-claudecode），每篇 front matter 带
source/source_ref/license，许可全文见 `许可/`。

## 现有素材（9 篇）

| 素材 | 用途 |
|---|---|
| 情节推演速查 | 主线定义、小纲细纲、高潮构建、卡文自救与节奏控制 |
| 冲突结构速查 | 矛盾设计、结构方法、冲突与对抗线 |
| 人物设计速查 | 人设构建、标签反差、配角功能化 |
| 人物关系速查 | 关系网、感情线、好感度节奏 |
| 对话技法速查 | 权力博弈、潜台词与议程、对话节奏 |
| 情绪弧线速查 | 弧线选型、中段加压、情绪落到纸面 |
| 写作技法速查 | 情绪落地、贯穿道具、场景与句式 |
| 读者与平台速查 | 读者心理推演、题材适配、平台选择判据 |
| 质量清单速查 | 多维度的逐项核对清单 |
