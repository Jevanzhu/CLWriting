# 文风与格式速查

用于改稿时判断正文的格式与声线取舍：段落怎么断、对话怎么写、标点怎么用。与本书文风铁律、
章纲冲突时以它们为准。**本档只收判断面**；可判定部分（markdown/缩进/工程词的机检）在
`src/check/body-format.ts`，两侧互指。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 段落长到读起来闷 | 戏剧单元优先：一段 = 一个完整的发生/感知/反应单元的展开 |
| 每段都 3-5 行，像排版 | 段落节奏：长短交错、疏密有别，不按字数硬拆 |
| 对话读起来像书面报告 | 对话规则：真人有打断、有答非所问、有说半句 |
| 满篇句号，标点单调 | 标点跟语气走：该质问用问号，该爆发少量感叹 |
| 段落之间出现空行 | 段落间只允许一个换行（本书正文格式契约） |

## 法则清单

- **一段 = 一个戏剧单元**：判断该不该分段，看这段是否还是一个完整的单元（同一动作链、
  同一段推理、同一缕氛围）。混入多个动作/信息/视线切换才拆；完整推理与情绪链可稍长。
  不按字数硬拆——「超过 N 字就分段」是排版，不是写作。
- **段落节奏**：长短交错，疏密有别。连续多段同一个长度会读起来像说明文；
  该密处（高潮/冲突）短句短段，该疏处（沉淀/氛围）可以长。
- **对话标记的取舍**：普通「说」可以保留，不必句句换动作标签；高频或公式化的
  「他笑了笑说」才用动作/上下文替代。对话标签占比过高是机器味信号（机检有该项）。
- **对话内容**：真人说话不做完整汇报——答非所问、打断、说半句、把话咽回去都正常。
  但停顿与口误要服务人物身份与情绪，不当「真人感」装饰批量添加。
- **标点跟语气走**：该质问就用问号，爆发峰值少量感叹，不把全篇改成句号；
  也不无功能地乱撒问号感叹号。犹豫、没说完，优先用动作、短句或换行承担，
  而不是靠省略号硬造停顿。
- **段落间不空行**：正文相邻段落之间只有一个换行符。空行会让正文排版散开，
  也让「段落」这一单位失去意义。
- **不做无功能的加粗**：正文段落里不用 `**` 加粗、不用斜体、不用行内代码、
  不用列表与引用——正文是纯叙事文本，强调靠句子本身承担。
- **不缩进**：段首不缩进（不用全角空格或空格起行）——缩进是纸媒体排版习惯，
  在编辑器与导出场景里都会带来对齐问题。

## 自检清单

- [ ] 每一段是否还是一个完整戏剧单元？有没有硬按字数拆出来的碎段？
- [ ] 段落长度有没有明显交错？还是连续多段一样长？
- [ ] 对话是否句句完整、逻辑精准到像汇报？
- [ ] 标点是否跟语气匹配（该问就问、该叹才叹），还是通篇句号？
- [ ] 段落间有没有空行？段首有没有缩进？正文里有没有加粗/斜体/列表？
