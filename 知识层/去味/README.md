# 去味

去 AI 味的判断类知识：AI 味识别（解释腔、电报体、伪自然）、文风与格式的取舍判断。

**可判定**的部分归代码，本目录只收判断面——两侧互指：

| 面 | 语料（判断） | 代码（判定） |
|---|---|---|
| AI 味识别 | `去AI味判断速查.md`（解释腔四型 / 删除测试 / 改写顺序 / 删过头自检） | `src/check/ai-patterns.ts`（套话词表 + 套路句式正则）；`src/check/body-format.ts` 的套话与套路句式两项 |
| 文风与格式 | `文风与格式速查.md`（戏剧单元优先 / 段落节奏 / 对话取舍 / 标点谱系） | `src/check/body-format.ts`（markdown / 缩进 / 写作工程词三项机检） |

两篇的注入面声明为 `faces: []`（不下发）：改稿链当前只在 system prompt 带词表约束
（`aiClicheRule.toPrompt`），尚未接运行时语料注入；两篇先作为判断面正本与作者参照在位，
接线归后续批。

**不含时效数据**：平台格式偏好表、样本统计一律不入（长期语料只收方法）。
