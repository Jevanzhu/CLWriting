# 段落钩子速查

用于短篇写段与段的推进：定段尾落在什么信息上、定段间怎么接、定节奏密度与对话 / 动作切换的落点。与本文细纲、人物设定冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 段尾收在总结句上，读者没有下一步预期 | 段尾落点：本段信息本段结清，段尾只留一笔未闭合 |
| 上一段留的口子，下一段开头没接 | 段间承接：紧邻下一段先回应或推进 |
| 段里挂了三个悬念，一个也没记住 | 段间承接：每段只留一处未闭合 |
| 连续三段都在交代背景，读着像滑冰 | 节奏与切换：交代拆进动作与对话 |
| 段落越来越平，读者猜得到走向 | 段间承接：相邻两段换一种落法 |
| 威胁抛完就没事，后面靠巧合收 | 禁忌：假悬念 + 机械降神 |
| 埋下的牌藏太久，读者忘了 | 段尾落点：兑现要在读者还记得时 |
| 冲突对话不升级，读着没劲 | 对话落点：按不礼貌度递进，收在最不客气的一句 |
| 主角委屈写足了，读者却不出气 | 张力来源：不公平伤害，用他人否定代替真委屈 |
| 段尾写「全场震惊」，读着空 | 落反应：落到有分量的具体角色身上 |
| 动作段与对话段之间切换生硬 | 节奏与切换：切换点落在具体动作或台词上 |
| 倒计时给了期限，后面没有兑现 | 段尾落点：期限须在篇内到期 |

## 法则清单

### 段尾落点（这一段的最后一笔落在什么信息上）
- 本段要交代的信息在本段内交代完；段尾只负责把读者送进下一段，不替下一段攒内容。
- 信息差型：落在「读者已知、场面内无人知晓」的信息上，读者为角色的不知情悬着。
- 反转型：落在与前面预期相反的事实上；反转要先有铺垫，无铺垫的反转是作弊。
- 倒计时型：落在一个明确期限上；期限一旦给出，必须在篇内到期兑现。
- 代价型：落在主角将要失去的东西上；主角最后什么都没失去，代价钩子失效。
- 暗牌型：落在主角按兵不动的动作上，同时让读者记得他手里还有牌没打，亮牌要趁读者还记得。
- 打脸型：落在「对手正在得意、读者已知证据在手」的落差上；打脸一句收住，不铺开解释。
- 弱者在场型：落在需要被保护的弱者身上；弱者要有自己的行动，只被救不行动的弱者撑不住共情。
- 异常物件型：落在不该出现在这里的物件上，让读者追问它为什么在这里。
- 假意顺从型：落在主角主动交出对手想要的东西上；对手误判，读者等的是他接住之后的反噬。
- 冷静发现型：落在「平静动作与异常事实」的并置上，冷静本身就是悬念。
- 限制视角型：落在「只能看、不能动」的限制上；限制执行得越严，读者越替主角着急。

### 段间承接
- 上一段留的口子，紧邻下一段的开头就要接住：回应、推进，或先让代价落地。
- 承接可以先给反应与动作，把结果往后挪一步，这是留悬念，不是拖。
- 每段只留一处未闭合；一段里挂两三个悬念，读者一个都记不住。
- 相邻两段换一种落法；同一类落点连用，读者就会开始猜得到走向。

### 节奏与切换
- 一段只落一个信息点；一段里塞两个转折，两个都会被读丢。
- 交代与场面交替来；连续几段纯背景说明，读者会滑走，把交代拆进动作与对话里。
- 段落长短随信息量走：重信息用短段，过渡处也不要堆成长段。
- 动作段与对话段的切换点，落在具体动作或具体台词上，不落在总结句上。
- 动作段的段尾停在动作未完成的瞬间（抬手未落、门将开未开），比停在完成之后有拉力。
- 安静的段落可以慢，但不能没有落点：段尾至少落一个人物的决定或态度变化。

### 对话落点
- 冲突对话按不礼貌度递进：陈述事实 → 提建议 → 主观指责 → 指责加命令 → 指责兼踩人抬己。
- 段尾落在最不客气的那一句上，比落在辩解与解释上有劲。
- 情绪最强的话术是「为你好」：句句关心、句句嫌弃，读者替主角憋的那口气才憋得住。
- 段尾落在对话上时，落在改变关系的那一句，不落在补充信息的那一句。

### 张力来源（不公平与代价）
- 段落要有往下读的拉力，最省力的来源是「不公平 + 伤害」：主角无辜，却同时受物理与精神两重伤害。
- 精神伤害比皮肉伤害更能拉动情绪；大多数读者受气的时候多。
- 伤害的重点在「不均」：大家一起倒霉、唯独主角被多扣一份，比一律变难更让人恨反派。
- 压主角要克制：能用「他人否定、主角打脸」，就不用「主角真受委屈」，真委屈只在关键处用。
- 否定要间接化、理由要合情理、否定者要多元：当面嘲讽改成背后议论，不同立场用不同方式否定。
- 反派动机越具体，段落里那份不公平越可信：转嫁代价、嫁祸脱身、报复秩序被破，各有各的行事方式。

### 落反应
- 段尾落反应时，落到具体人的具体反应上，不写「全场震惊」这类概括。
- 反应的分量由给反应的人决定：有分量的角色一个表情就够，群演喊破嗓子也不值钱。
- 让反应带上信息：围观者的话里要能带出身份、关系或后文走向，而不只是情绪。
- 熟人震惊优于陌生人震惊；同一场戏里让多种角色、多个层级各给一种反应。

### 禁忌
- 假悬念：威胁不存在，或刚抛出就解除；读者被骗过一次，后面的悬念都不信了。
- 机械降神：段尾抛出的危机用巧合解决；危机要由前文给过的人与信息解决。
- 过度留白：连续多段不揭示任何信息，读者失去耐心。
- 低风险钩：拿无关紧要的事制造悬念，读者不上钩。
- 同类连用：同一种落点连着用，走向能被猜到，钩子就废了。

## 自检清单

- [ ] 每段的最后一句落在具体信息、动作或台词上，没有落在总结句上
- [ ] 相邻两段没有连用同一种落点
- [ ] 上一段留的口子，在紧邻下一段开头已被回应或推进
- [ ] 每段只留一处未闭合，没有一段同时挂着两三个悬念
- [ ] 段尾抛出的危机在后面真的落地，没有靠巧合收场
- [ ] 背景交代已拆进动作与对话，没有连续几段纯说明
- [ ] 动作段与对话段的切换点落在具体动作或台词上
- [ ] 冲突对话按不礼貌度递进，段尾落在最不客气或最能改变关系的那一句
- [ ] 段尾落反应时，给反应的人是有分量的具体角色，不是「全场震惊」
- [ ] 不公平的段落里，主角是无辜受伤害的一方，且伤害落在「唯独他」上
- [ ] 真委屈没有连篇累牍，能压成他人否定就不写主角真受气
- [ ] 藏起来的信息在读者还记得时亮出，没有拖到篇末才交代
- [ ] 倒计时类段落给出的期限在篇内兑现
- [ ] 全篇没有一处落到无关紧要的小事上制造悬念
