# 质量清单速查

用于单篇短篇交付前的逐项审读：开篇抓力、核心情绪兑现、反转可回溯、收尾闭合、篇幅内无赘段。清单只定核对顺序，不替代通读；与稿件实际呈现冲突时以稿件为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 开头几段还在交代背景 | 开篇抓力：首屏异常 + 问题留到后文 |
| 说不清这篇主打什么情绪 | 情绪单品：一词命名 + 逐场加码 |
| 读到中段觉得「散了」 | 主悬念唯一，副悬念只服务证据与情绪 |
| 反转被评「没想到但不服」 | 可回溯线索前置 + 误导信息本身为真 |
| 中间连续抬问题不给答案 | 每次延迟都要交付新证据或关系变化 |
| 删掉某段说不清损失了什么 | 删除测试：六项状态有无变化 |
| 后半程像换了另一个故事 | 第二议题须与开篇问题已有两处绑定 |
| 配角比主角先拿全答案 | 决定性发现与不可逆选择归主角 |
| 结尾像作者出面总结 | 收尾落到动作 / 物件 / 关系选择 / 可见后果 |
| 解释机关的解释段拖长 | 揭示与清算长度服从实际欠账 |
| 卡点靠「危险将至」撑场 | 卡点落在未完成动作 / 归属变化 / 身份异常 / 两难 |
| 审读意见一次列出十几条 | 同类症状合并到一个根因 |

## 法则清单

### 开篇抓力
- 首屏（开头数段内）必须出现一处异常、缺口或代价，且完整答案留到后文。
- 开篇的题材信号与后文兑现同色：承诺悬疑，就不在中段转成日常温情。
- 第一段让主角处在已经开始的动作或正在承受的结果里，不从背景介绍写起。
- 开篇的问题要能一句话复述，且这句话与结局的答案同属一个问句。
- 开篇占过读者注意力的人、物、信息，后文至少回响一次；不回响的当场删或改写。

### 情绪单品完成度
- 全篇核心情绪能用一个词命名（爽 / 痛 / 惧 / 暖 / 怒）；命名不出即尚未定型。
- 每个场景至少往核心情绪上添一笔；添不上又删不掉的，另派功能或删。
- 最大兑现一次到位，前有铺垫、后有后果；兑现贴到篇末、不留后果空间，等于没收。
- 中途可加压、反衬、暂缓，但不改情绪主色。
- 最大兑现的强度必须压过此前所有同类场景，持平即失效。

### 反转与证据链
- 每层反转前至少一条可回溯线索，且该线索首次出现时另有正当用途。
- 误导信息本身是真的，错的只是解释方向；靠假信息撑起的反转不成立。
- 第一层给出可信的阶段答案，第二层同时解释旧线索并翻转情绪判断。
- 证据分批释放，最后一批改变全局认知；批次多少由篇幅与题材定，不设统一数量。
- 证据链走「来源 / 实物 → 解释争夺 → 归属或责任翻转」的阶梯，每一级都要改变角色下一步行动，不能只补设定。
- 揭示后仍要有行动、关系或代价结算，不用大段独白把机关一次讲完。
- 后半程若出现更深的冲突或第二议题，它与开篇问题之间至少已有两处因果或证据绑定；绑不上就是换主线，不是升级。

### 人物与对话
- 每个决定性证据转折，都写明谁取得、谁验证、谁选择公开。
- 主角至少拥有一次决定性发现与最终不可逆的选择；一路被配角喂答案的稿子不成立。
- 反派 / 操盘者有独立动机，且动机在翻转前已可见；只为最后一翻改设定即失格。
- 主角的冷静、失控或强势来自人设与处境，不靠标志性端杯、转笔一类模板动作顶。
- 对话要么取证、要么改变权力关系、要么撕裂关系、要么制造信息差；四样都不沾的删。
- 对话密度服从题材与源文基线，不套统一配比。

### 篇幅与赘段
- 删除测试：抽掉一段后，「信息 / 关系 / 风险 / 目标 / 证据归属 / 情绪立场」六项无一变化，该段即赘段。
- 每场结束时状态至少与开场不同一项；原地打转的场景，功能已由别处承担。
- 每接一次延迟，都要交付新证据、误判修正、关系撕裂或局部反击，不能连续两场只抬问题。
- 同一种情绪、同一量级的冲突场景只留最强的一次，其余合并或删。
- 主悬念只留一个，副悬念只服务证据、误导或情绪代价，不扩成第二个故事。

### 收尾闭合
- 结局完成核心因果与情绪结算，不在最后一节另开新线。
- 收尾落到动作、物件、关系选择或可见后果；余韵不是作者出面总结。
- 反转后的解释与清算长度服从实际欠账，欠多少讲多少，不按固定字数配。
- 开篇的问题与结局的答案必须是同一个问句；答非所问即未闭合。
- 可以留回味，但不留核心缺口：留下的是余味，不是待解。

### 审读输出
- 每条阻断项 / 高风险项同时给出：可定位证据、失败影响、最小修法；方向确有分歧时再附一个可选替代。
- 最小修法要写清改哪一节、补哪条因果或挪走哪笔结算；「加强铺垫」「提升主动性」不算修法。
- 同类症状并到一个根因，不用问题条数冒充审读深度。
- 判据不达标就报，不因「整体还不错」把阻断项降级为建议。

## 自检清单

- [ ] 首屏有异常 / 缺口 / 代价，答案留到后文
- [ ] 开篇问题能一句话复述，且与结局答案同一问句
- [ ] 全篇核心情绪可用一个词命名
- [ ] 最大兑现前有铺垫、后有后果，不贴篇末
- [ ] 每层反转前都有可回溯线索，误导信息本身为真
- [ ] 证据链每一级都改变了角色的下一步行动
- [ ] 后半程的新议题与开篇问题至少已有两处因果 / 证据绑定
- [ ] 主角至少一次决定性发现加最终不可逆选择
- [ ] 反派 / 操盘者动机在翻转前已可见
- [ ] 每场结束时六项状态至少变化一项
- [ ] 抽掉任意一段，能说出抽掉后损失了什么
- [ ] 结局落到动作 / 物件 / 关系选择 / 可见后果
- [ ] 收尾解释长度与实际欠账相称，未另开新线
- [ ] 审读意见每条带可定位证据与最小修法，同类已合并
