# 短篇

短篇（单篇完整开合）专属语料：章节与段落钩子、反转机制、悬念编排、情绪释放、
题材公式与短篇质量清单。

通用的方法（人物 / 对话 / 情绪 / 结构）在 `通用/`，本类目只收单篇闭口独有判据，
不写长篇专属指标（卷、章均、长线伏笔那类口径在 `长篇/`）。
篇目与注入面由 `src/knowledge/catalog.ts` 声明。

素材以「精选速查版」改写自外部 MIT 项目（oh-story-claudecode），每篇 front matter
带 source/source_ref/license，许可全文见 `许可/`。

## 现有素材（7 篇）

| 素材 | 用途 |
|---|---|
| 章节钩子速查 | 开篇抓力、单篇牵引与收尾落点 |
| 段落钩子速查 | 段尾落点、段间承接、节奏切换与对话落点 |
| 反转机制速查 | 反转选型、同篇内铺垫与误导、揭示与兑现 |
| 悬念编排速查 | 立悬与揭的时辰、信息差工序、过载与空转 |
| 情绪释放速查 | 主情绪选定、押注与还账、情绪落点与过火处置 |
| 题材公式速查 | 题材兑现点、反转位与高潮位配置、配方疲劳修正 |
| 质量清单速查 | 单篇审读逐项核对（开篇抓力 / 完成度 / 收尾闭合 / 赘段） |
