# 知识层

本目录存放写稿、三审与对话可读取的正式知识素材。

素材以「精选速查版」改写自外部 MIT 项目（主要是 oh-story-claudecode），
保留来源、来源 ref、许可证和文件哈希，记录在 `_manifest.json`。CI 只信本目录，
不把 ignored 的 `Dev/` 参考仓当隐式输入。

改写原则：
- **速查而非全文**：每篇提炼决策路由 + 法则清单 + 自检清单，避免知识层臃肿；真模型按需读。
- **只收判断类**：角度 / 取舍 / 法则 / 判据入库；时效数据（榜单数值、样本统计）丢弃，
  可判定项（阈值 / 枚举词表）分流进代码。
- **MIT 署名随改写**：每篇 front matter 带 source/source_ref/license，许可全文见 `许可/`。
- **GPL 不平移**：GPL 项目（如 webnovel-writer）仅作结构参考，不搬代码或文本。

## 目录结构

分类轴 = **体裁档**（一篇只属一档，与写稿面 `kind` 判据对齐）；
面（写稿 / 三审 / 对话）不进目录名，由 `src/knowledge/catalog.ts` 的 `faces` 承载。

| 类目 | 内容 | 消费面 |
|---|---|---|
| 通用 | 跨体裁通用的写作方法（情节 / 冲突 / 人物 / 关系 / 对话 / 情绪 / 技法 / 读者 / 质量） | 对话面 |
| 长篇 | 连载专属：钩子、反转、悬念、节奏与升级、开篇与大纲 | 后续批接线 |
| 短篇 | 单章开合专属：章段钩子、反转、悬念、情绪释放、题材公式 | 后续批接线 |
| 去味 | 去 AI 味的判断面（判定面归代码） | 后续批接线 |
| 题材 | 题材卡与索引（按书题材召回） | 后续批接线 |
| 许可 | MIT 许可全文与署名件 | 不注入（随包留存即满足署名） |

现行仍由写稿面与三审面消费的语料在 `追读力/`、`爽点/`、`方法论/`、`题材/`——
这些是上一版分类的遗留目录，其后继篇落在 `通用/` 与 `长篇/`、`短篇/`；退旧件随后继
就位后的批次清理（未改动的删除，作者改过的永久保留）。

校验：知识层为纯文档（AI 运行时按本索引读取），manifest 对账有正式门——
`npm run check:knowledge`（scripts/check-knowledge.ts：_manifest.json 与实际文件
sha256/路径任一失配、盘上存在未登记资产、随包语料与 `知识层/` 原稿不一致，均即红，
已入 CI 与 tag 发布门）；内容错漏直接改对应 md，并同步 _manifest.json 的登记与 sha256。
