# 题材卡索引

本目录一类一张卡，共 32 张。**卡只在写稿面内部校准题材味，绝不出现在正文里**：
正文不得出现卡名、题材标签、置信度或本索引的条目编号，也不得写「已按题材卡……」一类自评。

## 召回规则

与本书设定、章节细纲、同题材对标冲突时，一律以后者为准——题材卡排在它们之后。

- **判据**：书级 `book.yaml` 的 `book.genre` 命中卡的 `aliases`（front matter 声明）。
  全等优先于包含（含别名 > 别名含题材），同档按别名长度降序；至多召回 2 张（主卡 + 一张邻题材）。
- **未设题材**：不召回任何卡（不猜）。作者没在 book.yaml 写过题材时不套用全局默认值——
  全局默认是建书表单的初值，不是本书题材这一事实。
- **播种**：建书只把命中的卡铺进书根 `知识层/题材/`（作者可直接改）；未命中的卡仍可随包读取，
  书级同名覆盖随包的语义与其余类目一致。
- **档位**：卡按长篇语境取材（含「前中后期打法」）。短篇书取卡只取题材层核心
  （题材核心 / 冲突发动机 / 爽点与情绪释放 / 禁止漂移），不套用卷级、前中后期打法。

## 置信度

- **高（23 张）**：同题材样本充分，可直接作为写稿校准起点。
- **中（9 张）**：样本尚可，需结合本书设定与对标书对照取用。
- 无低置信卡。新增低置信卡只能作初稿方向，写作前必须补同题材对标。

## 不要把这些当成硬规则

- 卡给的是「该题材更常用的场面与情绪落点」，不是段落模板：不做固定字宽、固定对话占比、
  全局替换虚词、随机倒装一类机械改写。
- 具体段落仍按细纲、文风与当前场景处理；卡与本章细纲冲突时细纲优先。
- 卡里的「每章」表述按本书章法解释：短篇书按整篇（单章闭口）理解。
