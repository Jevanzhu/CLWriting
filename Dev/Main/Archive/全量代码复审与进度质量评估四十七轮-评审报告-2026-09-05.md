#### R47-1 右栏信息面板族：每击键 5-8 处全文 O(n) 派生重算，右栏折叠/专注模式下仍常驻挂载
- **位置**：`web-next/src/components/panels/WritingInfoPanel.vue:52`（countWords+stripFrontmatter）、`:72-78`（parseFmFields）；`MetaFormPanel.vue:133-164`（watch 全文 parse）+ `:178-184`；`AnalysisPanel.vue:74,79-86`；`HistoryPanel.vue:23-26`；`views/EditorView.vue:134-143`（titleModel watch 每键 parseFmFields）
- **证据链**：CM6 每键 emit → `doc.patch` 写 `e.content` → 上述依赖 `entry.content` 的 computed/watch 全部重算。成本根源在共享函数：`src/format/frontmatter-core.ts:16-37` splitFrontMatter 全文 `split('\n')` + 两次 slice/join；`src/format/words.ts:18` countWords = `[...body.replace(/[#>*_`~\-\[\]()!\s]/g,'')].length`（两次全文物化 + N 元素码点数组）。单次击键合计 ≈10+ 次全文扫描 + ~7 个全文级行数组分配。
- **触发路径**：进书 → 右栏默认展开且默认 tab=info（`stores/workspace.ts:32,41`）→ 打开章节 → 打字。10 万字 ≈2-4ms/键 + GC 压力；50 万字线性放大至 10ms+/键（144Hz 帧预算 6.9ms），必现输入迟滞——直接顶在「几十万字不崩」产品红线。加重因素：`SidebarRight.vue:94` 切 tab 才卸载、`CollapseSection` 折叠仍挂载（v-show）、右栏折叠/专注仅 CSS 收窄——面板照跑。
- **反证先例**：`EditorView.vue:104-126` 自身 wordCount 已做 150ms 防抖（R39-20/R64-33 注释明记「每击键 O(n) 超大单文件可感」）——右栏面板是同款问题的漏网面。
- **修复方向**（§六 批 A1）：防抖派生值源——`useDebouncedSource` 组合式（150ms，源身份切换即刻重算，沿 R43-17 切文档即时口径），各面板派生 computed 改吃防抖源；WbDraftCard/HistoryPanel 等同链顺带收编。

#### R47-2 RAG 召回每查询把全库向量物化进内存，同步线性扫描阻塞主进程事件循环
- **位置**：`src/rag/index.ts:804`（`readAllChunks(db, warnThreshold+1)`）→ `src/rag/store.ts:345-401`（全表 embedding BLOB 逐行物化为 Float32Array 并**全部持有**在返回数组）→ `index.ts:853-867`（全量余弦 + 全量排序）
- **证据与量级**：200 万字目标场景 ≈3.5 万块 × 1536 维 × 4B ≈ **215MB 单次驻留尖峰** + SQLite 同步读 + JS 点积 ~320-350ms 同步阻塞（store.ts:336-343 注释自实测）。studio server 内嵌于 Electron 主进程（阶段 22 utilityProcess 已回退内嵌），阻塞期间三窗口输入/IPC/SSE 全冻结。self-heal 每章首稿备料 `prepareMaterials → recallDetailed`（`src/process/materials.ts:222`）——每章生成必现一次。双书并发备料（per-book 锁允许）峰值翻倍；十万块硬截断上限下理论尖峰 ~614MB。
- **既定拍板对照**：store.ts 头注已登记「十万块内线性扫描可用……明确不引索引」（RC 范围决策）。本条修复**不引索引**、不动「线性扫描」决策本身，只消驻留尖峰：打分只需 embedding 于**打分当刻**，打完即可弃——embedding 数组无需跨「闭库→网络 embed 查询向量」窗口存活。
- **修复方向**（§六 批 A2）：流式打分重构——指纹/章表仍单开库窗口读（快），闭库后网络 embed 查询向量，再开只读库游标逐行「解码→打分→弃向量、存轻量 {meta,score} 命中」（峰值从 O(全库向量) 降为 O(命中元数据) ≈ 数 MB）；毒行过滤/截断告警/排序后指纹校验语义逐项保持（修复批以既有 scale/rag 测试 + 新增等价测试守护）。
