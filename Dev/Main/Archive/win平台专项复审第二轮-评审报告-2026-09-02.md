## 三、发现清单（P2×2 + P3×6；全部主评审亲验）

> 编号 R2W-N（win 专项 R2 轮）。

### P2

**R2W-1　纯大小写文档改名在大小写不敏感 FS 上恒 409「目标已存在」——文档层缺 R71-8 同款分支**

- 位置：`src/document/service.ts:1179`（doMoveOrRename 预检）+ `:1216`（linkOrRenameExclusive EEXIST 第二道闸）。
- 证据：`if (existsSync(newSafe)) return { ok:false, code:'ALREADY_EXISTS' ... }`。win NTFS/mac APFS 上 `0001-dragon.md → 0001-Dragon.md` 的目标与源是**同一物理文件**，existsSync 恒真、linkSync 撞 EEXIST → 恒 409，作者无法只改标题大小写（经 PATCH op:'rename' 与 op:'meta' 标题改名两条路径可达）。书级改名已有 R71-8 dev/ino 同目录判定（books.ts:449-463），文档层漏配同族分支。
- 修复：预检与落位两处接入「目标存在 + 与源 dev+ino 相等 = 纯大小写变体」判定——相等时预检放行、落位改走 `renameWithRetry` 原位大小写变体（MoveFileEx 跨平台成立；posix 上同 ino 仅硬链接形态可达，rename 合并同名链接同数据无损）；不等才是真冲突，既有 409/link-EEXIST 收口不变。

**R2W-2　`账本推进.md` 带 BOM 时归档判定失明 → 他章待确认推进草稿被静默覆盖丢失**

- 位置：`src/process/lead-update-draft.ts:171`。
- 证据：`(raw.split('\n', 1)[0] ?? '').match(/^#\s*第(\d+)章/)` 无 BOM 剥除——作者用记事本「UTF-8 with BOM」保存后，`^#` 不中 → 走「无标签旧格式 = 视为当前章」分支跳过归档 → 下一次批量/自愈生成覆盖主文件，他章未确认推进草稿无痕丢失。
- 同族佐证：读侧孪生 `check/lead-updates.ts:151`（readLeadUpdateChapterTag）已显式剥 BOM——R33D-3 在该侧记录过同型灾难，本处是同族写侧漏网。
- 修复：归档判定前剥首行 BOM（`replace(/^\uFEFF/, '')`），+ 回归（BOM 夹具他章草稿 → 换章生成 → 归档发生、主文件重写）。

### P3

**R2W-3　删书/改名书的整目录 renameSync 无 EPERM/EBUSY 退避**——`api/books.ts:344/:566`（墓地移入、改目录名）。目录 rename 要求整棵子树无句柄持有，是全应用对杀软/索引器最敏感的操作；`renameWithRetry`（R77-3）原语已在库，两处收编。

**R2W-4　`providers.json` 备份恢复 `copyFileSync(bakFp, fp)` 无 unlink/退避**——`ai/provider/store.ts:112`（全库唯一 copy* 调用点）。目标按构造必存在；目标带只读属性或被他进程瞬时打开 → CopyFileW EPERM → 自愈链中断（主文件损坏态持续 500）。改为读 bak 字节 + `atomicWriteFile(fp, data, {mode:0o600})`（tmp+rename+退避，语义与写侧 ee-P2-1 对齐，.bak 保留）。

**R2W-5　doCopy 目标 relPath 只净化文件段、目录段裸穿**——`document/service.ts:1335-1336`。对照 doCreate（全段净化）与 doMoveOrRename move（R33-9 仅对不存在段净化），copy 漏配同族纪律：`设定/CON./笔记.md` 形目标在 win 上 mkdir EINVAL → 500「复制失败」。按 R33-9 口径补「不存在段过 sanitizeFileNamePart」。

**R2W-6　`book.yaml` 补丁族键行匹配不认 BOM**——`format/yaml.ts:769-772`（matchesKeyLine 只剥 `\r`）。解析侧因 `trim()` 侥幸存活，补丁族（patchTopSection/setTopScalarKey 等）首行带 BOM 时锚定失配 → 文件尾造重复段/重复键 → 下次解析撞 fail-loud 重复守卫，全书配置降级默认。Z-7 的 BOM 同族补齐：键行比对剥首部 `\uFEFF`。

**R2W-7　lineDiff / deletedSegments 行级精确等值不认 CRLF**——`process/rewrite-prompt.ts:88-99`、`ai/author-signal.ts:74-89`。CRLF 正文（外部编辑器保存）× LF AI 产出：改稿 diff 退化成整文件删+加噪块（确认 UI 不可用）；作者信号把所有行误判「作者删除」，ai 痕迹规则命中统计虚高。两侧行比较统一剥行尾 `\r`。

**R2W-8　两处 readdir 扫描 `.md` 过滤大小写敏感（R34D-11 家族漏网）**——`process/prepare.ts:46`（findChapterByNumber 散章/卷层扫描）、`format/style-entry.ts:143`（文风条目 readEntries）。`0005-x.MD`（资源管理器改名）→ 前章正文结尾段缺配、文风条目静默消失。镜像 walk-md.ts:89 既有口径（`slice(-3).toLowerCase() === '.md'`）。
