## 三、发现清单（MP2-N）

**P0×0 / P1×0 / P2×1 / P3×4 / 观察项×8。**

### P2

- **MP2-1〔win〕font-list 依赖在 win 打包态枚举系统字体闪 cmd/PowerShell 黑窗**——`node_modules/font-list/libs/win32/getByPowerShell.js:32`（调用点 `src/desktop/main.ts:706` `desktop:get-system-fonts` IPC）。证据：`exec('chcp 65001|powershell -command "…"', { maxBuffer })` 经 cmd.exe 执行且**未设 `windowsHide: true`**；win10/11 优先走此路径。打包态 Electron 主进程为 GUI 子系统，libuv CreateProcess 不带 CREATE_NO_WINDOW → 打开设置弹窗字体下拉（renderer 会话首拉或 60s TTL 过期后）即闪控制台窗。项目自身 git 调用已就 R1W-8 专修同型问题（git/exec.ts `windowsHide: true`），依赖把该防线打穿；font-cache（R77-1，60s TTL + 在途合并）只降频不消闪。**既往登记**：win 平台专项 R1 轮已记「font-list 闪窗〔上游〕」维持——本轮独立再发现，处置建议升级（见 §八）。建议：主进程侧自绘枚举 `spawn('powershell', [args], { windowsHide: true })`（或 fork/patch font-list），win 实机复验闪窗形态后收口。

### P3

- **MP2-2 provider store 四缓存 Map 不随远端列表收敛——跨窗删除的提供方条目常驻至重启**——`web-next/src/stores/provider.ts:104-124`（refresh）/`127-140`（refreshRag）。`refresh()` 只整体替换 `providers`，从不把 `testResults`/`probeModels`/`modelsByProvider` 修剪到存活 id 集合；`refreshRag()` 同理不修剪 `ragTestResults`。本地删除路径已闭环（remove/removeRag 随删清，即 MP-1 修复 `1a0744d`），但**另一窗口删除**提供方后，本窗每次切书触发的 `useChatTier().refresh()`（Book.vue:243）列表更新而缓存键残留，桌面端整日驻留即不回收。体积 KB 级（TestResult 为标量组；modelsByProvider 为模型 id 串数组）、读侧按 id 取不再命中无功能影响——卫生级。建议：refresh/refreshRag 成功分支按存活 id 对四个 Map 做 retain 修剪（≈4 行）。
- **MP2-3〔win 主战场〕三处用户可见 rename 仍是裸 renameSync，未收编 renameWithRetry**——`src/document/trash.ts:288`（回收站还原目录段：`renameSync(trashAbs, origAbs)`；文件段已走 linkOrRenameExclusive）、`src/export/index.ts:149`（导出旧产物归档）、`src/process/lead-update-draft.ts:184`（账本推进归档）。win 杀软/索引器瞬时锁 EPERM/EBUSY 时上述路径直接失败（export 处有 catch 降级为 warning 提示手动移入，trash 处失败回 WRITE_ERROR 可重试）；而基建 `renameWithRetry`（fs/atomic.ts:49，R77-3）就近可用，books.ts 删书/改名（R2W-3）已采用。同族记档：journal/words-diary 的 `appendFileSync` 无瞬时占用退避（失败以 WRITE_ERROR 报给作者可重试，可接受）。建议：低频用户面路径统一包 retry，或维持现状但报错文案提示重试。
