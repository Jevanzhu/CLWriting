## 三、批次明细

### 批 1：CI 性能回归门（建议 4）

- **目标**：守住「两百万字不崩」——请求路径同步 IO（tree 红点全量计算、detectState 同步 walk）在长篇下有耗时上界断言。
- **改动面**：新增 `test/check/scale.test.ts`（+ 必要时抽共用合成书 builder 入 `test/helpers/`，若 `test/rag/scale.test.ts` 的合成书构造为 RAG 专用）。
- **步骤**：
  1. 合成书 builder：500 章 × 约 4000 字/章（含 front matter、部分含机检可命中项），落 tmp 目录；
  2. 断言两口：`collectTreeIssues` 冷算耗时 + 二次调用缓存命中耗时（`tree_issues_cache` 生效）；
  3. 阈值口径：实施时本机实测基线 **×12**（承 2026-08-22 CI 慢机复校教训，同 `rag/scale.test.ts` 4000ms 先例）；先以 `test.skip` 观察形态跑两轮 CI 再收门（可选项：双规模点 250/500 章斜率断言，判复杂度阶——单规模点判不了，8-22 已记档此局限）；
  4. CI 接线：随既有 `build-test` job 的 `npm run test:coverage` 自然纳入，不新增 job。
- **验收**：本机与 CI 连续两轮绿；人为注入 O(n²) 退化（如临时去掉缓存）时断言能红。
- **回归**：+1 测试文件（预计 3-5 例）；README 计数同步。
- **风险与回滚**：CI 慢机误红——阈值 ×12 已容差，仍红则复校口径记档（先例处理方式）；revert 即回滚。
- **预估**：小（半天内）。

### 批 3：新书冷启动守护（建议 9，依 D4=a）

- **目标**：回答「用户第一天」：空书/无语料/无摘要/无金句/无样章时，机检、RAG、首稿链路行为确定且不炸。
- **改动面**：新增 `test/check/cold-start.test.ts`（模块层）+ 必要时 e2e 一例（新书→首稿路径）；发现项修复另行按当轮评审口径销账，不在本批强修。
- **步骤**：
  1. 走查脚手架产物（新建书/新建短篇的初始目录与文件）实况并记档；
  2. 空书机检：`collectTreeIssues`/`runCheckForDocument` 对空书、仅大纲、仅一章正文三种形态——断言零误报红点；
  3. RAG 空语料：build/recall 对无语料书——断言降级不抛错（不产生假召回）；
  4. 首稿链路：无章摘要/卷摘要/金句/样章时的 prompt 组装——断言省略层口径与 promptFiles 登记铁律①不破；

### 批 4：知识层更新入口（建议 8，依 D3=a）

- **目标**：语料回归域沉淀的机检误报规律有正式归宿——知识层可演化，不止 manifest。
- **改动面**：新增 `scripts/knowledge-update.ts`、`scripts/knowledge-commit.ts`（或合并单脚本双子命令）；`src/knowledge/manifest.ts` 增受限写入函数（现有读取面零改动）；package.json scripts 两行。
- **步骤**：
  1. `knowledge:update`：读语料回归域误报账本（corpus 账本派生口径，同阶段 18 批 6）→ 生成候选草稿 `知识层/机检误报-草稿-YYYY-MM-DD.md`（含命中样例/建议规则/来源引用），**不动 `_manifest.json`**；
  2. 作者审核：人工改草稿（删改条目）；
  3. `knowledge:commit`：定稿条目并入 `知识层/`（散文件按 category 归位）+ `_manifest.json` 再生（`generated_at`/entries/sha256 重算；`source`=语料回归域、`source_ref`=账本 commit id，schema v1 兼容不 bump）+ `npm run check:knowledge` 必须过；
  4. 更新约定写入 `知识层/` 头部说明或 README 披露段。
- **验收**：一轮完整「误报→草稿→审核→入库→check:knowledge 过」演示留证；manifest 校验对存量条目零扰动（恒等对照）。
- **回归**：+1 测试文件（脚本纯函数部分：草稿生成/manifest 再生/恒等，预计 4-6 例）；README 计数同步。
- **风险与回滚**：manifest 再生误伤存量——恒等红线用例锁死（仅新增 entries + generated_at 变化，B-18 bookHash 同款口径）；脚本 revert 即回滚、知识层内容 git 可溯。
- **预估**：中（一天）。
