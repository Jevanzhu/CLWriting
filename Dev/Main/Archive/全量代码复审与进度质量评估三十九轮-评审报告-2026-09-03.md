### 5.1 R39-1：author-signal 未 await × rmSync 竞态 = win 测试门红

`beforeEach` 恒 `git(['init'], root)` 使 fixture 为 git 书库 → `recordAuthorSignal` 第一步 `listAiVersionsAsync`（src/ai/author-signal.ts:36）必 spawn git.exe（src/git/exec.ts:161，**cwd = 测试临时目录**）。用例 3/4/5（:58-73）同步回调裸调不 await：promise 挂起、断言立即执行、afterEach `rmSync(root, {recursive, force})` 开跑——此刻 git.exe 可能仍存活，Windows 删在用目录报 EPERM（错误路径恰为临时根目录，与基线日志逐字吻合）。失败 3 例 = 未 await 3 例，零交叉。附带：三例断言跑在异步逻辑完成前（「期望空」恰不依赖完成态，断言力虚置）。修：三例改 `async` + `await`（恢复确定性）；afterEach 改用仓内现成 `rmWithRetryQuiet`（src/fs/cross-process-lock.ts:299）覆盖 await 后句柄释放延迟的残余窗口。

### 5.2 R39-2：win-fonts 逐 chunk 解码劈字

`child.stdout?.on('data', (d) => { out += d.toString('utf8') })`——Node 管道按任意长度给 Buffer chunk，`Buffer.toString('utf8')` 对每 chunk **独立解码**：多字节字符（中文字体名 3 字节/字）切在边界即 U+FFFD，无报错、无日志，字体下拉直接出乱码项。修：收集 `Buffer[]`，close 时 `Buffer.concat(...).toString('utf8')` 一次解码（stderr 同理）；与 server-manager.ts:538 的 setEncoding 口径对齐。

### 5.3 R39-3：FontPicker 滚动即关闭

`.fp-menu` 为 `position:fixed; overflow-y:auto; maxHeight≤360px`（FontPicker.vue:95,167-173），`.fp-item` 29px 高——win 桌面字体族 100+ 时列表必溢出滚动。`window.addEventListener('scroll', onScrollOrResize, true)` 捕获监听：scroll 不冒泡但捕获路径经过 window，用户滚动菜单自身时 target = 菜单 → 首个滚动 tick 即 `close()`。第 13 项及以后字体**永远无法选中**（J5 自绘改造的功能性回归）。修：onScrollOrResize 排除菜单自身（`e.target` 在 menu 内则忽略），窗口级滚动/resize 关闭语义不变。

### 5.4 R39-4：FontPicker Esc 双效

useHotkeys（WorkspaceShell setup 挂，**先注册**）与 FontPicker.onKey（专注排版条挂载时挂，**后注册**）同为 window keydown bubble 监听，派发按注册序：useHotkeys 先跑，`!overlayOpen`（FontPicker open 态不在名单）且 `!defaultPrevented`（彼时 preventDefault 还没发生）→ `toggleFocus()` 退专注+全屏；FontPicker 随后 close。ContextMenu（:84-90）同款收口成立纯因「子组件先于父挂载」的注册顺序，FontPicker 是漏网形态。修：FontPicker.onKey 改**捕获阶段**注册（capture 先于全部 bubble 监听，与注册序无关），open 态消费 Esc 时 `preventDefault + stopPropagation`——对齐 Z-23「本层消费」口径且不依赖挂载时序。
