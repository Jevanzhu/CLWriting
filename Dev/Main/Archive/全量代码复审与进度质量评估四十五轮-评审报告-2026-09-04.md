### 复核通过项（平台适配，静态核验）

- 路径安全：`resolveWithinRoot` 双侧 realpath、`..` 段级判定兼容 `\\` 与 `/`、NUL 拒绝；rel 一律输出 posix 分隔，前端仅按 `/` 拆分安全。
- 文件名：`sanitizeFileNamePart` 单源覆盖控制字符、`\\/:*?"<>|`、尾点尾空格、win 保留设备名、NFC、码位+字节双封顶；`isMdFileName` 大小写不敏感。
- 原子写：同目录 tmp + fsync + rename；rename/rm 对 EPERM/EBUSY 3×50ms 退避（win 杀软/索引器场景）；exFAT/SMB 无硬链接时降级并留痕。
- 文本规范形：写侧 LF + 无 BOM + NFC，读侧容忍 CRLF/BOM；`.gitattributes` 钉 `eol=lf`，bat/cmd 例外 CRLF。
- Electron：`contextIsolation`/`sandbox`/`nodeIntegration:false`，`will-navigate` 阻断，`setWindowOpenHandler` deny，CSP 注入，单实例锁 + second-instance 聚焦；mac `hiddenInset`，win `autoHideMenuBar` + WCO。
- 子进程：git 与 win 字体枚举均 `spawn` 数组参数 + `windowsHide`，不经 cmd.exe；PowerShell 走 SystemRoot 绝对路径兜底 + 10s 超时 + Buffer 整流解码。
- userData：三平台目录解析统一 `CLWriting`，win 优先 `%APPDATA%`。
- 服务端：仅回环监听，Host/Origin 双校验，写路径 token 闸。
- 前端：`usePlatform` 三态（浏览器/mac/win），mod 键文案、交通灯避让、win 字号基准 +1px 分流。
- 系统垃圾：树扫描跳过点开头项（含 `._*`/`.DS_Store`），`.gitignore` 已排除。
