### 5.1 P2×4（全部主评审逐条亲验成立）

**R31-1 [P2] Chat 线「有 usage 无 finish_reason」→ 截断流被当正常完成**
- `src/ai/provider/openai-adapter.ts:263`（`let pendingStopReason = 'stop'`）+ `:410`（`if (latestUsage) { const ev = emitDone(toUsage(latestUsage), pendingStopReason); ... }`——该分支**不检查 `sawFinishReason`**，而该标志的注释明确「没见过=传输截断」。
- 影响：usage 随任意 chunk 先行的网关形态（Kimi 族）下，若连接在 finish_reason 之前断流，半截文本以 `stopReason:'stop'` 正常完成出场——generateText 不触发 MAX_TOKENS 检查、半稿按完整产出落盘入账。对照 Anthropic 线 output usage 只随 message_delta（带 stop_reason）到达，实际面主要在 openai 兼容中转网关。
- 修法：`if (latestUsage && sawFinishReason)` 才 emit；仅 usage 无终止 → 归「传输截断」可重试错误（与既有流终止契约对齐）。补该组合的单测（现仅覆盖「有 finish 无 usage」「两者皆无」）。

**R31-2 [P2] front matter/细纲解析只认半角冒号 → 全角冒号整章不可读/两端闭合假红**
- `src/format/frontmatter.ts:162-166`（`const colonIdx = line.indexOf(':')`，无冒号行静默跳过）+ `src/format/yaml.ts:122-127`（parseSections 同款）。
- 复现（tsx 实测）：中文作者用输入法手改章 fm 写 `章号：152` → keys=`[]` → readChapter 报「缺少必填字段：章号」整章不可读（机检 NOT_CHAPTER）；`细纲.md` 写 `推进：[悬念-001]` → 键静默丢失 → `lead-done-not-declared` 假红硬阻断定稿。同库 `HISTORY_ENTRY_RE`/lead 条目正则已是 `[：:]` 双认——两口径分裂本身即证据。
- 修法：键位冒号探测双认 `:`/`：`（取先出现者，值侧不动），或在 parseFlat/parseSections 入口做行级键位归一。配全角冒号矩阵用例。

**R31-3 [P2] 账本推进「兑现侧」读失败按空清单 → lead-declared-not-done 假红阻断定稿**
- `src/check/lead-updates.ts:44-48`（readFileSync catch → `return []`，注释自认 X-P2-5「读失败按无推进降级」）+ 消费侧 `src/check/run.ts` 两端闭合。

**R31-4 [P2] GET/HEAD token 闸用 raw URL 判 `/api/` 前缀，与 dispatch 的规范化 pathname 双轨 → dot-segment 绕读闸**
- `src/studio/server/index.ts:354`（`req.url.startsWith('/api/')`，raw）vs `:373-380`（`new URL(req.url).pathname` 规范化后才 dispatch，R72-10 注释自称口径统一但只统一了 dispatch 侧）。
- 亲验：node 实测 `new URL('/foo/../api/books','http://x').pathname === '/api/books'` 而 raw startsWith 为 false；Node llhttp 不归一化请求行 → `GET /foo/../api/books` 跳过 token 闸 → apiPathname 命中 `/api/` → 路由无凭据执行。`%2e%2e` 编码段同效。
- 影响限定：写闸按方法全拦（不受影响）；浏览器 fetch/XHR 发送前归一化（远端页面实际造不出裸 dot-segment）；本机进程属同信任域——**击穿的是代码自定目标**（R65-64「全量 GET 无凭据一律 403」穷举测试意图失守），且穷举测试只打干净路径测不出本条。
- 修法：GET/HEAD 闸复用规范化 `apiPathname`（计算上移到闸前），豁免表同口径匹配；补 raw-socket dot-segment 红测（static.test.ts X-21 已有同款构造技术先例）。
