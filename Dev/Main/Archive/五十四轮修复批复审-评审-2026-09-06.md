- **实现核验**（`src/desktop/main.ts:439-475`）：`probeDirReachable` 用 `Promise.race([stat(dir), timeout-reject])` 异步预探，超时哨兵 `PROBE_TIMEOUT = Symbol(...)`——与 stat 真实异常（均带 errno code）天然区分；`finally` 清理计时器零泄漏；三态 'ok'/'unreachable'/'invalid' 分诊：超时 = 唯一冻结形态 → 契约化拒切「目录暂不可达（可能是网络卷无响应或已断开），请稍后重试」（:1197-1199）；ENOENT/EACCES 等确定性快速失败 = 交回同步守卫走原「目录无效或是另一书库的子目录」契约文案，不把普通坏路径误报成网络卷不可达。
- **契约保护核验**：非字符串先于预探短路走原文案；预探通过后原 canSwitchLibraryDir 守卫全量保留（10+ 存量 switch-library 用例零破坏）；超时/预算经 `CLW_SWITCH_LIBRARY_PROBE_TIMEOUT_MS` 注入（测试快进），与 R53-A-1 SESSION_END_FLUSH_BUDGET_MS 同款可注入口径。
- **取舍如实性核验**：注释明确声明「预探通过后拔线的 TOCTOU 残窗仍在，冻结从恒现路径收窄为预探后瞬断」——收窄不封堵，诚实工程；预探通过后同步守卫仍会再跑一次 statSync（双 stat），成本毫秒级可忽略。

### 2.2 R54-A-1 close/quit flush 超时/无钩子留痕（P2）——通过（观察 2 条）

- **修复目标**：close/quit 两链 res===null 此前静默 destroy/继续退出——超时态（保存链慢盘/server 退避窗）与「无钩子（非编辑页常态）」不可区分且零诊断线索，与 session-end 链（R53-A-1 已有留痕）不对称可证非设计。
- **实现核验**（main.ts:984-1006 close / 1689-1709 quit）：两链同构——`let XFlushTimedOut = false` + race 内 timer 回调同拍「置旗 + resolve(null)」；race 落定后 clearTimeout（兼 A-5）；`res===null` 时旗为准分诊：超时 → `log.warn`「关窗兜底 flush 超时/退出前 flush 超时（>4000ms）未落定即关窗/退出——超时窗内未保存的键入可能丢失」；无钩子 → `log.info`「…无钩子/渲染层不可达（非编辑页常态）」。语义不变核验：超时后照常 destroy/收口退出（测试钉）。
- **竞态正确性核验**：「旗 + null」分诊无竞态误判——timer 回调置旗与 resolve 同一拍执行；仅存在「flush 与 timer 同拍落定」的边界（warn/info 择一），两态均属实可接受，无第三种语义。
- **三链对称性核验**：close/quit 超时 warn / 无钩子 info；session-end 链恒 info（含超时）——系 R54 报告 §五 已记档的 R53-A-1 显式取舍（OS 收尾期尽力而为不拖停机 vs 用户主动关/退的丢失风险），复审确认取舍口径成立，非缺陷。

- **结论**：修复正确、语义保持、三链留痕对称完形。评 9.0/10（观察 2 条见 §四——旗+null 可仿 Symbol 哨兵、warn 文案「>4000ms」严格应为「≥4000ms」）。
