### Z-P2-6 foreshadow 事件族接线（原「零生产写点」）

- 模式：**快照-差分**——documents API 四个变更点（PUT content 保存 / PATCH rename·move·meta·fm / POST 新建 / DELETE 软删）在变更前对 `设定/伏笔/` 抓全量快照（非伏笔路径 null 直通，零开销），变更成功后 `recordForeshadowChanges` 差分落 workspace 会话（foreshadow/change：create/edit/complete/block/clear）。

- 测试：chain-bridge.test.ts 3 新例（close 单事务 / flush 分批 / 超阈值凑批）+ chain-events 集成 5 例不回归。
