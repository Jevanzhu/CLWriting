## 二、设计要点

- **所见即所得零新链路**：控件全部直连 `usePrefsStore` 既有 setter（与 SettingsEditor「编辑器」tab 同构同 min/max/step）——调整即时 `apply()` CSS 变量 + 防抖落 global.json；无新偏好键、不动持久化链路（专注态仍不记忆，浮动条改的排版值按既有链路正常持久）。
- **纸宽保持当前 scope**：`setPageWidth(v, bookPageWidth !== null)`——书级覆盖存在时继续写书级（label 显示「纸宽·本书」），切换 scope 仍走设置面板；两处 UI 同一 setter 语义无双写冲突。
- **样式自持**：滑杆/select 样式组件内 scoped（规格同 settings-shared.css）——浮动条结构不同且不依赖设置组件的样式注入时机。
- **Esc 语义不变**：浮动条非弹层，不进 `useHotkeys` overlayOpen 让渡名单——Esc 保持「退出专注」单一语义，浮动条随 v-if 消失（测试锁死）。
- **不占布局流**：absolute 挂 ws-main（ChatDock 定位基准先例），浮于纸张旁空白区，`max-height` 保护小窗。
