### 1.3 效应让出契约（唯一新机制，形态落定）

```ts
// run-tree-issues.ts 邻近声明（不新增对外导出面）
type TreeEffect = { kind: 'openCheckDb'; bookRoot: string; hasWiring: boolean; opts: OpenCheckDbOpts }
// 核心签名：Generator<void | TreeEffect, TreeIssuesResult, unknown>
//   yield 无值       = 纯悬停：同步驱动直推 next()（= 改动前行为），async 驱动 await yieldToEventLoop()
//   yield TreeEffect = 效应请求：同步驱动现执行现回填 next(结果)，async 驱动 await 异步实现后回填
```

- 同步驱动：`r = r.value === undefined ? it.next() : it.next(execEffectSync(r.value))`（`execEffectSync` = `openCheckDb(...)` 同步版，逐位不变）。
- async 驱动：驱动循环加 `inject` 槽——`it.next(inject)` 后 `inject = undefined`；`r.value === undefined` → `await yieldToEventLoop()`；否则 `inject = await execEffectAsync(r.value)`。
- 计数：`execEffectSync` / `execEffectAsync` 各 `preludeYieldStats.rebuild++`（A4 佐证）。
