## 三、文件级落点明细

### 3.1 S1 `src/update/` 模块

- `semver.ts`：
  - `parseSemver(v: string): { major: number; minor: number; patch: number; prerelease: string | null } | null`——去前导 `v`；缺失/非数字段/垃圾输入 → null（不抛）。
  - `compareSemver(a, b): -1 | 0 | 1`——先比三元组；三元组相等时 **prerelease < stable**（这正是「rc 用户收到首个正式版提示」的判定：`1.0.0-rc.0 < 1.0.0`）；两侧同为 stable 或同为 prerelease 且串相等 → 0。
  - `pickLatestStable(tags: string[]): string | null`——逐 tag `parseSemver`，**含 `-` 者（rc/nightly 形态）与不可解析者全部忽略**，回最大值的原始 tag；空表/全垃圾 → null。
- `check.ts`：
  - `RELEASES_URL = 'https://api.github.com/repos/Jevanzhu/CLWriting/releases?per_page=20'`。
  - `fetchLatestStable(fetchImpl, timeoutMs = 5000): Promise<string | null>`——AbortController 超时；非 200 → null；JSON 解析容错 → null；条目取 `tag_name`（`draft === true` 跳过——匿名 list 本不含 draft，防御性保留）；`pickLatestStable`。**不抛**（对齐 `embed.ts`）。
  - `runUpdateCheckOnce(opts?)`：开关短路（`CLW_DISABLE_UPDATE_CHECK === '1'` → return，不置结果）；`currentVersion` 经 `resolveAppVersion()`；仅当 `compareSemver(current, latest) < 0` 才置更新结果 `{ version, url }`（url = release 页 `https://github.com/Jevanzhu/CLWriting/releases/tag/<tag>`）；失败/离线/限速一律静默（可选一行 info，**不 warn**，头注写明与 `embed.ts` 的差异理由）。
  - 结果缓存：模块内存 `{ state: 'idle' | 'done'; result: { version: string; url: string } | null }` + `getUpdateCheckResult()`（随 server 生命周期，同 startup-notices sink 语义；不落盘、进程内一次）。
  - `resolveAppVersion()`：`process.env.CLW_APP_VERSION` ?? 读 package.json 的 `version`（try/catch 回落 `'0.0.0'`）——**单源函数**，server 侧（端点与检查）都经它取，勿两处各读。
- 单测：`semver.test.ts` 表驱动（rc / 正式 / 相等 / 乱序 / 垃圾 tag / 空列表 / 高位版本 / 前缀 `v` 有无）；`check.test.ts` stub fetch（正常 / 超时 / 非 200 / 403 / 畸形 JSON → 全静默返 null 不抛；开关短路不调用 fetch）。

### 6.1 实况（与蓝图出入明细）
