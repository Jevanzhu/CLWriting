## 文档操作链

- **分工（2026-09-08 整理批定；2026-09-17 清库批随台账撤除修订）**：`Dev/Docs/README.md` 只记目录+计数；总览只记开放任务+现行口径+待拍板决策（已收口记录不入）；`Archive/README.md` = 归档规则 + 批次时间线。状态与细节不复制——正本唯一，他处只留指针。
- **新文档**：`主题-类型[-状态]-YYYY-MM-DD.md` → 入 `01-评审 / 02-执行 / 03-设计 / 04-调研` → 同步 README 计数 + 总览「一、文档地图」（+「三、实施顺序」「五、决策状态表」如需）。
- **评审命名（2026-09-09 作者指令）**：评审报告名须含执行模型名：`主题-评审-<执行模型>-YYYY-MM-DD.md`——执行模型名 = 主审模型（会话模型），位于类型与日期之间；报告头部同步记「执行模型」行，子代理与主审异模型时在头部另列。仅约束 2026-09-09 起新建文档，既有文档不追改（历史正文不改写）。
- **开工/完成**：改总览状态行（「已开工」/「已完成」）；完成时决策由待拍板→已拍板回改方案，方案归位 02-执行（可开工）或 03-设计（暂缓/现行规范标「现行」），留验收证据。
