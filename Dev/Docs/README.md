## 二、约定

- 命名：`主题-类型[-状态]-YYYY-MM-DD.md`。
- 分类：评审→`01-评审/`；已拍板可开工→`02-执行/`；暂缓/现行规范→`03-设计/`；调研→`04-调研/`；收口/失效→`Archive/`（扁平，删除即删、git 复原锚兜底，不 zip）。
- 同步：落地/换类/归档后更新本文件计数 + 总览地图；状态与细节的正本在总览，本文件只管目录与计数。
- 本文件不设变更记录节；各批明细随 commit message 自考。
