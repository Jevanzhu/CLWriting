## 门禁

改动前跑最小充分证据，推送前的检查按改动面选择（见 project-harness 的 pre-push 指引）。

```sh
node scripts/harness/run-gates.ts doc-quick   # 秒级，文档与决策记录
node scripts/harness/run-gates.ts check-all   # 全量：把构建、测试、平台门加进这个模式
```

分支保护只要求一个聚合检查名。**门禁失败时不要绕过它**——要么改代码，要么在评审里论证门禁本身错了。

## 决策记录

本仓的工作语言在这里声明：**中文**——文档、提交信息与指令文件同一种语言，别处不再重复声明；换语言是一次显式迁移，不是逐文件漂移。**指令面永不配对**：本文件、`docs/AGENTS.md` 与决策记录的机制说明各只有一份；需要双语的知识（设计、使用文档、决策理由）写进 `docs/` 或 `.agents/notes/`，配对与一致性记录只在那边。
