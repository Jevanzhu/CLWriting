## 校验

`scripts/harness/verify-doc-index.ts` 对照本表与磁盘，规则只有四条：声明的目录必须在磁盘上；`docs/` 下每个一级目录都必须被声明；本目录顶层的每份文档都必须在本表出现一次；声明了计数的目录，本表命名它的那一行上的数字必须等于磁盘上的实际篇数。

篇数是**声明**，不是展示：新档落盘时改这里的数字，门禁会在不一致时红。计数只数非隐藏文件——`.gitkeep` 不算一篇，空目录可以占位。

槽位的名字可以改（`03-设计` 换成 `design` 也行），改完同步 `scripts/harness/doc-index.manifest.json` 与本表——链的规矩是「材料、声明、磁盘三者一致」，不是名字具体叫什么。
