# 黄金三章实操清单

## 一、开篇钩子：前三段必须有「异常」

- 前三段内出现异常：事件（当众退婚/暴毙/穿越）、反差（废物突然胜了内门第一）、危机（追兵已至城门）。没有异常的开头留不住人。
- 从冲突中间开场：第一句就站在麻烦里，背景后置、分批给。谁欠谁的、世界观规则，留到读者产生疑问之后再答。
- 第一句禁忌：天气、起床、回忆、梦境、外貌描写。五种开头在编辑那里一律扣分。
- 若必须铺垫，用「倒计时」垫：三天后比武、今夜子时毒发——读者知道麻烦几点来，就等得起。

## 二、黄金 300 字：谁 + 在哪 + 麻烦是什么

- 前 300 字完成三件事：一个可共情的主角、一个具体处境、一个明确的麻烦。三缺一都会流失读者。
- 单视角开局：前三章只跟一个人，全知视角或多线开花是自杀，群像戏留到第三章之后再铺。
- 300 字内主角必须「做」一件事（哪怕只是小动作：藏起一枚玉佩）。只被介绍、不做事的人物立不住。
- 主角可以惨，但绝不窝囊：受欺压要顺手露出獠牙的预兆（一句狠话、一次忍而不发）。憋屈无反击，三章劝退。

## 三、人设锚定：500 字内一个反差标签

- 主角出场 500 字内立「反差标签」：能力反差（瞎子却听风辨位）、身份反差（赘婿却是隐世剑首）、性格反差（杀人如麻却喂猫）。标签即记忆点，记忆点即传播点。
- 给主角一个主动目标：他想要什么 + 谁或什么挡着。被动挨打的主角推不动剧情，读者也推不动书页。
- 金手指第一章只演示不解释：先看效果（一拳碎石），规则与代价留到使用中逐步显影。开篇说明书等于劝退书。
- 配角出场配一个功能标签（一句话可复述：贪财的师兄、只会笑的执事）；三章内给不出独立标签的配角，合并或删除。

## 四、期待感铺设：每章尾一个未兑现的钩子

- 每章结尾留钩：新麻烦登场、旧伏笔半揭、一句改变走向的话。断章处就是读者决定追读或弃文的地方。
- 三章内立至少一条长期期待：复仇名单、身世之谜、登顶目标。长期期待是追读的发动机，章尾钩子只是油门。
- 期待要可见进度：境界条、榜单名次、敌人层级——读者能丈量离终点还有多远，才肯陪跑。
- 伏笔记账：埋下的每个钩子记下章号，10 章内回扣或明确延期。烂尾感多半来自失约，不是慢热。

## 快速自查

1. 前三段有异常吗？第一句踩禁忌了吗？
2. 300 字内「谁 + 在哪 + 麻烦」齐了吗？主角做了动作吗？
3. 主角有反差标签与主动目标吗？
4. 每章尾有钩子吗？长期期待立了吗？伏笔记台账了吗？
