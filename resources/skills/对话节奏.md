# 对话节奏实操清单

## 一、潜台词：说 A 指 B

- 写完一场对话自查：若人物说的就是想的，这场戏太薄——改成言不由衷或只说一半。
- 三种安全藏法：答非所问（问行程，答「你瘦了」）、转移话题（被戳痛处立刻反问对方）、过度客气（越客气越疏远或越危险）。
- 让读者看见裂缝：动作或停顿与台词打架——嘴上说「没事」，手一直抖。台词会骗人，身体不会。
- 潜台词要可回收：埋下的言外之意后文必须兑现（他躲闪的问题，三章内给答案），否则是废话不是伏笔。

## 二、信息差：动笔前先列「谁知道什么」

- 列三方信息表：A 知道什么、B 知道什么、读者知道什么。冲突就藏在差集里，没有差集的对话只是交换情报。
- 读者比角色多知道一点 → 悬念（读者替角色急）；读者比角色少知道一点 → 反转（揭晓时才爽）。每场对话选定一种，不要混用。
- 角色绝不一次性倒光信息：一轮对话只放一条新料，放完就让位给反应（惊讶/怀疑/追问）。反应比信息本身好看。
- 设定解释拆散了给：借冲突给（质问中带出规则），不借讲课给。「你忘了当年……」永远优于三段设定陈述。

## 三、错位应答：别句句接得严丝合缝

- 连续直接应答不超过 3 轮，第 4 轮必须打断：反问、沉默、突然的动作、第三者插话都行。
- 常用错位手法：重复对方关键词但换语气（「你要走？」「走。」）、回答上一句没问的事（心里有事）、用事实回应情绪（「我怕」「明早卯时出发」）。
- 争吵戏用短句错位加速，谈判戏用长句加停顿错位施压。节奏感 = 句长 + 应答方式的组合。
- 关键对话不给全文：写读者该看的 3 轮，寒暄与重复用转场跳过（「又聊了半个时辰，无非那些话」）。

## 四、动作穿插：对白别写成剧本体

- 每 3~5 轮对白插一个动作或环境微变化（茶凉了、灯花爆了、他起身关窗）。动作是节拍器，也是潜台词的载体。
- 动作要挑有态度的：捏紧杯沿与推开杯子是两种回答。擦杯、踱步、翻账本可无限复用且不抢戏。
- 对话段落长短交替：连续等长段落等于催眠。重话前留白（单独成段），废话连写压缩。
- 结束对话别用「说完了」收：用动作收（把碗一推）、用打断收（门外传报）、用悬念收（「对了，还有一事——」切场景）。

## 快速自查

1. 这场对话的信息表列了吗？一轮是否只放一条新料？
2. 有没有超过 3 轮的直接应答没被打断？
3. 每 3~5 轮有动作节拍吗？动作带态度吗？
4. 有没有「角色说的就是想的」的薄戏？
