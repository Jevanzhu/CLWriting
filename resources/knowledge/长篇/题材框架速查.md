# 题材框架速查

用于长篇（连载）的选题、框架配置与题材迁移：判断一个题材由哪些要素构成、怎么为它配结构骨架、金手指与主角身份是否配套，以及题材错配怎么认、按什么次序改。与本书大纲、账本、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 分不清这个故事属于哪个题材 | 题材四件套识别 + 不可逆承诺 |
| 故事想同时走两条题材线 | 一个主框架 + 一条配菜 |
| 知道题材却不知从哪搭骨架 | 阶段功能位序列 + 情绪弧线完整 |
| 情绪弧线断层：只有憋屈没有宣泄，或一路爽无起伏 | 压抑 → 爆发 → 释放三段补齐 |
| 写到中段篇幅撑不住、单元在重复 | 模式循环 + 规模升级 + 主线串联 |
| 金手指给强给弱拿不准 | 金手指强度配主角姿态 + 力量体系对齐 |
| 主角想做的事与身份不相称 | 身份决定能做的事 |
| 换题材写，但沿用了旧题材的骨架 | 迁移功能位，不迁移冲突源与场景 |
| 读者说「这不是我要看的那个题材」 | 错配信号表 + 修正顺序 |
| 场景里斗不起来，冲突无根 | 场景是社会关系前提 |
| 结局写完读者说「空」 | 结局情绪对位题材核心 |

## 法则清单

### 题材的构成与识别
- 题材由四件套构成：核心冲突模式、第一情绪对、场景关系前提、金手指类型；四件成套，只换其中一件等于没换题材。
- 识别题材先问「谁对谁做了什么、这事能不能挽回」：不可逆承诺（追不回、来不及、回不去）才是题材名的来源。
- 题材自带读者期待：读者为这个承诺点进来，承诺要前置兑现，不能压到后期。
- 场景是硬前提：需要权力差的题材放进平权、人际稀薄的场景，冲突没有根。
- 一个故事只有一个主框架；混搭时另一条题材线只当配菜，两个主承诺并立会掉读者。
- 外壳不等于卖点：点子型题材的世界观外壳可以换，卖点必须保住。

### 结构骨架的配置
- 骨架 = 阶段功能位序列（起势 → 加压 → 转折 → 反攻 → 清算 → 余韵）；题材只改各功能位的强度与包装，不改功能本身。
- 情绪弧线必须完整：压抑 → 爆发 → 释放，断在哪一段读者就骂哪一段。
- 压缩或省略一个功能位，要把对应情绪补进别的功能位，并给出题材或人物因果上的支持。
- 单元、副本、地图型连载：同一模式反复循环，每轮换对象、换场景、抬对手层级；单元自成一事，主线负责串联保底。
- 核心梗须在首个剧情单元内运行或完成铺垫；连续多个单元不运行即视为失效。
- 反派按层级嵌套：小反派掀小事、中反派揭阴谋、大反派撑全书，层级与篇幅匹配，且各有独立动机，不是工具人。
- 结局情绪对位题材核心：爽向收在释放或治愈，虐向收在意难平或余韵。

### 金手指与主角身份的匹配
- 金手指强度与主角姿态配套：弱势主角配上强系统，爽点就从「算计碾压」变成「实力碾压」，等于换了赛道。
- 金手指与题材的力量体系对齐：力量体系清晰的题材，金手指必须有明确规则、有使用限制、随成长不崩。
- 信息差型题材的金手指就是信息本身（先知、原著知识、现代认知），不要给成万能实力。
- 反推检验：换一种金手指，题材卖点还在不在？还在，说明它本来就与题材错配。
- 主角身份决定他能做什么：身份不支持的目标没有说服力，人设不为意外让路。
- 显性身份要保持变化（层级上升、场景迁移），隐性身份与核心矛盾绑定。
- 先知型金手指到后期必与剧情撞车，须提前用自洽设定包装。

### 换题材时的框架迁移
- 可迁移的是功能位与情绪弧线；不可迁移的是冲突源、场景、配角层与情绪名。
- 迁移第一步：先定新题材的不可逆承诺与第一情绪对，再套旧骨架。
- 迁完重做三项匹配（金手指、场景、人物身份）；只换场景名等于没换。
- 开篇必须重做：前几章重新点题、重新亮卖点。
- 题材认可的强度区间是刻度盘不是开关：阻力太强读者被虐跑，太弱没张力，两端都要回调到区间内。

### 错配的信号与修正
- 信号：开局用了别的题材的惯用冲突（该憋屈的开局在撒糖，该清算的开局在过日常）。
- 信号：读者留言「这不是我要看的那个题材」。
- 信号：情绪弧线断层，长时间无宣泄，或一路平推没有起伏。
- 信号：场景撑不起冲突——没有权力差硬写伤害与追悔，人际稀薄硬写圈层斗争。
- 信号：配角没有独立利益，矛盾靠主角身边人硬凑。
- 修正顺序：先改题材定位 → 再改冲突源与场景 → 再调金手指与身份 → 最后才动结构比例。
- 老套外衣可以换新包装，但换的是包装，题材承诺不换。

## 自检清单

- [ ] 能用一句话说出本作的核心冲突模式与不可逆承诺
- [ ] 场景提供了该题材必需的权力差或人际密度
- [ ] 全书只有一个主框架承诺，另一条题材线只当配菜
- [ ] 阶段功能位序列齐全，缺位处已给出题材或人物因果
- [ ] 情绪弧线压抑→爆发→释放无断层
- [ ] 核心梗已在首个剧情单元内运行或完成铺垫
- [ ] 单元循环每轮抬升对象、场景或对手层级，且单元能自成一事
- [ ] 反派分层嵌套，每个反派有独立动机
- [ ] 金手指有规则、有限制，与题材力量体系对齐
- [ ] 金手指反推检验通过：换掉它卖点就没了
- [ ] 主角身份支持他的终极目标，显性身份在持续变化
- [ ] 结局情绪与题材核心对位（爽向释放，虐向余韵）
- [ ] 开篇几章已点题并亮出卖点
