# 核心梗与卖点速查

用于定型长篇连载的核心梗与卖点：把卖点写成可判定的判据、让它在高频复用中保鲜、管住它与支线的关系、识别并修正卖点稀释与跑偏。与本书大纲、账本、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 被问「这书卖什么」答不上来 | 核心梗三问：一句话能说清 / 能反复运转 / 每轮给新东西 |
| 单元章纲里找不到卖点落点 | 单元循环检查：期待点、爽点、两者之间三选一 |
| 写到中段卖点不再出现 | 断期待诊断：核心梗被搁置还是被支线顶掉 |
| 同款桥段重复第三遍，读者说腻 | 复用保鲜：换场景 / 对象 / 条件，或升一档兑现 |
| 读者对同规模爽点不再反应 | 爽点阈值递升：四个维度里至少升一项 |
| 卖点写几章就没得写 | 卖点容量检验：拆得出多少条不重复的展开方向 |
| 换地图 / 换阶段后掉追读 | 旧资产继承：关系、资产、目标是否随主角带走 |
| 支线越写越多、主线停摆 | 支线剪裁：只留服务核心梗的，其余砍掉或并线 |
| 感情戏抢了主线的观感 | 观感一致性：藤蔓必须为骨架服务 |
| 书名简介承诺与正文不符 | 羊头狗肉检验：开篇传递的卖点与实写内容对齐 |
| 多线并进、什么都想写 | 核心梗收敛：只留一条主运转逻辑，其余降为变奏 |
| 加完新机制读者不认了 | 基调贯穿：基调变一次等于换了一本书 |

## 法则清单

### 核心梗的判据
- 核心梗 = 金手指最核心的使用方式 + 读者最想看的爽点模式；只有工具没有用法，或只有用法没有读者想要的那口，都不成立。
- 三问定梗：一句话能说清读者最想看什么；能反复运转（换场景、换对象、换条件还能再跑一轮）；每一轮都给出新东西。
- 三问有一条不过就是桥段不是梗：只说得出一次事件、跑不了第二遍、第二遍没有新意，三者占一即降级。
- 三层递进：立意（主题）→ 题材核心（这类题材独有的吸引力）→ 核心情绪（完整的期待到满足链条）；缺哪层哪层会露怯，没有立意的文字干瘪无情绪。
- 核心情绪不等于爽点形式：装逼打脸是演出方式，真正要交付的是情绪链条。
- 构建顺序：先定核心情绪（读者要看什么）→ 再定情绪套路（怎么让他感受到）→ 最后定具体事件。
- 平替测试：把背景、身份、时代换掉机制仍成立 = 卖点在机制上；一换就散 = 卖点寄生在背景上，写不长。

### 单元循环与断期待
- 每个剧情单元至少占一项：卖点相关的期待点、卖点相关的爽点、或两者之间的过渡。
- 两种运转模式二选一：不断循环型每单元跑一遍机制、变奏场景与对象；只运行一次型围绕同一核心情绪分阶段推进。选错模式，前者写成重复，后者写成断档。
- 断期待的判定：某单元既无期待点也无爽点，前一个爽点已结清，本身又没拉起新期待，读者从这里开始流失。
- 卖点首次运行不晚于开篇的剧情单元，最迟在该单元内完成铺垫；连续多个单元不运行即视为失效。
- 卖点要扫到配角与反派：核心梗只在主角身上运转、其余角色当工具用，故事会高开低走。

### 复用与保鲜
- 保鲜的上策是换变量不换机制：场景、对手、条件、代价逐轮变，机制本身不动。
- 每轮兑现至少在四个递升维度中升一项：影响力范围、人物层级、收获价值、认知颠覆。
- 递升失效的三个信号：读者对同规模爽点不再反应、升级没有差异化展示、人际网没随等级更新。
- 卖点用完必须升级：同一桥段生硬重演即审美疲劳，宁可少用一轮也要换代。
- 五种保鲜手法：精炼（把已有套路做到极致）、升级（框架不变、元素上档）、加料（框架内换新元素）、反套路（掉转预期方向）、组合（两个不相干的套路捆在一起）。
- 错位生落差：时间、环境、身份任错一位，落差本身就是戏剧性。
- 感情线不走「接触升级」的一次性路线，改走稳定人设加变化情境的循环；升温靠共同困境、互相理解、意外发现。
- 微创新的口子只开在人物、人物关系、情节三处，且点数要少；口子开多了等于换梗，也超出读者对这本书的期待边界。

### 卖点与支线
- 事业线是骨架、感情线是藤蔓：主线必须落成「一件事」，升级只是做事的手段，不能顶替主线本身。
- 支线只留服务核心梗的；不服务主线的支线砍掉或并线，不在卖点上加戏的支线一律不写。
- 卖点要与矛盾网对齐：纵向的上下级压制、横向的平级争夺、交叉的三方互牵至少各有一条在转，且都落在卖点的射程内。
- 卖点偏去满足别的题材的需求就是偏题，读者的回敬是「这书不是我要看的」。
- 感情线的观感必须与主线一致；观感偏移即核心梗偏移。
- 卖点所需能力要与世界观压迫度匹配：机制只会解一类矛盾时，硬换题材必须先补设定。

### 稀释与跑偏的识别
- 三种跑偏形态：核心梗被搁置、卖点被同类桥段稀释、核心情绪崩坏（换地图清空旧关系资产、全员变工具人）。
- 单一情绪走到黑会麻木：悲壮、悲情、爽到底都要穿插别的情绪；刀人是手段不是目的，多用挫折替代清场。
- 主角目标必须让读者觉得有意义：没有立意的纯装逼打脸，剧情撑不住长期连载。
- 基调贯穿：全文基调变了一次等于换了一本书，金手指发展也不许破坏基调。
- 挂羊头卖狗肉：书名、简介、开篇传递的卖点与正文实写内容必须对齐。
- 卖点被稀释时先减量再加量：先砍掉不服务卖点的剧情，再补新的展开方向。

### 从点子到卖点
- 工序：得到点子 → 评估开发潜力 → 放进合适的题材 → 提炼核心卖点 → 加工成情绪缺口与读者期待 → 梳理故事雏形 → 动笔验证。
- 提炼阶段就把卖点拆成情绪缺口与期待：读者不认「我想看这个」就退回换题材。

## 自检清单

- [ ] 能用一句话说出「读者翻开这本书最想看什么」
- [ ] 卖点换场景、换对手、换条件后还能再跑一轮
- [ ] 每一轮运转都给了新东西，不是同一桥段重演
- [ ] 立意、题材核心、核心情绪三层都写出了定义
- [ ] 核心情绪是完整的期待到满足链条，不只是爽点形式
- [ ] 每个剧情单元至少有一个卖点相关的期待点或爽点
- [ ] 没有既无期待也无爽点的空白单元
- [ ] 卖点在开篇的剧情单元内已运行或完成铺垫
- [ ] 最近几轮兑现至少在影响力、层级、收获、认知里升了一项
- [ ] 支线全部服务核心梗，没服务主线的已砍或并线
- [ ] 主线能用一句话说成「主角要做成的那件事」
- [ ] 感情线（如有）为事业线服务，观感与主线一致
- [ ] 书名、简介与开篇承诺的卖点和正文实写内容一致
- [ ] 微创新点只落在人物、关系、情节，且数量少到不影响核心期待
