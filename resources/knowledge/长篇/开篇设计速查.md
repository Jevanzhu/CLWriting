# 开篇设计速查

用于连载长篇的开篇期（前三章这一单元）：立起开篇必立的东西、选切口、排信息、埋第一条悬念，并按失效形态反查修改。与本书大纲、账本、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 开篇从天气、风景或成段背景写起 | 从最精彩最有冲突处写起；背景融进冲突 |
| 首章读完，说不清主角在哪、要什么 | 首章亮出主角处境与目标 |
| 主角登场了，读者却记不住他的处境 | 处境三选一 ＋ 人设基点先立 |
| 前三章没见到主角的独特优势 | 金手指基点：不拖过开篇期 |
| 第一个冲突读者不紧张 | 写明解决的收益与不解决的代价 |
| 开篇信息很全却抓不住重点 | 信息分批释放与优先级 |
| 首章挤进多个主要角色就读乱 | 同章主要角色不过三 |
| 有噱头，但读者读完开头就走 | 噱头选型 ＋ 起效后立刻嫁接主线 |
| 主角登场即掉价（见人紧张、无意义内心戏） | 主角要有分量，配角要有特色 |
| 金手指出场像翻日记 | 用危机或困境触发金手指首秀 |
| 开篇与书名、简介对不上账 | 三位一体：开篇呼应书名与简介的承诺 |
| 读者问不出「然后呢」 | 期待感三件套：情绪 ＋ 情节 ＋ 信息差 |

## 法则清单

### 开篇要立起的三件事
- 连载开篇是一个单元而非一章：人设基点、切入点基点、金手指基点在开篇三章内全部到位，切入点最好落在首章。
- 人设基点 ＝ 核心性格与处境，管代入与共情；切入点基点 ＝ 第一个冲突或机遇，管紧迫感与阅读动力；金手指基点 ＝ 独特优势，管期待与差异化。
- 困境型开篇先立人设，优势型开篇先亮金手指；切入点必须与主线强相关。
- 首章要让读者说得出主角在哪、要什么、为什么现在就得要；后续情节与打斗都基于这个目标。
- 主角开场的处境三选一：身处危机 / 令人羡慕 / 被丢入陌生环境。
- 第一个冲突要够重：事先点明解决它能得到什么、不解决会失去什么。

### 开头切口
- 从故事里最精彩、最有冲突的地方写起，不从故事的最早时刻写起。
- 三种开局策略按需选：危机（生死压力起手）、悬疑（悬念勾好奇）、反转（先颠覆预期）。
- 噱头三分法：事件噱头（书名即事件，直接进事件）、金手指噱头（困境 → 目标 → 首次施展 → 小成果）、人设噱头（人设须能持续驱动冲突，单写「杀伐果断」不算）。
- 噱头起效后立刻嫁接主线：事件结束前就接上新目标，不停在噱头里打转。
- 题材开头方向是菜单不是模具：切口、句序、信息释放顺序按本书主角与卖点自选；同题材连续开书照套同一套骨架，开篇就成了可检索的模板指纹。
- 开头策略按投放平台的取舍定：偏节奏的平台先给强情绪与强噱头，偏人物与代入的平台可放慢铺垫、先立角色魅力。

### 卖点与承诺
- 首章要同时亮出主角目标与本文卖点；「升级」「爽文」这类空词不算卖点。
- 卖点分两层：商业性（噱头、创新、新鲜的金手指）与文学性（文风、笔力、世界观）；开篇至少把商业性卖点摆到读者眼前。
- 单一卖点会被同质内容淹没，开篇即需多卖点叠加。
- 每个创意点必须落成具体剧情冲突，停在概念层等于没有这个卖点。
- 书名报金手指与题材，简介只报三件事（处境、金手指能干什么、第一个爽点预览）；开篇须呼应这些承诺，口径不一即违规。

### 信息投放与情绪
- 背景融进冲突：用旁人议论之类的在场动作同时完成背景与冲突，不单开一段铺陈。
- 信息分批释放，优先级：危机感 → 人设 → 金手指暗示 → 世界观；每次释放只服务当前要的情绪。
- 世界观解说至少等到第一个剧情单元走完。
- 情绪走上行与下行交替：每次波动都要有具体信息支撑；先让读者站到主角这边，戏剧性情节必须真写出来。
- 主角要有分量、配角要有特色：不给主角安排见人紧张、无意义内心戏这类掉价表现。

### 期待与第一条悬念
- 期待感三件齐备才成立：情绪 ＋ 情节（人设与动机）＋ 信息差；缺一件，读者就问不出「然后呢」。
- 每条情报都要有期待价值，关键情报要能拉起「然后呢」。
- 开篇先跑通一个小循环（情报 → 收获 → 震惊），后续循环才好提速；第一条悬念要落在开篇期内能兑现的东西上。
- 期待感来源三选一：事业线（结局可预见、过程猜不到）、爱情线（开头抛亮点）、双线缠绕（互相牵扯）。
- 金手指首秀必须由危机或困境触发，不能凭空冒出；金手指须与人设匹配，冷酷的人配搞笑金手指这类组合会违和。

### 失效形态与修改工序
- 大段背景介绍、天气风景开头、世界观解说 → 开头全是「缓」没有「冲突」，删到冲突先行。
- 同章挤进过多主要角色、铺垫过长 → 删无关互动，尽快进主线。
- 序章、楔子、引 → 除非以叙事为主、足够简短且与首章逻辑紧密，否则不用。
- 插叙、切视角、回忆梦境打头 → 开篇以正叙为主。
- 战斗读着枯燥 → 在打斗里穿插恐惧、愤怒、决心等情绪。
- 章节名暴露是铺垫 → 用有戏剧性的标题把读者带进来。
- 改稿工序：按「起 — 转 — 合」查验开篇单元——起段用日常动作立人设并把主线嵌进来；转段叠加危机，给出动力与目标；合段留下短、中期目标，让新篇章开启。
- 改稿工序：过一遍情绪波动线，删无信息支撑的起落。
- 改稿工序：五步自检卖点——核心梗与金手指、围绕核心梗特化的世界观与情节、人设反差、写法特色、能否蹭上当下话题。

## 自检清单

- [ ] 读完首章，能一句话说出主角在哪、要什么、为什么现在要
- [ ] 首章已亮出主角目标与本文卖点，且与书名、简介口径一致
- [ ] 开篇三章内人设、切入点、金手指三个基点均已到位
- [ ] 切入点与主线强相关，不是可随手摘掉的枝节
- [ ] 第一个冲突的收益与代价已写明，读者知道输了会失去什么
- [ ] 开篇单元三段各有功能：起立人设、转给动力与目标、合留短中期目标
- [ ] 背景与世界观没有成段铺陈，由冲突与在场动作带出
- [ ] 信息按危机感 → 人设 → 金手指暗示 → 世界观的顺序分批释放
- [ ] 首章主要角色不超过三个
- [ ] 没有从天气风景开头，没有序章、楔子、回忆或切视角打头
- [ ] 金手指由危机或困境触发，且与人设匹配
- [ ] 开篇跑通一个小循环（情报 → 收获 → 震惊），第一条悬念落在开篇期可兑现处
- [ ] 期待感三件（情绪、情节、信息差）齐备，读者问得出「然后呢」
- [ ] 噱头起效后已接上主线目标，未在噱头里打转
