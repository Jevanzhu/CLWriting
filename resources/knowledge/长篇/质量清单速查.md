# 质量清单速查

用于连载审读与改稿：先按信号定位维度，再逐项核对主线与卷结构、连续性、交付与卖点。与本书大纲、账本、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 读完前三章不知道主角要干什么 | 开局三章 |
| 第二章重复第一章同一类受挫 | 开局三章 + 阶段目标 |
| 章纲上找不到本卷的结算点 | 主线与卷结构 |
| 最近窗口没有可见进展，或连着几章同一情绪母题 | 连载节奏 |
| 旧期待拖过窗口不还，读者说追不动 | 期待交付 |
| 高潮之后没有下一步可看 | 期待交付 + 卖点守恒 |
| 跨卷设定、时间、人物状态接不上 | 连续性 |
| 角色说出他无从得知的事 | 连续性 + 证据链 |
| 人物做事不像本人，或配角用完就消失 | 人物一致性 |
| 收益被配角、机构或巧合无交换拿走 | 卖点守恒 |
| 升级线提前动用后续阶段才该解锁的底牌 | 卖点守恒 |
| 逐章看都成立，整体还是不对 | 审查输出合同 + 根因合并 |

## 法则清单

### 开局三章
- 第一章交代主角处境、主动目标或不可忽略的异常，世界观随行动露出。
- 第二章把阻力、代价或信息复杂度抬到高于第一章，不重复同类受挫。
- 第三章须产出可执行的东西：阶段追查方向、明确目标或第一笔兑现，同时留着更大的问题。
- 关键因果与收益由主角的不可替代选择挣得，不被导师、机构或巧合代领。
- 核心机制在前三章立住两条可验证硬规则，外加一个未解释的例外；例外制造问题，不推翻已立规则。
- 嫌疑人、入口或线索载体退场时，留下可继续追的物件、地点、见证人或权限链。
- 前三章每个章尾都留继续读的理由，低压章的钩可为阶段目标、关系变化或未完成动作。

### 主线与卷结构
- 全书有一个能一句话说清的解决对象，卷是它的阶段切分，每卷各有阶段目标与结算。
- 开卷时读者应能答出：本卷要解决什么、失败代价是什么、哪一层留给下卷。
- 卷末结算落地：状态、关系、资源或认知至少一项与卷初不同，不靠换地点充数。
- 支线与暗线在本卷内向主线交汇；不交汇的并入或推到写明的下卷位置。
- 卷与卷的连接件是一个未闭合期待，不是新地图或新名词。
- 越接近结局并行线越少；中后期不断加新长线判为结构失控。

### 连载节奏与期待交付
- 判断进展用当前卷的窗口口径，不看整篇写了多少；窗口内状态没变即停摆。
- 高压、推进、低压、关系与信息整理章交替，相邻章不同时用同一情绪母题与钩法。
- 短、中、远期期待同时在账；回收旧期待前先立好下一层。
- 单章反转改变下一步行动，卷级反转改变对阶段机制的理解，全书真相不透支。
- 爽点按前置铺垫的厚度兑现，铺多少给多少；被流程、解释或新设定吞掉即失信。
- 兑现后允许短暂低压与可见奖励，不机械地在高潮后立刻追加更大危机。
- 高光落在主角身上并可见；旁观者的震惊是附加值，不是交付本身。

### 连续性
- 设定、时间线、人物状态三者一起对：改动其一，回头核对另两项是否仍成立。
- 换卷处核对人物起点：境界、权限、伤势、关系与已知信息须接得上。
- 角色只能知道自己有途径知道的事；按证据链回推到获知场景，推不出来就是越界。
- 时间线要能复算：行程、倒计时、恢复期与「过了多久」的说法互不打架。
- 已立承诺与伏笔在本卷必须有推进；不推进的回收、延期留痕或明确弱化。
- 新设定、新地图、新谜团不得用来堵旧承诺，也不得一次性倒出。
- 同一事实前后给出不同数值或见证人时，以最早已立版本为准并改后文。

### 人物一致性
- 关键抉择要对得上已立人设；偏离时补可见触发，不放过无因转向。
- 同一人物的口吻、称呼、底线与能力上限跨卷稳定，变化要有过程可循。
- 配角与反派各有自己的目标与行动线；只在本卷服务一次就消失的判为工具人。
- 对手分量与本阶段主角筹码匹配：过弱无压力，过强要靠削弱主角维持，两者都失真。
- 人物成长写成能力与认知的变化，不写成性格被剧情推着换一套。
- 关系变化要有事件依据：亲密或反目的节点能在正文指出是哪一场。

### 卖点守恒
- 开篇承诺的核心卖点按期兑现，收益与高光没有被配角、机构或巧合无交换地拿走。
- 契约四问：结果是否靠主角自己的选择挣到；收益与高光有无对价；本卷有没有提前动用后续阶段才该解锁的底牌；延期的期待有没有付利息。
- 四问全过即安全；能靠补交换、补铺垫或补成本救回即需补强；补不上即契约破坏，先修纲再续写。
- 升级线不得提前顶到天花板：宿敌、身份、真相与能力上限按阶段解锁。
- 被延期的期待在回收时留下一层新期待，不让读者觉得这条线关掉就没别的。
- 卖点强度与卷位匹配：铺垫卷可以少给，但每次给出的都要是真的。

### 审查输出合同
- 阻断项与高风险项必须同时给出三样：可定位证据、失败影响、最小修法；有方向分叉再给一个替代。
- 最小修法要保护后续容量：说明留下什么期待、推迟什么揭示、下一阶段追什么，而不是只让当前几章更热闹。
- 同类症状并到一个根因，优先点出会让阶段目标失效、机制天花板提前或主角因果权旁落的问题。
- 反向检查：删掉安全解释后情绪是否更强、因果是否仍成立；保留的风险情节是否换来更强期待、代价或关系变化。
- 章节功能成立与否，不看是否每章都有高潮或字数配比，只看章节定位与跨章因果。
- 说不出失败影响就不下结论；可增强项只作提示，不当门槛。

## 自检清单

- [ ] 第一章已给出主角处境与主动目标，世界观只随行动露出
- [ ] 第二章的阻力或代价高于第一章，不是同类受挫重复
- [ ] 前三章至少立住两条可验证硬规则与一个未解释的例外
- [ ] 第三章结束后仍留着阶段目标与可追的物件 / 地点 / 见证人
- [ ] 每卷能用一句话说清要解决什么、失败代价与留给下卷什么
- [ ] 卷末至少一项状态与卷初不同，且不是靠换地点充数
- [ ] 当前窗口内有可见进展，相邻章没有同一情绪母题与同一钩法连用
- [ ] 短、中、远期期待都在账，回收旧期待前已立下一层
- [ ] 单章反转改变了下一步行动，全书真相未被提前透支
- [ ] 换卷处人物状态（境界 / 权限 / 伤势 / 关系 / 已知信息）接得上
- [ ] 时间线可复算，行程与倒计时无打架
- [ ] 配角没有只服务一次就消失的，关键抉择无无因转向
- [ ] 开篇承诺的卖点按期兑现，收益未被无交换拿走
- [ ] 阻断项都带证据、失败影响与保护后续容量的最小修法
