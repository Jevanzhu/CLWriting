# 大纲方法速查

用于连载长篇的建纲与回修：把一句话主线推成全书纲、卷纲与章纲，并给出写飞后的回修路径；冲突时以本书大纲、账本、章节细纲为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 一句话主线写不出来，或写得出却定不下终局 | 锚点先行 + 节点设计 |
| 某章好看却与全书无关，主线不见了 | 主线校验 + 事件推进判据 |
| 卷末不知道该收什么 | 卷纲只标起点终点 + 高潮先行 |
| 大纲越写越像正文 | 层级粒度边界（章纲只标目的与钩子） |
| 剧情一段段靠时间往前推，读者跳着看 | 结构分级 + 因果串联 |
| 相邻两段用的是同一种金手指逻辑 | 相似度检查 + 同型不连用 |
| 越写越平，后段给不出比前段更强的刺激 | 情绪值不递减 + 本卷高潮提前定 |
| 写到中段发现偏了 | 回正判据：金手指是否还咬住核心卖点 |
| 伏笔埋了没人提，揭晓时读者已忘 | 线头登记 + 预埋时机 + 碎片逆推 |
| 细纲写完了，落笔还是不知道写什么 | 细纲只写目的与效果 + 详略指派 |
| 卡文推不动，大纲也改不动 | 用结构推方向 + 滚动写时留可调空间 |

## 法则清单

### 推演工序（一句话主线 → 大纲）
- 先定核心创意点并挖出核心卖点，再由核心卖点定主线；金手指跟着主线衍生，不反过来。
- 金手指要担两职：给主角开挂，并不断拉出新目标推进主线；脱离核心卖点即是全书偏航的源头。
- 高潮先行：开卷前先把本卷最大冲突一次写定，再用小剧情填充前面的篇幅；小剧情必须与大高潮或感情线有关，无关即删。
- 节点即大纲：先定起始与终末状态，再拆出通往终末的各条路径（境界、实力、收集等），每条线设子节点，最后往节点间填故事。
- 起始与终末的落差要够戏剧性，且方向相反——好者愈好，坏者愈坏。
- 逆推比顺推省力：先想清要用什么方式让读者满足，再倒推期待点与铺垫。
- 开篇按序搭建：钩子 → 异常处境 → 金手指登场 → 欲望或矛盾运转金手指 → 目标建立；收尾则解决主线高潮并展余波、奖励外留阶段外资源、交代本卷角色结局、为新卷留钩。

### 层级与边界（全书纲 / 卷纲 / 章纲）
- 全书纲只标主体方向、终末状态、核心卖点与主线的绑定；不标分章事件、场景与对话。
- 卷纲只标本卷起点与终点、本卷高潮、阶段目标与收益、要埋的新线与要还的旧账；不标章内过程，也不替下一卷做决定。
- 章纲只标关键事件、本章目的、钩子与伏笔落点、详写或略写指派；不标成稿的对话与描写，不写超纲的花活。
- 判档口诀：一条信息跨卷仍成立归全书纲，只在本卷成立归卷纲，只在数章内成立归章纲；归错档就是粒度失控。
- 自由度分配：全书纲必须坚守，卷纲可适度变化，章纲完全灵活；限制画得越清楚，反而越推得出故事。
- 章纲不是必写项：大纲与细纲够用就不写；要写就按关键事件分段写粗纲，粒度是事件而非逐章。
- 细纲只写目的与效果，不展开具体情节，篇幅远小于正文，每个节点标明详写还是略写。

### 卷内结构（节点与情绪段）
- 每卷套同一套八节点：开篇 → 发展 → 转折一 → 转折二 → 高潮 → 矛盾结果 → 转折三 → 结局，节点可跨多章。
- 转折一给改变格局的信息/事件，须同时具备意外、合理、推动力；转折二赌注高于转折一，且类型不与转折一重复。
- 高潮走快节奏不留水，主角必须展示成长；矛盾结果让读者喘息，战利品用情节展示而非罗列，并顺手为下一弧埋钩。
- 转折三颠覆读者对「结局」的预判，须有前期铺垫；真结局解决核心悬念、收束情感，伏笔不必全清。
- 发展段由数个递进事件组成，每个都推动主线并埋线。
- 情绪段用五折线排：上行 → 下行拐点 → 行动回升 → 虚晃再下 → 爽点爆发；每段可再套一层同结构。

### 剧情单元与相似度控制
- 每个剧情单元都要让主角用金手指的一种新用法换到实利；相邻单元禁止使用同一套金手指逻辑。
- 单元之间要建立因果关系，而非靠时间顺序串联；有因果关系的成组单元即剧情链路。
- 相似度检查四问：矛盾类型、金手指用法、链路位置、结局走向——有一项雷同就得改。
- 匹配度检查三问：进度是否合本卷阶段、场景是否在本卷清单内、人物组合与关系是否一致。
- 情节下行不能源于主角失误；憋屈给一分、报复还十分，下行后用贵人相助、歪打正着补情绪缺口。
- 后段情绪值不得低于前段；同型套路之间要有间隔，不能连着用。

### 线头与预埋
- 地图、阵营、人物、金手指、世界设定、矛盾、收集、感情诸线同时牵引，每条都要写明预埋时机与升级节点。
- 建纲就是给线头登记还账日：埋在哪一卷、哪一卷兑现，都要落成文字，悬着不还的即为废线。
- 开篇就布升级暗示：新目标、实力、资源、感情、人脉、混乱、新线索，给读者明确的期待方向。
- 真相型线索逆推：先定核心真相，再拆成碎片分散到不同章节，每一片揭示都要触发角色的行动或转折。
- 本阶段收束哪条线、暂时搁置哪条，在大纲上写明，别让读者以为这条断了。

### 失效识别与回修
- 写飞的四信号：主角当前行动与目标无关、新章不再建立后续期待、连续多个单元不跑核心梗、后段给不出更强刺激。
- 回修先查核心卖点：金手指一旦脱离卖点，情节再顺也要回正，拖着不改中期必掉。
- 拉回顺序：先把本卷高潮重新写定，再倒推该删的事件与该补的铺垫；偏离段落不是重写，而是重挂回主线的因果上。
- 滚动续写时大纲保持动态：关键节点围绕核心梗发展，细纲留出可调整空间，写得太细反而锁死自己。
- 检验靠结构而非感觉：拿不准下一段写什么，就用八节点或五折线定位所处节点，由结构推下一步。

## 自检清单

- [ ] 全书能用一句话说成「谁去解决什么冲突」，终末状态明确
- [ ] 本卷高潮在建纲时已经写定，前面小剧情都与之或感情线相关
- [ ] 全书纲未写分章事件，卷纲未写章内过程，章纲未写对话与描写
- [ ] 卷纲已标明本卷的起点、终点、要还的旧账与要埋的新线
- [ ] 章纲以关键事件为粒度，且已指派详写 / 略写
- [ ] 相邻剧情单元用的不是同一种金手指逻辑，单元之间有因果关系
- [ ] 后段情绪值不低于前段，同型套路未连续出现
- [ ] 每条线头都在大纲上登记了埋设处与回收处
- [ ] 本卷转折二的赌注高于转折一，类型与转折一不同
- [ ] 转折三有前期铺垫，结局没有把伏笔一次性清空
- [ ] 主角当前行动与主线目标相关，新章已建立后续期待
- [ ] 金手指仍咬住核心卖点，未发生偏离
