# 悬念编排速查

用于单章完整开合的作品编排悬念：疑问怎么立、信息差怎么排、答案与下一个问题怎么接力、什么时点揭、悬空与空转怎么认出来。与作品大纲、单篇细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 通读下来，读者说不出自己等的是什么 | 点名判据：每处疑问报得出名字 |
| 开篇问得比本篇答得上的更大 | 立悬的篇幅边界 |
| 悬念吊着不揭，尾段草草收 | 兑现余量：揭完还得留一段结账 |
| 一处疑问放在哪一段揭都不影响别处 | 时限与代价判据 |
| 揭完一层，后半程没了拉力 | 答案即换问的接力 |
| 读者手里没有主角不知道的东西 | 知情表取差两法 |
| 提前交给读者的事，读起来像剧透不像紧张 | 揭开时点与现场反应链 |
| 悬着的疑问超过两个，读者记混 | 在悬数量上限 |
| 中段与开篇一个力度，读着读着放下了 | 中段抬级 |
| 读者一眼猜到走向，疑问降格成等待 | 错选项要写足理由 |
| 尾段揭开时还剩没结的问题 | 收拢时辰：并入或删掉 |
| 连着两段只把同一处疑问抬得更高 | 空转判据：无新物即拖延 |

## 法则清单

### 立悬
- 悬念成立的判据：同一处信息同时留着两个以上都说得通的走向；只剩一个走向时，把它当答案写出来，不要再拖。
- 每处疑问要能一句话点名：读者此刻在等谁在撒谎、在等那扇门后是什么；报不出名字的疑问不给拉力。
- 疑挂在具体物件上——一件东西、一句原话、一次没做完的动作；挂在「气氛不对劲」上的疑，读者抓不住也没法回收。
- 悬念的规格受篇幅约束：本篇兑现不了的疑问不要立；单篇没有后文替它找补。
- 先给一个与常理不符的现象，再给一个说得通的坏解释，读者会自己推出坏预期，追问就这样长出来。

### 信息差工序
- 工序：列知情表（读者 / 主角 / 对手或知情人，各写已知、未知、误信）→ 挑一组差值 → 定这组差值什么时点收掉 → 收掉的那一段备好现场人物与反应。
- 差值优先取两种：读者先知道、主角还不知情（把即将发生的事提前交给读者，主角照常行事，紧张自己出来）；主角手里有底、在场的人不知情（先亮主角手里的东西，再让他面对不知情的对手，读者等的是对方撞上来的那一下）。
- 瞒住读者的那一份，要选主角视角本来就拿不到的信息；写主角视角却藏住他自己知道的事，读者会读成作者藏牌，改成「他没往那处想」。
- 揭开时点由这一下能炸出什么倒推：先定现场有谁、谁先起反应、谁的关系被改写，再回推摆在哪一段。
- 每一组差值都要写明收拢时点；从头到尾没打算收的差值不是悬念，是欠账。
- 提前告知要配倒计时：把大事拆成逐个逼近的节点，隔一段放一次进展，越到后面节点越密。

### 悬念与反转的接力
- 悬念负责让读者往后看，反转负责让读者回头改判；同一处信息先按一种读法给出，再按另一种读法翻过来。
- 揭一层就换一层：给出答案的那一段，同时留下一个比原答案更近、更重的问题，拉力才接得过去。
- 换上的新问题必须与刚答的问题同源；换成另一件事，读者读到的就是两个故事。
- 反转用事件与事实翻，不用角色独白宣布；由谁说出、在什么场合说出，决定这一下落不落地。
- 给读者一个够分量的错选项：走向只剩一条就没有悬念，错选项理由不足则读者根本不承认它。
- 接力到尾段为止：尾段的反转用来结账，不再开一笔新账悬着。

### 篇幅与强度
- 单篇只立一条主疑问，至多搭一条副疑问；副疑问只负责给主线添证据、添误导或添代价，不自己长成一个故事。
- 强度按位置配：开篇用中强的不对劲，中段靠新信息量抬，尾段前用最重的一击；开篇拉满，后面无处可去。
- 一处的力度看它离兑现还剩多远，不看形容词有多重；越接近答案、代价越大，才越紧。
- 中段必须抬一次级：同类型的疑问第二次出现时，牵扯的人更多或可失去的东西更重，否则是原地循环。
- 给一件事加上时限——必须在某个时刻之前做完或拦下——等待本身就带压力。

### 揭的时辰
- 揭完还要留一段承受后果；只剩收尾几行才揭，账来不及结。
- 读者已经猜到且猜对了，就不要再拖：提前兑现，用省下的篇幅去压下一层。
- 通向终局的主疑问留在尾段，管着中段节奏的小疑问就近兑现；小疑问拖过大半篇，读者只当它不重要。
- 一处疑问该在信息集齐的那一刻揭，不在情绪最浓的那一刻揭；凑齐的人、物、时机是揭的开关，不是心情。

### 过载与空转
- 过载信号：同时悬着三处以上待答问题，读者记不住哪件是哪件；同一时刻在悬的不超过两处，多出来的降成细节或删掉。
- 空转信号一：连着两段只把同一处疑问抬得更高，却没给新证据、新代价，也没牵进新的知情人；原地加压会被读成拖延。
- 空转信号二：这处疑问在哪一段揭都不影响别处，说明它既无时限也无代价，直接删。
- 别用新谜题续命：一处疑问快答出来时又开一个无关的，读者认出套路后不再上钩。
- 收拢时辰：尾段之前把支线疑问并进主疑问，并得掉的并，并不掉的删，不留悬空。
- 一处疑问既没有下一步动作指向它，也没人再提起它，读者会自动把它忘掉——那已经不是悬念，是漏网的问题。

## 自检清单

- [ ] 每处疑问都能一句话点出读者在等什么
- [ ] 每处疑问都留着两个以上说得通的走向，不是一个走向被硬拖
- [ ] 开篇提出的疑问在本篇内有答案
- [ ] 知情表已列全（读者 / 主角 / 对手或知情人各自的已知、未知、误信）
- [ ] 每一组信息差都写明了收拢时点
- [ ] 瞒住读者的那一份是主角视角本来就拿不到的信息
- [ ] 揭开的那一段有现场人物与反应链，不是悄悄告知
- [ ] 揭完一层后有一个更近的问题接上，且与刚答的同源
- [ ] 同一时刻在悬的疑问不超过两处
- [ ] 中段有一次级别抬升，不是同型疑问原地重复
- [ ] 中段悬着的问题都带时限或代价，没有可随便挪位的
- [ ] 尾段之前支线疑问已并入或删掉，没有悬空
- [ ] 尾段的反转只用于结账，没有再开新疑问
- [ ] 至少一处疑问在读者猜到之前就已兑现
