# 情绪释放速查

用于短篇的情绪调度：定下这一篇要给读者留下哪一种情绪，把压与放排成能兑现的账，把每次释放落在动作、台词、物件或后果上。与本文细纲、人物设定冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 说不清读者合上这篇时该留下哪一种情绪 | 主情绪：一篇一种，先写成一句话 |
| 情绪靠形容词硬喊，场面里只有「她很伤心」 | 情绪落点：改成动作、台词、物件、后果 |
| 压了三段没有回报，读者开始滑 | 押注与还账：每笔都记下何时还、拿什么还 |
| 该疼的场面一句总结带过，读者没跟上 | 押注三要素：谁受损、替谁憋着、记在谁头上 |
| 写完没有印象最深的一幕 | 记忆点：只留一处最贵的场面并给足 |
| 伤写了不少，后文没人接 | 还账对价：押多重还多重，还法要看得见 |
| 每段都在顶，读到后面反而麻木 | 过火处置：只留一处最强，其余降一格 |
| 大哭大闹写完，合上却没有余味 | 收声：最痛处写安静动作与物件状态 |
| 前半与后半读着像两篇不同的文章 | 贯穿物：一件东西、一句话系住两端 |
| 情绪转得突然，读者跟不上 | 转向触发：每次情绪变化都要有事件做因 |
| 主角心里翻江倒海，旁人毫无反应 | 反应落地：让具体角色给出可见的反应 |
| 反派坏事做了一堆，读者只烦不恨 | 立足点：伤害写成「唯独他」而他无辜 |

## 法则清单

### 主情绪
- 一篇只认一种主情绪：读者合上时该留下的那一种；其余情绪只能垫它，不能争主位。
- 动笔前把主情绪写成一句话：谁、对谁、从什么情绪起、到什么情绪落；写不出就先别动笔。
- 每场戏回看它把主情绪推向哪里；推不动的删掉或改写，不靠场面数量凑。
- 连续多段没有立场、期待或压力的变化就是停滞；停滞处补事件或补信息，不补形容词。
- 情绪可以中途转向，但每次转向都要有触发事件；无来由的变化，读者读成角色发疯。
- 副情绪按点数用：悲情篇里的一处笑点很贵，多了就把主情绪冲淡。
- 最后一次转向决定余味基调：结尾是释然还是意难平，由它定。

### 押注与还账
- 把情绪当账记：每处让读者受压的场面都是一笔押注，落笔时同写下谁来还、何时还、拿什么还。
- 押注三要素：谁受损（越无辜越痛）、读者替谁憋这口气（共情对象要明确）、这笔账记在谁头上（要能指认到人，天灾不算）。
- 押注要具体：情绪的重量来自具体数字、物件与重复动作，不来自形容词。
- 还账趁读者还记得：拖到连自己都快忘了那笔押注，还回来也读不出解气。
- 还账对价相当：押的是一条命，就不能拿一句道歉来还；拿小事还大账，读者只读到敷衍。
- 还账要看得见：落在具体结果上——东西退了、关系断了、人走了，不停在「她终于释怀了」上。
- 收尾前结清：一篇之内没有下一段可以补账，欠一笔就是烂尾；结不清的押注，动笔时就别押。
- 压放交替：一路压到底或一路爽到底，读者都会脱敏；压上两三次就给一次可感的回暖或兑现。

### 情绪落点
- 情绪不写名词写后果：不写「她愤怒」，写她做了什么——手在抖、门没关、话说一半停住。
- 落在动作上：让身体替情绪说话，抓一个可反复用的动作当标记，每次出现都比上一次重。
- 落在物件上：让一件东西的状态变化替情绪说话；这件东西再出现一次，就是情绪的第二层。
- 落在台词上：最疼的一句往往最平静或最不客气；落在改变关系的那一句上，不落在辩解与补充上。
- 落在后果上：释放必须付得起价——有人离开、有东西失去、有选择再也回不去。
- 落法换着用：同一种落法连用两次，读者第二次就绕过去了；重头释放各换一种落法。
- 「不」是最重的写法：不回头、不解释、不流泪；克制比嚎啕更容易击穿人。

### 贯穿与走完
- 短篇的情绪必须在一篇之内走完：起、转、落三手都要在场；把释放推到「以后」，这篇情绪就是空的。
- 选一处贯穿物：开篇、中段、收尾各出现一次，第三次出现时它的状态已经变了，这就是情绪走完的证据。
- 前三分之一与后三分之一之间要有一条看得见的线连着，否则整篇读成两篇。
- 重复动作可当节拍器：同一动作出现三次、一次比一次用力，第三次就是释放点。
- 转向不按固定间隔卡点：先看情绪铺够没有，够就转，不够就先撤一步再转。
- 释放一旦开始，只写兑现与余味，不再新开事件或补交代。

### 释放不足与过火
- 释放不足的三个现象：读完没有一幕记得住；伤写了没人接；该疼的场面用一句总结带过。
- 释放不足的处置：回到押注账，找出没还的那笔，排成一个看得见、给足时长的场面。
- 过火的三个现象：形容词堆到顶；每段都在最强；大哭大闹把余味冲掉。
- 过火的处置：只留一处最贵的场面，其余全部降一格；最痛处反而收声。
- 最贵的场面要给足：把该场的动作与台词写满，砍掉旁边抢戏的场面，读者的注意力才聚得住。
- 记忆点靠反差：安静处放一个异常、热闹里留一句冷不丁的话；平淡处硬拗重击，读着假。
- 假虐自检：读者只是看着难受、并不心疼，说明押注没落到具体的人身上。
- 割裂自检：前后像两篇文章，说明缺一处贯穿物或主题线；补线，不补字数。

### 按题材取法
- 虐心 / 情感、亲情 / 年代：关系先写具体再碎得动；两边都不站队，各写各的难处，先充分受伤再谈和解。
- 爽文 / 世情、古言 / 复仇：受辱到还账要快，反派嚣张逐次加码；关系设定简洁，账一笔归一笔砸实。
- 悬疑 / 推理：不安靠信息差：先给做了什么，再给为什么做。

## 自检清单

- [ ] 全篇能用一句话说出主情绪是什么、从什么情绪变到什么情绪
- [ ] 每场戏都能说出它把主情绪推向了哪里，没有推不动的场面
- [ ] 每处让读者受压的场面都写了「谁来还、何时还、拿什么还」
- [ ] 每笔押注都在读者还记得的时候兑现，没有悬空的账
- [ ] 还账的对价与押注的分量相当，没有拿小事还大账
- [ ] 情绪落在动作、台词、物件或后果上，没有直接写情绪名词
- [ ] 没有连续多段原地打转，每次转向都有事件做因
- [ ] 贯穿物在开篇、中段、收尾各出现一次，末次状态已变
- [ ] 全篇只留一处最贵的场面，其余处都降了一格
- [ ] 最痛的场面写的是安静动作或物件状态，不是嚎啕与抒情
- [ ] 读完能点出印象最深的一幕，且这一幕有人、有物、有动作
- [ ] 释放开始后没有新开事件，也没有再补交代
- [ ] 结尾停在余味上，没有把主情绪再解释一遍
- [ ] 每笔账都在篇内结清，没有留到「以后」的押注
