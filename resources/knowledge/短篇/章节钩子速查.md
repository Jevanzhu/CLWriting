# 章节钩子速查

用于单章完整开合的作品写开篇与收尾：让第一屏留住读者、让钩子与反转同源、让最后一句落在可判定的地方。与作品大纲、单章细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 开篇前几行还在写天气、铺背景、交代身世 | 开篇第一屏判据 |
| 开头够怪，读者却不追问为什么 | 钩子的双重任务 |
| 反转揭出来，读者觉得跟开头问的不是一回事 | 钩子与反转同源 |
| 反转读起来像解释，翻不出落差 | 反转前先让读者形成错判 |
| 开篇抛出的问题，收尾处接不住 | 开幅不超兑现能力 |
| 中段松，读者读到一半就放下了 | 反转接棒牵引 + 中点认知转进 |
| 结尾收在总结、感慨或主题陈述上 | 最后一句落点判据 |
| 最后一句句子漂亮，却没有画面 | 落到物件、动作、台词 |
| 尾句读完读者还追问「后来呢」 | 收尾闭合，不新增疑问 |
| 收尾时发现开头埋的细节没用上 | 先定最后一句，再回推开篇 |
| 通篇绷得太紧，收尾反而没劲 | 强度曲线 |
| 一篇里开了好几条疑问，收尾只结一条 | 一处钩子对一处兑现 |

## 法则清单

### 开篇钩子
- 第一屏要出现一个不对的东西：可疑的话、反常的细节、被打断的动作；风景与身世交代不能开局。
- 开篇钩子要做成两件事：让读者停在这一句，又让读者想知道下一句的答案；只怪不悬的开头留不住人。
- 钩子落在具体物上——一件东西、一句原话、一个日期；落在氛围或情绪上的钩子，读者抓不住。
- 开篇提出的疑问必须是本篇答得出的疑问；问得比篇幅能答的更大，收尾必塌。
- 开篇的牵引只用到反转为止：反转本身就是后半程的钩子，不必让开头承担全篇的拉力。
- 反差开局：把两个不该并置的场景或状态摆在一起，先让读者自己问这两件事怎么会在一起。

### 钩子与反转
- 钩子向读者提的问题，与反转回答的问题必须是同一个；不同源时，反转只会被读成解释。
- 反转前要让读者形成一个错误的结论：只留白、不给线索的写法，翻过来时没有落差可翻。
- 反转不是给出答案，是把同一个细节重新解释一遍：前一种读法让读者误判，后一种读法推翻它。
- 反转后回看开篇，读者应读到第二层意思；读不到，说明开头的细节没挂上反转。
- 反转的位置服从情绪：情绪铺够就翻，不够就先撤一步再翻，不按篇幅比例卡点。
- 反转要靠事件与事实推翻，不靠角色独白宣布「原来一切都是……」。
- 留一处第二遍才看得见的铺垫：耐读来自重读时的第二次解释，不来自信息的数量。

### 牵引与兑现
- 中段要有一次认知转进：一条新信息让读者对同一件事的看法改变一次，否则后半程只是在往前推。
- 每处吊起的期待都要在收尾前兑现；兑现可以是答案，也可以是让这个问题不再重要的替代答案，但不能绕开。
- 收尾不新增疑问：单章作品的收尾要闭合，结尾可以留余味，不能留一个悬着的问题。
- 收尾前把支线收进主线；收不进的删掉，或降成主线里的一个细节。

### 强度取舍
- 钩子强度受兑现能力约束：收尾兑现不了的期待不要吊，吊过头的开头最后都成虎头蛇尾。
- 宁弱勿欠：单章作品没有后文慢慢找补，欠下一处期待就直接读成烂尾。
- 强度曲线：开篇中强、中段靠信息增量、收尾最强；开头就拉到顶，后面无处可去。
- 一处钩子只对一处兑现；同时开多条疑问线，单章篇幅内必有悬空的。
- 强钩子靠信息差与反差，不靠形容词堆紧张；形容词制造的紧张，读者第二句就免疫了。
- 反转之后仍要有一段紧绷：答案给出后读者的兴趣会掉，用后果或代价把拉力接回来。

### 收尾落点
- 把最后一句单独抄出来读：能读出画面与反常就算立住，读出一段完整的解释就是没立住。
- 最后一句落在具体的物件、动作或一句台词上，不落在总结、感慨、主题陈述上。
- 落在反应上：只写谁做了什么、谁的脸上变了什么，不写他悟出了什么道理。
- 最后一句里要有人；落到环境或抽象概念上，等于把收尾交给风景。
- 回声式收束：最后一句复现开篇的句子或细节，关键处已被反转改写，同一个句子第二次出现时意思变了。
- 最后一句用短句收；长句会把刚聚起来的力泄掉。
- 落在台词上时，让台词偏离读者预期半句：读者等着的那句不说，说它后面那句。
- 上翘式收束：答案落地后补一处小信息，让读者多停一秒；这处上翘只改意味，不添新的疑问。

### 工序
- 先定最后一句，再回推开篇钩子：收尾的落点决定开头该埋哪个细节、该把哪部分藏住。
- 动笔前把「开头抛出的问题」与「收尾给出的答案」写成相邻两行；对不上就换钩子，不换答案。
- 开篇改完重读收尾，收尾改完重读开篇：两端互为对方的判据。

## 自检清单

- [ ] 开篇第一屏有具体的异常，不是天气、风景或身世交代
- [ ] 开篇提出的疑问，收尾正面回答过
- [ ] 开头给足了让读者形成错误判断的信息，不只是留白
- [ ] 反转推翻的是读者的先入判断，不是角色的嘴
- [ ] 中段有一次看法被新信息改写的转进
- [ ] 每处吊起的期待都在收尾前落地，没有悬空的
- [ ] 最后一句是具体画面，不是总结、感慨或道理
- [ ] 最后一句里有人的动作，不是环境或抽象概念
- [ ] 最后一句用短句收，没有被长句泄力
- [ ] 收尾闭合，读者不会追问「后来呢」
- [ ] 收尾后的小上翘只改意味，没有新开疑问
- [ ] 强度曲线是开篇中强、收尾最强，开头没有拉到顶
- [ ] 开篇埋的每个细节都在反转或收尾处用上
- [ ] 首句与末句并排读，说的是同一件事的两面
