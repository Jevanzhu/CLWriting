# 题材公式速查

用于短篇按题材配配方：先认出这个题材的兑现点，再定反转位与情绪落点，最后用错配与疲劳信号回头修。与本书设定、大纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 开篇几段读完，还不知道在看什么题材 | 兑现点先行：第一个题材承诺挂在开篇 |
| 要素齐全，读者却说「没内味」 | 兑现点定位：先查读者点进来要的那一股情绪 |
| 桥段都写到了，读者却不激动 | 反差点兑现：情绪靠对比，不靠抒情 |
| 情绪释放的次序别扭、爽得不合时宜 | 情绪链次序：先虐后爽的题材不许提前给治愈 |
| 反转抛出去了，却没响 | 反转位前因检查 + 反转后立刻给后果 |
| 读到一半就猜到了底牌 | 底牌留到后四分之一，中途只交代部分真相 |
| 高潮场面热闹，却不解气 | 高潮逆推：势能翻转处必须有前因堆到位 |
| 结尾不知道停在哪 | 结尾三件：对手下场、主角选择、可感后果 |
| 同款配方连着写三篇 | 换兑现路径，不换题材期待 |
| 读者能替主角想出下一步 | 换代价值：加代价、换视角、改关系位置 |
| 读者比自己更早看出在按套路走 | 高频套句与标志性动作按本篇人设自造 |

## 法则清单

### 题材先定配方

- 短篇体量小，没有余裕先养信任再慢慢铺，读者入场时自带的题材期待就是交付形状。
- 题材期待＝这个题材里读者点进来要看的那一件事；写到它才叫交付，没写到写得再顺也是空转。
- 题材先把牵引强度定档：复仇类最强，悬疑次之，情感与年代亲情偏中；强度说的是读者对「下一段会怎样」的默认压力，不是逐节的配额。
- 越是短，越要求每一段都踩在题材的兑现点上；配方不是偷懒，是短篇唯一来得及兑现的交付形状。
- 标签不等于题材：同一个标签下可能是两种配方，先定这一篇卖的是信息差，还是力量碾压。
- 题材装置只服务情绪线：重生、系统、身份、超自然都只是让那股情绪成立的工具，装置本身不占交付位。

### 兑现点与情绪落点

- 先用一句话写清「这一篇读者要的情绪是什么」，之后每个桥段都拿这句话筛一遍。
- 每个题材有一组必选场景，缺一个读者就觉得没交付；场景按情绪链排序，不按事件发生的方便排序。
- 情绪靠反差兑现：反派越得意，翻转越强；主角越平静，压迫感越足；平静与残忍同框才有力。
- 兑现要升级不要重复：同类桥段按对方嚣张度、付出的代价、见证范围逐级加码，同级再来一遍就是注水。
- 情绪链不许乱序：先憋屈后释放的题材要把憋屈写足，先虐后爽的题材不能提前把治愈发出去。
- 每小节至少一个状态变化（信息、关系或处境）；连着几节原地打转，先停下复核再往下写。
- 小节的长度服从动作链是否走完，不按固定字数切；感官细节揉进动作节拍，别单独成句。

### 反转位与高潮位

- 反转类型由题材的兑现方式定：靠真相与证据翻盘的，反转是信息差兑现；靠身份与实力翻盘的，反转是力量兑现；配错类型，反转再响也不对味。
- 最大底牌留到后四分之一才揭开；中途每处反转只交代部分真相，并顺手带出一个更大的问号。
- 反转位前面必须有前因堆到位；前因不足的高潮只是吵闹，读者会替它尴尬。
- 反转之后立刻给后果：对方下场、格局变化、关系翻转。不给后果的反转是空翻。
- 压抑段与释放段是一组：压抑是为了攒释放，只压不放会闷，只放不压会轻。
- 高潮位是势能翻转的那一刻，此前埋下的东西都该在这一刻被读者回头看懂。
- 结尾职责三件：交代对手下场、主角选择、可感后果；收尾的余韵长度服从余波，不另开新矛盾。

### 错配的识别

- 错配的第一症状是元素齐全但不是读者要的情绪；先查兑现点，再查情绪链，最后才轮到文笔。
- 别把装置当题材：有重生不等于逆袭，有鬼不等于悬疑，有身份不等于宅斗；装置必须挂在核心情绪上。
- 公开对质要有围观关系网：只有围观者的存在能改变结果时，这场面才成立，否则只是换个地方吵架。
- 时代与地域质感靠具体物件、习俗、称谓落地，不靠旁白交代。
- 主角的强要由行动与选择展示，不靠心声自述；反派的恶要出自自洽的利益与处境。
- 对手一旦纯坏，行为就可预测；给他一个能自圆其说的处境，他的每次出手才有意外。
- 标签与兑现点不符时改兑现点，不要改标签：读者的期待来自标签，改标签等于换读者。

### 配方用旧了怎么修

- 疲劳的第一信号是「同款配方连着写三篇」，第二信号是「读者能替主角想出下一步」。
- 修正优先换兑现路径，不换题材期待：读者要的还是那股情绪，换的是达成方式。
- 四个可换的变量：视角、关系位置（外人换家人）、代价（每次胜利都收走一样东西）、反转位（提前或拆成两段）。
- 高频套句和标志性动作最容易变成检索指纹：方向可以留（冷静反差配权力宣告），句子必须按本篇人设自造。
- 反套路是配方加一处替换，不是取消配方；配方撤了，读者会找不到自己在看什么。
- 主角一路顺会显轻：给每次胜利加代价，或让对手的失败带出新的窟窿。

## 自检清单

- [ ] 能用一句话写出这一篇读者要的情绪，且每个桥段都服务于它
- [ ] 开篇已兑现第一个题材承诺，读者不必等到后半段才知道在看什么
- [ ] 这个题材的必选场景已全部到位，无一缺席
- [ ] 情绪链次序正确，没有把后段的情绪提前释放
- [ ] 同类桥段逐级加码，没有同级重来
- [ ] 每个反转前都有前因铺垫，反转后立刻给出后果
- [ ] 反转类型与题材的兑现方式一致，没有信息差型与力量型混用
- [ ] 最大底牌没有在最后四分之一之前用掉
- [ ] 每小节至少一个状态变化，没有连续原地打转的小节
- [ ] 结尾交代了对手下场、主角选择与可感后果
- [ ] 反派的作恶逻辑自洽，出手不能被读者一句话猜到
- [ ] 公开对质的场面里，围观关系网确实能改变结果
- [ ] 没有照搬标志性动作与高频套句，动作与台词均按本篇人设自造
- [ ] 每个胜利都付了代价或留下窟窿，没有一路无代价的通吃
