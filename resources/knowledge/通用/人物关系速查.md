# 人物关系速查

用于设计角色关系与感情线：关系类型、人设核心、好感推进、配角与负面角色。与本书人物档、大纲、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 要定两个角色的关系性质 | 关系四型，先认功能再写戏 |
| 感情线人设空、不知写什么 | 人设核心法：定核心 → 追成因 → 延伸剧情线 |
| 拿不准爱情线往哪写 | 先定目标读者群，再选「展示优秀」或「深化连接」 |
| 穿书 / 穿游戏选角 | 熟悉原世界 + 角色自带强矛盾 + 留信息差 |
| 多角关系收不住 | 控烈度；对象之间不许有不可调和的矛盾 |
| 好感推进突兀或油腻 | 好感度 × 关系阶段，按低的一方算 |
| 角色像被剧情推着走 | 自洽四步：排除外部强推 → 定目标情绪 → 按人设推导 → 校验一致 |
| 配角只会站着等触发 | 保缓冲区 + 拐点标注态度变化 |
| 写宿敌 / 亦敌亦友 | 双方都立得住，认可与冲突并存 |
| 恋爱线拖累事业线 | 融合检查：两条线拆开各自能看 |
| 分不清发糖与工业糖精 | 阻碍解决后不再造新矛盾，只发实在的 CP 行为糖 |
| 要用负面角色或竞争者 | 先确认不可替代性，再看使用时机 |

## 法则清单

### 关系与功能
- 关系四型：冲突 / 联盟 / 亲密 / 权威，分别对应张力、助力、软肋、压力；功能必须服务情节，不为甜虐而存在。
- 每个重要关系至少过一次考验（背叛 / 牺牲 / 误解），并有一条变化弧线。
- 禁止所有关系铁板一块；同一角色在不同人眼中的声望是变量，评价差异本身就是冲突源。
- 亦敌亦友最忌单方用力：双方都要有魅力，高度认可与绝对冲突并存，才算宿敌。

### 人设与目标
- 感情流中剧情为人设服务：不能丰满人物或推进感情的剧情，就是无效剧情。
- 人设先行：定核心特征 → 追问成因（经历 / 环境）→ 把核心自带的目标线与治愈线写出来。
- 两个主角都要有闪光点与独立变化路线，不能一人出彩一人黯淡。
- 高光不等于装逼：让读者记住角色的时刻都算高光，包括痛彻心扉的时刻。
- 角色生命里不能只有恋爱，只有恋爱的角色立不住、很单薄。
- 主角目标必须属于自己；把他人交办的事转化成他自己的利益或认可，否则主角沦为工具人。

### 读者群与爱情线
- 先定目标读者群再选逻辑，两套口径混用，读者立刻觉得不对味。
- 男频围绕「展示优秀」设计事件，女频围绕「深化连接」设计事件。
- 男频：主角靠自身品质吸引，不主动追求；主动过头会被读作舔狗。
- 把恋爱当升级文写：暧昧拉扯的过程最有吸引力，每个事件让好感攀升一档。
- 女主付出要贴着人设走，不要写成统一模板。
- 善用对比：与初识态度的反差、只对主角破例的双标、双重身份的信息差。

### 推演与融合
- 极简爱情线三要素：英雄救美建立初始好感 → 事业舞台让好感随成就升级 → 对手衬托兼作感情胜利。
- 女主要有自己的目标，不是花瓶；好感升级绑定主角的成果，不单写纯感情戏。
- 融合检查：删掉爱情线段落事业线仍成立，删掉事业线段落爱情线仍有看点。

### 好感度与节奏
- 两个维度定位：好感度 × 关系阶段，取低的一方为准；好感到了关系阶段没到，行为就是突兀。
- 好感不足时写亲密或妥协等于油腻，这类行为必须给补偿。
- 阻碍解决之后不再设计新矛盾，只发糖；糖用实在的 CP 行为与照顾，不用宣言式工业糖精。
- 关系翻转的上策：两人同时改变，改变后恰好与原先的对应关系相反；只做局部调整，与原人设有明确联系。
- 节奏先慢后快：前期积累好感，后期集中爆发。

### 配角与负面角色
- 配角态度变化的过程就是攻略过程，本身产生期待与爽点；缓冲区要一直保持。
- 在事件拐点处标注配角状态与对主角态度的变化，跨过关键点位时态度变动必须写清。
- 配角不是站着等触发的 NPC：由配角的观点引出事件，正面角色同样要有自己的动机与行动。
- 竞争者（鲶鱼型）用于高潮节点之前的铺垫，不是高潮后续命的手段。
- 亲友助力多在高潮前发挥，亲友阻力前后都能用，阻力更好发挥。
- 负面角色可用，但先确认不可替代性；主角弱势时这类角色会招读者恨。

### 特殊构型
- 修罗场本质是矛盾：控住对抗烈度，对象之间不能出现不可调和的矛盾。
- 收场三法：把争风吃醋转成比事业贡献 / 用突发事件让内斗转为一致对外 / 极克制地一笔带过。
- 傻白甜底线：犯错不能是故意的，也不能违反道德；站在道德高地指责别人是致命伤。
- 反向用法：把这些毛病全套给反派，读者一见就厌恶。
- 后宫要弱化主角「主动渣」感，让女主人设成为推进主力；先做差异化设定，再把「脚踏多船」转化成「守方与共享方」的问题。

### 自洽检查
- 角色「恰好」推进剧情却没有自身动机 = 人设偏移，必须补角色层面的理由。
- 写每段先问三句：本段要让读者产生什么情绪 / 人设是否支持这情绪 / 行为是否符合角色的功能定位。
- 从已有属性推导行为：列出几种可能反应，挑最合人设且最有戏剧张力的一个。
- 角色情绪核心与场景目标情绪不一致时，改角色行为或改场景目标，二者必须对齐。

## 自检清单

- [ ] 每个重要关系已归入冲突 / 联盟 / 亲密 / 权威，且过了一次考验或变化
- [ ] 没有任何一组关系是永远「你好我好」
- [ ] 两个主角都有闪光点与各自的变化路线，角色除恋爱外还有别的生活内容
- [ ] 主角目标属于自己的：随机翻开一章，都能看到他在主动追求什么
- [ ] 爱情线事件按目标读者群的口径写，没有混用两套逻辑
- [ ] CP 行为与好感度、关系阶段匹配，按低的一方计算
- [ ] 好感不足处的亲密或妥协行为已给补偿，读起来不油腻
- [ ] 阻碍解决后没有再生新矛盾，糖落在实在的 CP 行为上
- [ ] 配角有行动和动机，不是站桩等触发；拐点处已标态度变化，缓冲区没被撤掉
- [ ] 多角关系中对象之间没有不可调和的矛盾
- [ ] 删掉爱情线段落事业线仍成立，删掉事业线爱情线仍有看点
- [ ] 负面角色与竞争者的不可替代性、使用时机都已确认
