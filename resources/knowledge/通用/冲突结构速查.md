# 冲突结构速查

用于设计矛盾与冲突结构：主线支线、双线、冲突升级、对抗与反派、感情线与金手指定位、动机与困境。与本书大纲、账本、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 定主线矛盾 | 矛盾四重递进 + 底层矛盾；动机至少两源并用 |
| 搭主线结构 | 高潮逆推 + 主线即冲突驱动 + 支线须汇回主线 |
| 剧情撑不起篇幅 | 用门槛拆阶段小主线；三驱动力反推 |
| 冲突温吞、没张力 | 冲突三标准：升级、有结果、有人阻止主角得到他要的 |
| 设计反派 / 对抗 | 压势不压人 + 反派视角信息差 + 主角行动力三维度 |
| 设计感情线 | 先定事业 / 感情主次；四阶段推进，试探段是核心 |
| 定金手指 / 身份 | 四点统一 + 合格五问 + 能力碎片化融入剧情 |
| 单元不推进 | 核心梗运行节奏 + 事件驱动与价值改变 |
| 拿不准爽点 | 核心爽点须切在主线上；看配角认知变化 |

## 法则清单

### 矛盾与主线
- 矛盾四重递进：人与自我 → 人与自然 → 人与人 → 人与世界。
- 世界观从最根源、最不可调和的矛盾架起；偏离核心梗，中期必掉。
- 主角动机至少两源并用：世界背景（环境逼强）、金手指（机制生利）、人物关系（亲朋遭遇）。
- 危机解决后立刻由配角 / 反派强调「更强才能活下去」，把动机过渡到下一阶段。
- 上一个危机解决时，下一个危机的伏笔必须已埋下。
- 矛盾来源须与题材相容；不相容的冲突再激烈也没有逻辑根基。
- 主线即解决冲突：大冲突拆成小冲突成线，每阶段都要有一个暂时无法解决的核心冲突。
- 支线是完成主线的手段，最终必须汇回主线。

### 结构线
- 高潮逆推：先定一句话结局，反推各层目标与大 / 中 / 小主线；小主线完成后，中主线降为新的小主线，循环推进。
- 明线 = 主角的行动与成长；暗线 = 反派线或隐藏信息线，负责衔接、铺垫、嵌套后续。
- 暗线后期必须与明线交汇，形成本阶段高潮；高潮期支线并入主线或暂时搁置。
- 性价比最高的结构：明线主线带支线，暗线只留一条主线。
- AB 交织（升级类题材）：A 线积累变强，B 线拉出矛盾 → 卷入 → 爆发 → 解决 → 收获，ABAB 交替。
- 角力配比：保持主角稍占上风，每次小角力以主角胜利收，最后给大胜利。
- 核心梗在第一个剧情单元内必须运行一次或完成首次铺垫；连续多个单元不运行即失效。

### 冲突设计
- 冲突三标准：必须升级（言语 → 行动 → 激烈对抗 → 决定胜负）、必须有明确结果、本质是有人阻止主角得到他要的。
- 矛盾决定方向、冲突是其具体表现；写场景时回看它服务哪条矛盾。
- 用门槛把主线拆成阶段小主线，每个阶段都配一个明确驱动力。
- 驱动力反推：先定主角的阶段成长，再用戏剧性 / 矛盾 / 欲望与恐惧各反推一遍剧情。
- 第一幕陷阱：解决第一个冲突的过程中，就埋下引爆下一个冲突的伏笔。
- 超额收获：除当前所需，再给可送人的、暂不可用但一看就强的东西；兼作伏笔与钩子，本身也是爽点。
- 救赎类冲突：让救赎有条件、有代价、有倒计时，把人物逼进两难。
- 核心爽点必须切在主线上；偏离主线的装逼是偏移爽点。

### 对抗设计
- 压势不压人：反派针对地区 / 群体 / 阶层，不针对主角个人；主角被卷入是客观结果。
- 反派被推翻后旧问题未必消失（底层依旧麻木、甚至借主角善意牟利），给新冲突留口。
- 反派密谋要大方写出计划，制造「读者知道、主角不知道」的信息差；不写谜语人。
- 主角行动力三维度：做别人不敢做的、做别人做不到的、做别人没想到可以这么做的。
- 人设是行动的缘由；不能为了意外崩人设。
- 反应力度与设定成正比：高实力者轻描淡写，低实力者隐忍蓄力；暴怒反击是掉价反应。

### 感情线
- 先判断读者为什么点进来：事业线为主则恋爱对象是奖励，感情线为主则情节按对方人设设计。
- 四阶段推进：萍水相逢 → 频繁接触的试探 → 外力隔断 → 克服最大阻碍收尾。
- 试探段是核心：不确认心意下反复拉扯，每次试探都要读得出「甜」与「涩」两种。
- 结局段不再设计新矛盾，专注兑现。
- 高潮后关系升级靠人设对冲：双方都改变，且改变后与此前的对应关系反转；变化须基于原人设。

### 金手指与身份
- 四点统一：社会身份、身世、金手指、性格必须高度一致。
- 显性身份须不断变化；隐性身份与核心矛盾绑定。
- 显性金手指须是能力集合，每次都有新东西；隐性金手指 = 让主角与众不同的性格，中后期供货。
- 合格五问：是否凸显与众不同并能持续解困 / 与世界设定有联系和反差 / 是否喧宾夺主 / 主角实力暴涨后能否仍解决主要矛盾 / 能否顺带表达主题。
- 碎片化：能力拆细融入剧情，未集齐是远期期待，集到每一片至少解决一个冲突。

### 动机与困境
- 除压迫与利益，再给人物一个梦想：动机趋物质、由外力推，梦想求精神、由内驱动；两层叠加人物才立得住。
- 目标须与人设匹配；身份不支持的目标没有说服力。
- 困境循环：环境压迫 → 行动（运转金手指）→ 更大的困境 → 更强的突围；主角始终主动出手。
- 上强度要有度：让读者相信有破局希望；后期压力必须高于前期。
- 设定推演：环境 + 人物 = 情节；每加一个设定点做一次逻辑推演，挑最贴核心情绪的设定组合。
- 先有趣再有用：先保证情节有戏剧性，不够有趣时再用铺垫拉期待。

## 自检清单

- [ ] 矛盾按四重递进逐层推进，底层矛盾与世界观绑定
- [ ] 主角动机至少两源并用，且已为下一个危机埋好伏笔
- [ ] 主线能用一句话说成「解决某个冲突」，支线最终汇回主线
- [ ] 每个阶段都有一个暂时无法解决的核心冲突
- [ ] 主线由高潮逆推得出；暗线（如有）与明线在本阶段交汇
- [ ] 本阶段冲突逐级升级且有明确结果
- [ ] 反派动机自成逻辑，信息差不是靠谜语人
- [ ] 感情线（如有）按四阶段推进，结局段未再添新矛盾
- [ ] 金手指过了合格五问，四点统一，能力已碎片化融入剧情
- [ ] 核心梗在第一个剧情单元内已运行或完成铺垫
- [ ] 每个事件至少一个价值改变，且能推进主线
- [ ] 核心爽点切在主线上，反应力度与人设匹配
