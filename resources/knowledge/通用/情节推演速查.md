# 情节推演速查

用于推演剧情：主线定义、小纲细纲、高潮构建、卡文自救与节奏控制。与本书大纲、账本、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 要写小纲 / 细纲 | 小纲四步法：分段 → 标目的与效果 → 标详略 → 保证后续可快速定位 |
| 要设计高潮 | 高潮逆推 + 五步公式：先定爽点，再倒推所需铺垫 |
| 主角刚变强，下一步不清楚 | 立即引入新挑战或新目标；每次提升后马上给下一个门槛 |
| 卡文、剧情转不动 | 查「题材 + 金手指 + 主角身份」三要素是否统一，用循环模式重启 |
| 剧情撑不起篇幅 | 设门槛（系统性条件），且门槛须围绕核心卖点 |
| 追读下滑、反馈无聊 | 查信息团密度与期待线；给低密度章补一个「想知道后续」的点 |
| 要换地图 / 换阶段 | 新旧联动 + 带人走 + 提前铺垫；保留至少一条贯穿主线 |
| 拿不准是否自嗨 | 自嗨三问，有一问答不好即停下修正 |

## 法则清单

### 主线与结构
- 主线是**一件事**，不是一个元素；升级只是达成目标的行动，不是主线本身。
- 主线写成元素罗列或升级条 = 锚点错误，后续剧情会整体偏掉。
- 三层套娃同时运行：大（全书主线）/ 中（卷或阶段目标）/ 小（剧情单元的即时目标）。
- 主线完成后，要么靠铺垫开启第二条主线，要么完结。

### 小纲与细纲
- 细纲只标目的与效果，不展开情节；细纲与正文比例约 1:2.5 ~ 1:3。
- 四步：分段判断 → 标注目的和效果 → 标注详写 / 略写 → 保证后续能快速定位本段要交付什么。

### 高潮构建
- 五步按序执行：蓄能 → 假胜 → 崩解 → 交叉死磕 → 悬置收尾。
- 蓄能 = 牺牲与焦灼打底，把读者从看客变成参与者。
- 假胜 = 先给希望再击碎；情绪落差就是反转冲击力。
- 崩解 = 伏笔一次引爆，并推入单人绝境（帮手全失）。
- 交叉死磕 = 对抗线与绝境线来回切换，每切一次紧张感加一。
- 悬置收尾 = 胜负不立刻揭晓，余劲不散。
- 假胜适合强反转 / 强压迫 / 大高潮；低压章、纯奖励章、关系回收章可不用——但必须另给情绪落差或明确兑现。

### 逆推与铺排
- 高潮逆推：先确定高潮，再反推它需要的人物与情节铺垫。
- AB 粗纲：A = 压情绪 / 铺垫 / 伏笔，B = 抬情绪 / 小收获；ABAB 交替排列，写作时只关注当前段。

### 卡文自救与循环
- 核心公式：题材 + 金手指 + 主角身份 = 循环模式，三要素必须统一。
- 六种循环：案件串（信息差 + 推理）/ 扮猪吃虎（读者与角色的信息差）/ 资源积累（螺旋上升）/ 戏剧性反转（不依赖数值膨胀）/ 组织枢纽（信息交换 + 多线）/ 公路片（靠人物塑造力）。
- 设定多一条，循环元素就多一层；把设定写丢了 = 把卖点写丢了。

### 设门槛（拉长剧情的核心技巧）
- 门槛不是放一个敌人挡路，而是系统性条件：达成目标必须满足一系列条件。
- 门槛须围绕核心卖点设计；脱离金手指与脑洞的门槛是无效剧情。
- 门槛分批提出，不要一次全甩给读者；每跨过一个立刻设立下一个。

### 期待与节奏
- 三层期待同时在线：短期（下一章发生什么）/ 中期（这个单元怎么收）/ 长期（主角最终能否达成）。
- 「两长一短」：当前单元的短期期待只能有一个，长期期待留一到两个。
- 信息团 = 一段剧情的核心信息单元，每个必须能一句话概括；密集 = 节奏快，稀疏 = 节奏慢，为零或与主线无关 = 水章。
- 高密度与低密度章交替，不能一直高或一直低；每个低密度章至少埋一个让读者想知道后续的点。
- 单元高潮前提前插入下一单元的期待线；当前目标完成前给出下一目标的线索。

### 连续性与过渡
- 元素热度四态：hot（当前驱动冲突的核心）/ warm（近期活跃）/ cold（超安全线未触及）/ archived（已完结或有意关闭）。
- 有效触碰 = 直接推进线索、施加压力、改变关系状态、产生实际后果、交代合理休眠原因；纯提名、空头回调、随机提及都不算。
- 单元故事结束前先把下一个目标拉出来；过渡章必须维持至少一条活跃期待线。
- 过渡场景没有信息量就跳过；场景切换在悬念点切出，不在平淡处切出。
- 换地图 = 新环境 + 新角色 + 新规则 + 新目标 + 新冲突；换前旧地图核心冲突至少阶段性解决，换后开头几章快速重建代入感与期待。
- 换地图升级循环：更大规模、更高门槛、更强对手；旧角色不一刀切抛弃，新设定不一次性倒出。
- 伏笔先定结局再倒推线索，长线伏笔必须记录；信息延迟超过三章且中间无推进 = 谜语人，删掉或提前给。

## 自检清单

- [ ] 主线能一句话说成「一件事」，不是元素罗列或升级条
- [ ] 大 / 中 / 小三层次同时有事可看
- [ ] 本次高潮五步齐备；若不用假胜，另给了情绪落差或明确兑现
- [ ] 循环模式与题材、金手指、主角身份三要素统一
- [ ] 门槛围绕核心卖点，且已分批提出
- [ ] 三层期待同时在线，短期期待只有一个
- [ ] 每段都能一句话概括在讲什么；无关信息团已砍或改为服务主信息团
- [ ] 高 / 低密度交替，没有连续高压或连续平淡
- [ ] 没有「该 warm 却 cold」的元素；核心角色与主要支线在安全线内有过有效触碰
- [ ] 过渡场景中无信息量的部分已删，场景在悬念点切出
- [ ] 换地图保留至少一条贯穿主线，旧地图核心冲突已阶段性解决
- [ ] 自嗨三问（写给谁看 / 他们想看什么 / 本书哪些内容是他们想看的）全部答得清
