# 写作技法速查

用于场景与句子落地：情绪、描写、物件、分段、节奏、群像、标点。与本书大纲、账本、细纲、文风档冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 要写情绪节点 | 情绪落地判断：上下文是否已成立 → 是否改变下一步 → 场内事物能否承载 → 直写是否更准 |
| 句尾又补一个身体细节 | 删除测试：删掉有损失吗？换个名字换间房仍成立吗？ |
| 要写「危险」的设定 / 能力 / 威胁 | 用一次有代价的试探演示，不由叙述者断言 |
| 要写物件 / 金额 / 年数 | 贯穿道具三次出现；数字二次锚定 |
| 一章读完平淡，或连续全动 / 全静 | 动静按整章起伏算，不逐段配一个动与一个静 |
| 场景像在交代，或描写堆成三段 | 细纲是规格不是形状：演出来，维度织进同一镜头，状态变化给台阶 |
| 段落一块密、眼睛看累 | 断段按镜头与信息变化；最重的一句最短 |
| 通篇报名字，读着卡 | 段首点名，段中流动，转折再点名 |
| 不知哪里该详、哪里该略 | 疏密分配 + 同类并列项递减 |
| 小节偏短，想加水 | 反注水规则；人物余韵是豁免不是配额 |
| 群像像合唱、所有人一起转向 | 镜头准入 → 反应分层 → 说话权分级 |
| 要点出这件事厉害 / 难得 | 标价人当场标价，且在事情起效之前；尺子先出场 |
| 要定语气与标点 | 先定这句话在场景里做什么，再选标点 |

## 法则清单

### 情绪落地
- 情绪没有固定译法：上下文已让读者感到就删掉补充说明；同一节点只取最有信息量的一种。
- 情绪推动剧情时写选择、台词、策略或关系与物件的变化；身体细节只在有新信息或有后果时写。
- 不把「动作 + 身体 + 比喻 + 心理解说」叠成四重注释。
- 删除测试：删掉无损即删；换个名字、换个房间仍成立 = 通用表演，回整段重写。
- 设定、能力与威胁同理：用一次有代价的试探演示，保留读者的发现权，不由旁白先给答案。

### 物件与数字
- 每个叙事单元设一到两个贯穿道具，各出现三次且意义不同：初立意义 → 中段被颠覆 → 结尾暴击。
- 用具体数字顶替「很久」「很多」；数字的变化推进情节（逐次增大，或极端膨胀后骤降）。
- 二次锚定：数字不许停在数字上，要折回角色能用掉的东西；新价值换算成读者已付过代价认识的旧价值，换算在同一段里做完。

### 场景与描写
- 细纲各字段是「要发生什么」的规格，不是正文的形状；照着逐格填就是电报体。
- 演出来，不是交代出来：把情节点演成角色此刻可感知的选择、动作、对话、物件与结果。
- 状态变化要给台阶：让读者看见中间态（先怎样、跟着怎样、最后成了什么）；换十种说法说同一状态仍只有一个台阶。
- 视角锁死主视角角色的此刻感知：不拉远镜头、不切他人内心、不提前剧透。
- 主观偏差代替客观叙述：场景被角色情绪染色，不写谁看都一样的描述。
- 发生、感知、反应是可选维度不是配额：确有其内容才写，且织进同一镜头。
- 堆叠式描写绝对禁止：同一动作被掰成发生、感知、反应三段写三遍。
- 文风按题材借语感，不套万能腔，不机械拉长或压短句子。
- 章尾落在最后一个具体动作、画面、台词或悬念上，不写状态总结句。

### 句式与分段
- 断段按镜头与信息变化（新动作、新物件、视线转移、直接引语、判断落下），不按维度变化。
- 最重的一句要最短：底牌、定生死的话、身份被说破，用最短一段承接；长度表达绵延，不表达重量。
- 名字承担主语重置与强调，不承担每句打标签：段首、切换、多人同场点名，段内用代词或省略。
- 动作串用虚词接出先后与因果，不写成逗号清单；少写「没做什么」，多写人物做了什么。
- 对话带口气；比喻用中文现成的说法，不造跨感官新搭配。
- 标点跟语气走：先定这句话在场景里做什么，再选标点；停顿靠短句、动作与换行，不靠拖音标点。

### 节奏与疏密
- 一章整体要有推进与停顿的起伏，但不给每个小节配一个动与一个静。
- 停顿来自信息悬置、对话空白、环境压力或角色暂不行动，不等于擦灰、理衣领一类微动作。
- 爆点可以突然安静，低谷也可以持续劳动；连续全动或全静先复核是否出于有意。
- 疏密分配：爽点、打脸、反转、情绪高潮逐拍详写；过场、赶路、信息交代一两句带过；铺垫取中。
- 同类并列项递减：第一个写足，第二个减半，后面一句带过，每项仍留一个不重复的记号。
- 判为「密」的地方禁止用「七八下」「半晌」把过程折成数字，只挑出具体的几下逐拍写。
- 反注水：不为凑字数加环境描写、重复情绪、内心独白、无意义动作或流程细节；删掉无损就删。
- 显式例外——人物余韵：给人物加层的段落不问推进了什么，问删掉之后谁少了一层；是豁免不是配额，没长出来就不补。
- 小节偏短先诊断：缺信息补维度，缺交锋补对话，冲突没演到位回细纲补事件，不拿感官与回忆注水。
- 角色办一件具体事被卡住时用卡点，卡出信息、关系、代价、选择或伏笔；删掉无损失就不是有用卡点。

### 群像与标价
- 写一个人之前先答他在保什么、在算什么；答不上来不给镜头，给了镜头就要在台词或动作里露出来。
- 遮住名字能否认出这句反应是谁的？认不出就是同一句话的几种说法；反应要分层，全体折服最没张力。
- 一场戏只给少数几个人台词，其余降级为一个动作或一个目光；地位越高动作越少，同级同立场合并成一句。
- 点名的时机就是承担功能的时机，提前点名是提前许诺。
- 「厉害 / 难得 / 要命」由有立场的人当场标价，不由叙述者断言。
- 尺子要先于被度量的事出场，事后补一轮尺子也可以。

## 自检清单

- [ ] 情绪节点已按判断落地，无功能微动作已删（不是换同义词）
- [ ] 关键处没有四重注释，也没有发生、感知、反应三段式堆叠
- [ ] 贯穿道具出现三次且意义递进（或本单元有意不设）
- [ ] 数字有具体重量，或已折算成读者认识的旧价值
- [ ] 正文由场景演出，不是细纲形状的逐格填答
- [ ] 状态变化给了中间态，不是只给起点与终点
- [ ] 视角没拉远、没切他人内心、没提前剧透
- [ ] 章尾落在具体动作、画面、台词或悬念上
- [ ] 最重的那一拍用了最短的段落
- [ ] 详略不均：过场已压到一两句，密处逐拍展开，不用量词概括
- [ ] 群像里每个人都在为自己争取，遮住名字认得出是谁
- [ ] 该标价的地方由在场者当场标价，尺子先于事情出场
- [ ] 凑字数的描写、重复情绪、流程细节已删；人物余韵该留的没砍
