# 对话技法速查

用于写对话场景：模式选择、权力博弈、潜台词与议程、信息嵌入、差异化和节奏。与本书人设、大纲、章节细纲冲突时以它们为准。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 主角碾压 / 打脸 | 压制模式：对方长篇，主角极简回应 |
| 主角亮底牌 / 反转 | 反转模式：对方嚣张 → 主角一句事实 → 对方沉默 |
| 关系破裂 / 心死 | 心死模式：回话越回越短，直至「随意」 |
| 日常互动 / 立人设 | 让配角参与冲突，不让主角独白 |
| 群众震惊 / 弹幕 | 递进：普通人震惊 → 专业人士分析 → 特殊身份者反应 |
| 要交代设定与世界观 | 用角色语气与立场包裹信息，不做原理讲解 |
| 情绪拉扯 / 虐心 | 上行与下行交替，像拉锯一样拉升期待 |
| 通篇一问一答像审讯 | 改为一方主动说，另一方给反应 |
| 冲突不够劲 | 冲突逐级升级，不一次到位 |
| 多人对话混乱没营养 | 写前给每个角色定功能：信息 / 情绪 / 冲突 |
| 对话平淡、没有功能 | 让它带来驱动力、受阻或脱离预期 |

## 法则清单

### 准入与禁令
- 每句对话至少承载一项：推进剧情 / 增加期待 / 展示人设；不承载即删。
- 情绪场景里每句还要回应上一句的情绪状态（承接 / 偏转 / 升级 / 退缩）；无承接就是机械对话。
- 禁配角无脑夸主角、互相复述读者已知信息、大段说明文式台词、所有角色一个腔调。
- 禁靠对话说服人物——现实中没人被几句话说服，改用突发状况替代。
- 禁悬念正攒着被台词说破；情绪写完方向变了就回退重拆。

### 权力博弈
- 对话长度 = 权力地位：掌控者话短而冷静，被动者话多而情绪化。
- 对话双方时，短句方是权力上位。
- 亮底牌不带解释，一句事实即可，不加动作描写。
- 心死不说破：从辩解到沉默到「随意」，一轮比一轮短。

### 潜台词与议程
- 每个角色进场都带自己的议程，即想从这场对话得到什么。
- 两个议程碰撞才是张力来源；议程一致 = 复述，改议程或删。
- 动机不写在台词里：每句同时设计角色的动机与角色给自己找的借口。
- 语气 = 关系 × 场合 × 目的；私密的话放到公众场合说才有冲击力。
- 台词讲不出的部分，用动作、神态、环境补。

### 情绪与信息
- 情绪转变不跳步：相邻两档之间必须有事件触发。
- 强情绪用命令式 + 否定式；最狠的话术是句句关心、句句嫌弃。
- 信息不整段讲，用角色当下的目的与立场取舍，用到哪带到哪。
- 任何角色都不当科普嘴，尤其信息型配角；反应不固定拼接。
- 情绪拉扯靠上下行交替，不靠一次把话说完。

### 人物差异化
- 遮住角色名仍能分辨是谁在说话；分不清就是人设模糊。
- 每个主要角色给一个标志性用词和一个固定立场角度。
- 差异化维度：口癖、说话节奏、信息偏好、立场、身份、性格、关系阶段。
- 卡在「他会说什么」时，先总结同类人设的说话方式再落笔。

### 弹幕与群众
- 弹幕只做三件事：补主角不知道的信息、拉期待、渲染情绪；不替代主线。
- 用递进取代同质刷屏，可安排一个路人反转改变全场认知。
- 集中在关键爽点 / 燃点 / 泪点前后用，不必每章都写。

### 节奏与篇幅
- 紧张段落对话短促，舒缓段落可放长；不删口吻词来「精简」。
- 连续多轮对话后要换气：插环境、心理或停顿。
- 动作与表情用在关键转折处；每句都配会机械，平淡场景靠微动作与沉默。
- 关键信息放对话开头或结尾，中段用于拉扯情绪。
- 能用突发状况替代的对话整段替换；读者已知信息的对话用叙事一句概括。
- 删掉语气词就干巴巴 = 对话本身缺信息量，要重写而非精简。
- 对话过少时把旁白交代改成人物对话，但新配角必须带主线戏份。

### 以梗填充（带例外）
- 梗与骚话放在主角或重要配角的突出台词上，强化记忆点。
- 可用一个梗作高潮点，整段剧情围绕达成它来设计。
- 高压 / 生死 / 悲痛 / 严肃 beat 里梗一律收敛，声线让位于情绪基调。
- 梗只在安全或喘息 beat 放；自检：这句玩笑放进当前基调会不会让读者出戏。

## 自检清单

- [ ] 每句都能指出它推进剧情 / 增加期待 / 展示人设中的哪一项
- [ ] 情绪场景中每句都承接了上一句的情绪状态
- [ ] 已清掉配角无脑吹捧、复述已知信息、说明文式台词
- [ ] 遮住角色名后仍能分辨是谁在说话
- [ ] 每个角色都有自己的议程，且议程之间存在碰撞
- [ ] 真实动机没有直接写进台词
- [ ] 权力关系体现在话长上：掌控者短，被动者长
- [ ] 情绪转变有事件触发，没有跳步
- [ ] 设定由角色立场包裹，没有角色在整段科普
- [ ] 弹幕有递进层次，且没有替代主线
- [ ] 关键信息落在对话开头或结尾
- [ ] 长对话中有换气点，动作表情没有每句都配
- [ ] 高压 / 生死 / 悲痛 / 严肃 beat 里没有插科打诨
- [ ] 这段对话结束时，剧情确实往前推了一步
