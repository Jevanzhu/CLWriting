# 去AI味判断速查

用于改稿与自检时判断「这段为什么像 AI」以及「该往哪改」。与本书文风、章纲冲突时以它们为准。
**本档只收判断面**（取舍 / 角度 / 判据）；可判定部分（词表、句式正则、删除比例阈值）在代码
（`src/check/ai-patterns.ts` 的套话词表与套路句式表、`src/check/body-format.ts` 的正文格式检），
两侧互指，改词表改代码、改判断改本档。

## 决策路由

| 信号 | 用哪条法则 |
|---|---|
| 读起来「哪里都对，就是不像人写的」 | 先判是不是解释腔：叙述者跳出来讲道理 |
| 每一段都工整、长短一样 | 节奏问题：句式过于整齐，不是词的问题 |
| 情绪写得很足，但读者不代入 | 情绪被标注而非被演示——查有没有替读者下结论 |
| 改了一版，更假了 | 二修伪自然：把「删词」当成去味的全部 |
| 删完读着像电报 | 删过头：中文的自然冗余不是 AI 味 |
| 不知道要不要动这句 | 先做删除测试：删掉后信息/选择/关系/后果有没有损失 |

## 法则清单

- **判断顺序：先删后改，最后才润色**。多数 AI 味句是废话（解释、注水、凑数），删掉即可；
  润色留不住它的功能，只让它更体面。
- **删除测试（逐处过）**：删掉后若伏笔、钩子、人物特征、情节推进、必要转折都不丢 → 直接删；
  丢任意一项 → 保留信息、只改「怎么说」。
- **解释腔是最难察觉的一类**（叙述者出戏）：表现为解释因果（「之所以…是因为」）、剧透
  （「她不知道的是」「多年以后」）、替读者定性（「演得真好」「他就是这样薄情」）、软评判
  （「关切得恰到好处」）。判据是「这话是角色此刻能想到的，还是作者在补充说明」。
- **情绪不是不能直写**：上下文已经让情绪成立时就保留或删掉重复说明；不要机械执行
  「情绪词 → 身体动作」的替换——那会造出满篇攥拳、咽口水的另一种模板。
- **身体细节按功能取舍**：伤势、动作失败、人物习惯、情节后果可留；只重复标注情绪的微动作删掉。
- **节奏问题的修法是打断整齐，不是把长句拆成短句串**：只拆臃肿修饰、堆叠比喻、抽象总结；
  叙述仍以逗号长句为主，长短随情绪 beat 交错（沉淀放慢、冲突骤短）。
- **对话的 AI 味来自「每句都逻辑完整、信息精准」**：真人说话有答非所问、有打断、有说半句；
  但口误/停顿/粗话要服务人物身份，不作为「真人感」装饰批量添加。
- **结尾不升华**：删总结句，用动作或未解决的问题收尾（短篇例外见下）。
- **替换不复用**：同一个词在一章内多次命中时各处给不同写法；同一个替换写法反复出现
  （每次都「垂下眼」），替换产物本身就是新模板。

## 改写顺序（只排所选门的先后）

1. **去泛化**：删抽象总结、万能结论、意义膨胀，把「说明了什么」落回「发生了什么」。
2. **去书面化**：书面判断词（不容置疑/显而易见）改口语；修饰词清扫（多余的形容词、
   定语、代词、量词：多余即删，删后含义流失则改简洁名词）。
3. **回自然感**：段落长短交错、对话带停顿、叙述回到角色此刻能感知的东西。

**删过头自检**：删完若整段只剩最短句、结构虚词被扫光、每个动作都带「了一下」式尾巴，
就是删过头了——把非峰值叙述句恢复成自然白话，不是接着删。删的是废话，不是中文的自然冗余。

## 自检清单

- [ ] 有没有一句是作者在补充说明（因果解释/剧透/定性），角色此刻想不到？
- [ ] 情绪是标注的还是演示的？读者有没有被替着下了结论？
- [ ] 段落是否工整到每段都一样长？该打断的地方打断了吗？
- [ ] 删掉可疑句后，信息/选择/关系/后果有没有损失？（无损即该删）
- [ ] 替换产物本身有没有重复成新的模板（同一动作反复用同一个替换写法）？
- [ ] 改完通读一遍：读起来像人写的，还是像「努力像人写」的？

## 与短篇的口径差

短篇（单篇闭口）的章尾带主角主观情绪的审判句、心死式收尾是**卖点**，保留；
去味只删中立、与角色情绪无关的作者讲解。长篇按上面通用口径执行。
