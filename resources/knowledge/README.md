# 随包知识语料（写稿面运行时读取）

本目录是 `知识层/` 正式语料的**随包子集**，只放「真模型写稿时按章选材」会读到的判断类速查；
不随包的篇目留在 `知识层/` 供人读与后续接线（题材路由 = 建书/大纲面、质量检查清单 = 三审 prompt 固化面）。

- 来源与许可：各篇正文前的 front matter 保留原始 source / source_ref / license；MIT 许可全文见 `许可/`。
- 一致性：本目录下每个文件必须与 `知识层/` 内同名文件**逐字节相等**，由 `npm run check:knowledge` 对账；
  改语料 = 改 `知识层/` 原稿（含 manifest 哈希）后同步此处，两处不同步即红。
- 注入口径（写稿面）：按本章细纲/章纲信号选材，基础篇 1 篇（长篇＝章节钩子速查，短篇＝反转设计速查）
  + 信号追加 1 篇（节奏与升级感速查／人物与对话技法速查），合计 ≤2 篇、单篇 ≤2000 码点、
  合计 ≤3000 码点；篇内 front matter 不进 prompt。冲突时以本书设定为准。实现 = `src/knowledge/select.ts`。
